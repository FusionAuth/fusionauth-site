The Reconcile API logs in a user with a JWT that an external system issued. FusionAuth validates the JWT with an [External JWT Identity Provider](/docs/apis/identity-providers/external-jwt), then reconciles the user that the JWT represents. FusionAuth creates or updates the user, depending on the linking strategy of the Identity Provider.

The Reconcile API takes the same request and returns the same response as [Complete the External JWT Login](/docs/apis/identity-providers/external-jwt#complete-the-external-jwt-login). The Reconcile API accepts only External JWT Identity Providers.

<ExternalJwtProviderWarning />

When **`createRegistration`** is enabled for the Application in the Identity Provider, FusionAuth registers a user who has no [[Registration]] for the Application. FusionAuth then assigns the default roles of the Application. When **`createRegistration`** is disabled, FusionAuth doesn't register the user, and the response has a `202` status code.

## Request

Send the JWT in **`data.token`**.

## Response

The response contains the User object.

<IdentityProviderLoginResponseCodes />

When the **`applicationId`** or the **`identityProviderId`** doesn't exist, the response has a `400` status code. The response also has a `400` status code when the **`identityProviderId`** belongs to an Identity Provider of another type.
