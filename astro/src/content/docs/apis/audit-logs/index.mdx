The audit log records changes to FusionAuth configuration and users. FusionAuth adds an entry automatically when someone makes a change in the Admin UI, the Tenant Manager, or the self-service account pages.

Changes made directly with the APIs aren't recorded automatically. To record them, call the [Add an Entry to the Audit Log API](/docs/apis/audit-logs/add-an-entry-to-the-audit-log) from your code, or capture API requests in your proxy's access logs.
