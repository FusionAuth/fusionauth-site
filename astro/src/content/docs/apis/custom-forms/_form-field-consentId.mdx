The Id of an existing [Consent](/docs/apis/consents). This field is required when **type** is `consent`.

A consent Form Field lets users self-consent during registration to a FusionAuth Consent, such as terms of service, an end user license agreement, or another opt-in or opt-out agreement.

<If condition={props.update_request}>
  You can change the Consent of a consent Form Field with this API. FusionAuth updates the key of the Form Field to match the new Consent. The Admin UI doesn't allow this change.
</If>
