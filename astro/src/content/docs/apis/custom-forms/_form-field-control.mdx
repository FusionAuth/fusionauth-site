The form control that displays the Form Field. The possible values are:

* `checkbox`
* `number`
* `password`
* `radio`
* `select`
* `textarea`
* `text`

<If condition={props.form_field_request && !props.update_request}>
  You can set the control for custom fields only. The default value is `text`. FusionAuth sets the control of managed fields, such as `user.firstName`.
</If>

<If condition={props.update_request}>
  This field is required when you update a custom Form Field with `PUT`, unless the Form Field is a consent Form Field. You can change the control of a custom Form Field with this API. The Admin UI doesn't allow this change.

  FusionAuth ignores this field for managed fields, such as `user.firstName`, and for consent Form Fields. FusionAuth keeps the original control of those Form Fields.
</If>
