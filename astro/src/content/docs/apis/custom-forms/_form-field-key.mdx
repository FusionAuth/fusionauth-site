To store custom data, start the key with one of the following prefixes:

* `user.data.`
* `registration.data.`

For example, to store the favorite color of a User, set the key to `user.data.favoriteColor`.

A key can't contain spaces or special characters. To store the value in an array, use array syntax, such as `[0]` for the first position. To store the value in a nested object, use object syntax, such as `['foo']` for the property named `foo`. For example:

* `user.data.preferences[0]` stores the value in the first position of an array named `preferences`.
* `user.data.preferences['color']` stores the value in the `color` property of an object named `preferences`.

To show a readable, localized label for the key during registration, add the key to the messages of your theme. For example, the following message shows `Favorite color` for the `user.data.favoriteColor` key:

```properties
user.data.favoriteColor=Favorite color
```
