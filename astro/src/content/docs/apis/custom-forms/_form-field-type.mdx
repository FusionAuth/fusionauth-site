The data type FusionAuth uses to store the value. The possible values are:

* `bool`: a boolean value, `true` or `false`.
* `consent`: a value that completes self-consent.
* `date`: a date in `YYYY-MM-DD` format, such as `2025-01-31`. A JavaScript date picker can convert the selected date to this format.
* `email`: a valid email address.
* `number`: a numeric value.
* `string`: a string.

<If condition={props.form_field_request && !props.update_request}>
  FusionAuth validates all user input against the data type. When FusionAuth can't convert the input, FusionAuth shows a validation error to the user. Each option in **options** must also match the data type.

  When **type** is `consent`, **consentId** is required.

  You can set the data type for custom fields only. The default value is `string`. FusionAuth sets the data type of managed fields, such as `user.firstName`.

  You can't change the data type after you create the Form Field. To use a different data type, create a new Form Field.
</If>

<If condition={props.update_request}>
  You can't change the data type after you create the Form Field. FusionAuth keeps the original data type, but still validates the request against the **type** you send. Send the original **type**, or leave **type** out. When you update a consent Form Field with `PUT`, set **type** to `consent`.
</If>
