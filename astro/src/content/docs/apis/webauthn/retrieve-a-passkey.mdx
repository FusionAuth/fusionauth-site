Use this API to retrieve information about a single WebAuthn passkey or all of a user's registered passkeys.

## Request

### Retrieve a Single Passkey

<API method="GET" uri="/api/webauthn/{id}" authentication={["api-key"]} title="Retrieve a single Passkey by Id"/>

#### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

#### Request Parameters

<APIBlock>
  <APIField name="id" type="UUID" required>
    The unique Id of the WebAuthn passkey to retrieve.
  </APIField>
</APIBlock>

### Retrieve All Passkeys for a User

<API method="GET" uri="/api/webauthn?userId={userId}" authentication={["api-key"]} title="Retrieve all Passkeys belonging to a User"/>

### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

### Request Parameters

<APIBlock>
  <APIField name="userId" type="UUID" required>
    The unique Id of the User to retrieve WebAuthn passkeys for. Required if `id` is omitted.
  </APIField>
</APIBlock>

## Response

The response for this API contains either all of the Passkeys belonging to a User, or a single Passkey.
