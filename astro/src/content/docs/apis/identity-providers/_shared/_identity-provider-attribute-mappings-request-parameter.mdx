
<APIField name="identityProvider.attributeMappings" type="Map<String, String>" since="1.65.0" optional>
  A map of attribute mappings that FusionAuth applies during user reconciliation when the Identity Provider has no reconcile Lambda. The default is an empty map.

  Each key is a FusionAuth target field path. Each key must begin with `user.` or `registration.`. FusionAuth ignores a key with any other prefix. Each value is a source expression in the payload of the IdP response. FusionAuth converts a dot-notated value, such as `email` or `id_token.given_name`, to a JSON Pointer. FusionAuth uses a value that starts with `/` as a JSON Pointer without changes.

  You can't use this field with **`identityProvider.lambdaConfiguration.reconcileId`**.

  When **`identityProvider.linkingStrategy`** is `LinkAnonymously`, FusionAuth ignores this field.

  FusionAuth ignores a mapping that resolves to null, that FusionAuth can't extract, or that FusionAuth can't write to the target field. A mapping to `user.password` doesn't set a password.
</APIField>
