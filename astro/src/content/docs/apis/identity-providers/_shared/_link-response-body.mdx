The response body for this API contains either a single Link or an array of Links. When you call this API with **`identityProviderId`**, **`identityProviderUserId`**, and optionally **`userId`**, the response contains a single Link. When you call this API with **`userId`** and optionally **`identityProviderId`**, the response contains an array of Links.
