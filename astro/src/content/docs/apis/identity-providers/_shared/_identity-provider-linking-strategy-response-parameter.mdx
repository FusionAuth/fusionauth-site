
<APIField name="identityProvider.linkingStrategy" type="String" since={ props.idp_since < 12800 ? "1.28.0" : '' }>
  The strategy that FusionAuth uses to link the {props.idp_display_name} Identity Provider to the User.

  <If condition={props.idp_display_name === 'HYPR'}>
  For the HYPR Identity Provider, the value is always `Unsupported`.
  </If>

  <If condition={props.idp_display_name !== 'HYPR'}>
  The possible values are:

    * `CreatePendingLink`: FusionAuth creates a pending link.
    * `Disabled`: FusionAuth doesn't link automatically. <AvailableSince since="1.37.0" />
    * `LinkAnonymously`: FusionAuth links by the unique Id from the IdP, without a username or email address.
    * `LinkByEmail`: FusionAuth links by email address, and creates a missing User.
    * `LinkByEmailForExistingUser`: FusionAuth links by email address, and doesn't create a missing User.
    * `LinkByUsername`: FusionAuth links by username, and creates a missing User.
    * `LinkByUsernameForExistingUser`: FusionAuth links by username, and doesn't create a missing User.
  </If>
</APIField>
