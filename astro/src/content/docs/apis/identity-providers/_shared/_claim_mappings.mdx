
A map of incoming claims to User fields, User data, or Registration data. Each key is the name of an incoming claim from the configured Identity Provider. The map accepts the following values:

* `birthDate`
* `firstName`
* `lastName`
* `fullName`
* `middleName`
* `mobilePhone`
* `imageUrl`
* `timezone`
* `UserData`
* `RegistrationData`
