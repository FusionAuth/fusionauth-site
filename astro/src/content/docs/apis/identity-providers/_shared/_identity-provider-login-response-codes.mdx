import TableGrid from 'astro-better-tables/TableGrid.astro';
import Row from 'astro-better-tables/Row.astro';
import Cell from 'astro-better-tables/Cell.astro';

<TableGrid caption="Response Codes" widths="1 6">
  <Row slot="head">
    <Cell header>Code</Cell>
    <Cell header>Description</Cell>
  </Row>
  <Row>
    <Cell>200</Cell>
    <Cell>
      The authentication succeeded. The response contains the authenticated User object.
    </Cell>
  </Row>
  <Row>
    <Cell>202</Cell>
    <Cell>
      The authentication succeeded, but the user isn't registered for the Application in the **`applicationId`** of the request.

      The response contains the authenticated User object.
    </Cell>
  </Row>
  <Row>
    <Cell>203</Cell>
    <Cell>
      The authentication succeeded, but the user must change the password. The response contains the **`changePasswordId`** for the [Change Password](/docs/apis/users/change-password) API.

      <JSON title="Example Response JSON" src="login/login-change-password-response.json" />
    </Cell>
  </Row>
  <Row>
    <Cell>204</Cell>
    <Cell>
      The login waits on an action by the user. Wait, and then send the request again.
    </Cell>
  </Row>
  <Row>
    <Cell>212</Cell>
    <Cell>
      The identity that the user logged in with, such as an email address or phone number, isn't verified yet. The response contains the authenticated User object. When the verification strategy is `FormField`, the response also contains the **`emailVerificationId`** that FusionAuth generated for the user. The response can also contain an **`identityVerificationId`**.
    </Cell>
  </Row>
  <Row>
    <Cell>213</Cell>
    <Cell>
      The Registration of the user isn't verified yet. The response contains the authenticated User object. When the verification strategy is `FormField`, the response also contains the **`registrationVerificationId`** that FusionAuth generated for the user.

      Before version `1.27.0`, FusionAuth returned `200` instead of this status code.
    </Cell>
  </Row>
  <Row>
    <Cell>232</Cell>
    <Cell>
      The Identity Provider uses the `CreatePendingLink` linking strategy, and the user has no link. The response contains only the **`pendingIdPLinkId`**, and possibly **`threatsDetected`**. To link the user, call the [Complete a Pending Link](/docs/apis/identity-providers/links#complete-a-pending-link) API. After FusionAuth links the user, call this API again to log in.

      <JSON title="Example Response JSON" src="login/login-pending-link-response.json" />
    </Cell>
  </Row>
  <Row>
    <Cell>242</Cell>
    <Cell>
      The authentication succeeded, and the user has two-factor authentication enabled. In `1.42.0` and later, FusionAuth also returns this status code when two-factor authentication is required. The response contains the **`twoFactorId`** for the [Complete Two-Factor Authentication](/docs/apis/login/complete-mfa) API.

      <JSON title="Example Response JSON" src="login/login-two-factor-response.json" />
    </Cell>
  </Row>
  <Row>
    <Cell>400</Cell>
    <Cell>
      The request was invalid or malformed, or a login validation lambda rejected the login. The response contains an [Errors](/docs/apis/errors) JSON object with the specific errors.
    </Cell>
  </Row>
  <Row>
    <Cell>401</Cell>
    <Cell>
      FusionAuth couldn't complete the login. For example, the Identity Provider isn't enabled for the Application, FusionAuth couldn't verify the response from the Identity Provider, or FusionAuth couldn't reconcile the user.
    </Cell>
  </Row>
  <Row>
    <Cell>404</Cell>
    <Cell>
      FusionAuth didn't find the user, or no Link to the user exists and either the linking strategy is `Disabled` or the request set **`noLink`** to `true`. The response is empty.
    </Cell>
  </Row>
  <Row>
    <Cell>409</Cell>
    <Cell>
      An action on the user prevents login. The response contains the actions that prevent login.

      <JSON title="Example Response JSON" src="login/login-prevented-response.json" />
    </Cell>
  </Row>
  <Row>
    <Cell>410</Cell>
    <Cell>
      The user has expired. The response is empty.
    </Cell>
  </Row>
  <Row>
    <Cell>500</Cell>
    <Cell>
      FusionAuth had an internal error and logged a stack trace in the FusionAuth log files. The response is empty.
    </Cell>
  </Row>
  <Row>
    <Cell>503</Cell>
    <Cell>
      The search index is unavailable or returned an error, so FusionAuth can't complete the request. The response contains a JSON body.
    </Cell>
  </Row>
  <Row>
    <Cell>504</Cell>
    <Cell>
      One or more webhook endpoints returned an invalid response or were unreachable. Because of the transaction configuration for the event, FusionAuth can't complete the request. FusionAuth logs a stack trace in the FusionAuth log files.
    </Cell>
  </Row>
</TableGrid>
