  <APIField name="identityProvider.defaultKeyId" required deprecated>
    The Id of the key that verifies the signature of the JWT. In most cases, the JWT header contains the key identifier. FusionAuth uses the key identifier to look up a key in **`identityProvider.verificationKeyIds`** or in this field.

    Before FusionAuth `1.69.0`, this field was optional. In `1.69.0` and later, you must provide this field or at least one value in **`identityProvider.verificationKeyIds`**.

    <DeprecatedSince since="1.69.0">
      In version `1.69.0` and later, use **`identityProvider.verificationKeyIds`**. For backward compatibility, FusionAuth populates **`identityProvider.defaultKeyId`** with the first entry in **`identityProvider.verificationKeyIds`**.
    </DeprecatedSince>
  </APIField>
  <APIField name="identityProvider.domains" optional>
    An array of domains that this Identity Provider manages.
  </APIField>
  <APIField name="identityProvider.enabled" type="Boolean" optional defaults="false">
    Whether this Identity Provider is enabled. When `false`, FusionAuth disables the IdP globally.
  </APIField>
  <APIField name="identityProvider.headerKeyParameter" type="String" required>
    The name of the header claim that identifies the public key that verifies the signature. In most cases, the header claim is `kid` or `x5t`.
  </APIField>
  <APIField name="identityProvider.lambdaConfiguration.reconcileId" type="UUID" optional since="1.17.0">
    The unique Id of the lambda that FusionAuth runs during the user reconcile process. The lambda maps custom claims from the external Identity Provider to the FusionAuth user. You can use the lambda in addition to the claim mappings, or in place of the claim mappings.

    The lambda must be of type `ExternalJWTReconcile`.
  </APIField>

  <APIField name="identityProvider.name" type="String" required>
    The name of the Identity Provider.
  </APIField>
  <APIField name="identityProvider.oauth2.authorization_endpoint" type="String" optional>
    The authorization endpoint for this Identity Provider. FusionAuth doesn't use this value. FusionAuth only returns this value in the Lookup Identity Provider API response. During integration, you can use this value to redirect the browser to the OAuth2 authorize endpoint.
  </APIField>
  <APIField name="identityProvider.oauth2.emailClaim" type="String" optional defaults="email">
    The name of the claim that contains the user's email address. When **`identityProvider.linkingStrategy`** is `LinkByEmail` or `LinkByEmailForExistingUser`, FusionAuth finds or creates the user by this email address. When the JWT contains an email address and **`identityProvider.domains`** has values, the email address must be in one of the domains.

    When **`identityProvider.uniqueIdentityClaim`** has a value, FusionAuth ignores this field.
  </APIField>
  <APIField name="identityProvider.oauth2.emailVerifiedClaim" type="String" optional defaults="email_verified" since="1.48.0">
    The name of the claim that identifies whether the user's email address is verified.

    When **`identityProvider.linkingStrategy`** is `LinkByEmail` or `LinkByEmailForExistingUser`, and the JWT has this claim with a value of `false`, FusionAuth doesn't create a link. FusionAuth returns an error that says FusionAuth can't create a link with an unverified email address.
  </APIField>
  <APIField name="identityProvider.oauth2.token_endpoint" type="String" optional>
    The token endpoint for this Identity Provider. FusionAuth doesn't use this value. FusionAuth only returns this value in the Lookup Identity Provider API response. During integration, you can use this value to complete the OAuth2 grant workflow.
  </APIField>
  <APIField name="identityProvider.oauth2.uniqueIdClaim" type="String" optional defaults="sub">
    The name of the claim that contains the user's unique user Id. FusionAuth links the user to this Identity Provider by this value. The Reconcile API rejects a JWT that doesn't contain the claim.
  </APIField>
  <APIField name="identityProvider.oauth2.usernameClaim" type="String" optional defaults="preferred_username">
    The name of the claim that contains the user's username. FusionAuth only uses this claim when **`identityProvider.linkingStrategy`** is `LinkByUsername` or `LinkByUsernameForExistingUser`.
  </APIField>

  <IdentityProviderSourceRequestParameter />

  <IdentityProviderTenantConfiguration />
  <APIField name="identityProvider.tenantId" type="UUID" optional since="1.62.0">
    The unique Id of the Tenant.

    When you provide a value, FusionAuth creates an Identity Provider scoped to the specified Tenant. Otherwise, FusionAuth creates a global Identity Provider. A Tenant-scoped IdP can only authenticate users in the context of the specified Tenant. A global IdP works with any Tenant.

    This value is read-only after FusionAuth creates the Identity Provider.
  </APIField>
  <APIField name="identityProvider.type" type="String" required>
    This field must be set to `ExternalJWT`.
  </APIField>
  <APIField name="identityProvider.uniqueIdentityClaim" type="String" optional deprecated>
    The name of the claim that contains the user's email address. When this field has a value, FusionAuth reads the email address from this claim instead of the claim in **`identityProvider.oauth2.emailClaim`**. The Reconcile API then rejects a JWT that doesn't contain the claim.

    Use **`identityProvider.oauth2.emailClaim`** for the email address and **`identityProvider.oauth2.uniqueIdClaim`** for the user's unique Id instead. To switch an existing Identity Provider to those fields, update the Identity Provider without **`identityProvider.uniqueIdentityClaim`**, or set the field to `null`. FusionAuth treats an empty string as a claim name, so an empty string keeps the legacy behavior and the Reconcile API rejects the JWT.
  </APIField>
  <APIField name="identityProvider.verificationKeyIds" required type="Array<UUID>" since="1.69.0">
    The Ids of the keys that verify JWT signatures. In most cases, the JWT header contains the key identifier. FusionAuth uses the key identifier to look up a key in this list or in **`defaultKeyId`**.

    Before version `1.69.0`, this field doesn't exist. Use **`identityProvider.defaultKeyId`** instead.
  </APIField>
