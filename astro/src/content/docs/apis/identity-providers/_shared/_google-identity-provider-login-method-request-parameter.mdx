
<Aside type="version" title="Before version 1.44.0">
In FusionAuth versions before `1.44.0`, `UsePopup` doesn't work. `UseRedirect` still works. For more information, see the [1.44.0 release notes](/docs/release-notes#version-1-44-0). For a workaround and the update process, see the [Google Identity Provider changes forum post](/community/forum/topic/2329/upcoming-google-identity-provider-changes).
</Aside>
