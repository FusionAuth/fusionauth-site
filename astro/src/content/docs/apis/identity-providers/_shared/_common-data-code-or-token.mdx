<APIField name="data.code" type="String" optional since={props.data_code_since}>
  The authorization code that {props.idp_display_name} returns to your redirect URI. FusionAuth exchanges the code for tokens at the {props.idp_display_name} token endpoint.

  Send either **`data.code`** or **`data.token`**. When you send **`data.code`**, also send **`data.redirect_uri`**.
</APIField>
<APIField name="data.redirect_uri" type="String" optional since={props.data_code_since}>
  The redirect URI that your app sent to the {props.idp_display_name} authorization endpoint. FusionAuth sends the value to the {props.idp_display_name} token endpoint as the `redirect_uri` parameter.

  This field is required when you send **`data.code`**, even when you also send **`data.token`**.
</APIField>
<APIField name="data.token" type="String" optional>
  When {props.idp_display_name} returns {props.token_for_login_request} to your app directly, such as from a popup or a native SDK, send the token in this field. FusionAuth sends the token to {props.idp_display_name} to look up the user and then completes the login.

  When you send both **`data.code`** and **`data.token`**, FusionAuth uses <strong><code>data.{props.preferred_field}</code></strong>.
</APIField>
