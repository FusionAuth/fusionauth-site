<APIField name="identityProvider.linkingStrategy" type="String" optional defaults={props.idp_linking_strategy} since={ props.idp_since < 12800 ?"1.28.0" : ''}>
  The strategy that FusionAuth uses to link the {props.idp_display_name} Identity Provider to the User.

  <If condition={props.idp_display_name === 'HYPR'}>
  The HYPR Identity Provider doesn't support linking strategies. FusionAuth always sets this field to `Unsupported`, and ignores the value in the request.
  </If>

  <If condition={props.idp_display_name !== 'HYPR'}>
  <LinkingStrategyEditLimit />

  The possible values are:

    * `CreatePendingLink`: FusionAuth doesn't link automatically. FusionAuth returns a pending link Id. Use the pending link Id to link to an existing User.
    * `Disabled`: FusionAuth doesn't link automatically. You must create Links with the API. <AvailableSince since="1.37.0" />
    * `LinkAnonymously`: FusionAuth always creates a Link based on the unique Id that the IdP returns. FusionAuth doesn't require a username or email address, and doesn't use a username or email address to link the User. FusionAuth doesn't run a reconcile Lambda.
    * `LinkByEmail`: FusionAuth links to an existing User by email address. When no User has the email address that the IdP returns, FusionAuth creates a User with that email address.
    * `LinkByEmailForExistingUser`: FusionAuth links only to an existing User by email address. When no User has the email address that the IdP returns, FusionAuth doesn't create a User.
    * `LinkByUsername`: FusionAuth links to an existing User by username. When no User has the username that the IdP returns, FusionAuth creates a User with that username.
    * `LinkByUsernameForExistingUser`: FusionAuth links only to an existing User by username. When no User has the username that the IdP returns, FusionAuth doesn't create a User.

   <If condition={!!props.idp_enforce_email_verified_claim}>
    When **`identityProvider.linkingStrategy`** is `LinkByEmail` or `LinkByEmailForExistingUser`, and the response from the {props.idp_display_name} Identity Provider has an `email_verified` claim of `false` and no Link exists yet, FusionAuth doesn't create a Link. FusionAuth returns an error that says FusionAuth can't create a Link with an unverified email address.
   </If>
  </If>
</APIField>
