<APIBlock>
  <APIField name="access_token" type="String">
    The access token, an encoded JSON Web Token (JWT). FusionAuth writes the access token as an HTTP-only session cookie.
  </APIField>
  <APIField name="refresh_token" type="String">
    The refresh token. FusionAuth writes the refresh token as an HTTP-only persistent cookie. The cookie lasts as long as the refresh token time to live in the JWT configuration of the Tenant. When the Application enables its own JWT configuration, the time to live of the Application applies instead.
  </APIField>
</APIBlock>
