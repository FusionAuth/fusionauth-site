
<APIField name="identityProvider.loginMethod" type="String" since={props.idp_since < 12800 ? '1.28.0': ''}>
  The login method for this Identity Provider.

  The possible values are:

    * `UsePopup` : FusionAuth uses a popup window and the {props.idp_display_name} JavaScript library for login.
    * `UseRedirect` : FusionAuth uses the {props.idp_display_name} OAuth redirect login flow.
    * `UseVendorJavaScript` : FusionAuth lets the {props.idp_display_name} JavaScript library choose the login method.
</APIField>
