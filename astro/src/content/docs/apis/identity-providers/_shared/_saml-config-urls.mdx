
`<base_url>` is the URL of your FusionAuth instance, such as `https://login.piedpiper.com`.

`<identityProviderId>` is the UUID of the Identity Provider.

`<applicationId>` is the UUID of the Application the user logs in to.

For an SP-initiated configuration:

**Callback URL (ACS):**
`<base_url>/samlv2/acs`

For an IdP-initiated configuration, which has one URL per Application:

**Callback URL (ACS):**
`<base_url>/samlv2/acs/<identityProviderId>/<applicationId>`

**Issuer:**
`<base_url>/samlv2/sp/<identityProviderId>` by default.

To override the issuer, set **`identityProvider.issuer`** on the SAML v2 Identity Provider. FusionAuth expects the Audience in the SAML response assertion to match the issuer.

**Metadata URL:**
`<base_url>/samlv2/sp/metadata/<identityProviderId>`

For an IdP-initiated login to return a refresh token at the end of the OAuth2 workflow, request the `offline_access` scope. To request the scope, add `?scope=offline_access` to the ACS URL that you configure in your IdP. When users log in to the FusionAuth Admin UI, you can skip this step, because FusionAuth adds the `offline_access` scope.
