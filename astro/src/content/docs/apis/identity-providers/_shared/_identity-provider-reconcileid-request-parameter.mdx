
<APIField name="identityProvider.lambdaConfiguration.reconcileId" type="UUID" optional since={props.idp_since < 11700 ? "1.17.0" : ''}>
  The unique Id of the Lambda that FusionAuth runs during user reconciliation to map custom claims from the external Identity Provider to the FusionAuth User.

  The Lambda must be of type <code>{props.idp_type}Reconcile</code>.

  You can't use this field with **`identityProvider.attributeMappings`**.

  When **`identityProvider.linkingStrategy`** is `LinkAnonymously`, FusionAuth doesn't run this Lambda.
</APIField>
