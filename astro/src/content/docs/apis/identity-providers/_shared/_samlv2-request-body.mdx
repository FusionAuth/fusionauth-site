    The policy for the destination assertion on the SAML login request. The possible values are:

    * `Enabled`: FusionAuth verifies that the Destination attribute in the SAML response equals the expected destination. The FusionAuth hosted login pages expect the FusionAuth ACS (Assertion Consumer Service) URL. The Start a SAML v2 Login Request API expects **`data.samlDestination`**. `Enabled` is the default and the recommended setting.
    * `Disabled`: FusionAuth doesn't validate the Destination attribute. FusionAuth doesn't recommend this setting.
    * `AllowAlternates`: FusionAuth verifies that the Destination attribute is either the FusionAuth ACS or one of the values in **`identityProvider.assertionConfiguration.destination.alternates`**. Use this setting with caution, to help migrate from a third-party IdP.

When the signature doesn't include a certificate, FusionAuth uses the first key in the list. A key without a certificate can verify a response only as the first key. For more information, see [Signature Verification](/docs/authentication/identity-providers/overview-samlv2#signature-verification).
