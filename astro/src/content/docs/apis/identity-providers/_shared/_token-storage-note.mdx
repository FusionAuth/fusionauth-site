
FusionAuth also stores the {props.idp_display_name} <code>{props.token_name}</code> from the {props.return_text} in the **`identityProviderLink.token`** field of the `identityProviderLink` object. You can access the `identityProviderLink` object with the [Link API](/docs/apis/identity-providers/links).

Your application can use the stored token to call {props.idp_display_name} APIs on behalf of the user.

On every login, FusionAuth replaces **`identityProviderLink.token`** with the value from the latest response.

<If condition={props.idp_long_lived_token_type === 'refresh'}>
  Before you call {props.idp_display_name} APIs, make a refresh grant to get a new access token.

  When the provider leaves the refresh token out of a response, FusionAuth loses the stored refresh token. Some providers return a refresh token only on the first login. To keep the refresh token, copy the token to your own storage after the first login.
</If>
