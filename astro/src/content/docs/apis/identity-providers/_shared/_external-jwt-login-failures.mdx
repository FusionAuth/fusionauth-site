FusionAuth returns a `401` for the following causes:

* FusionAuth can't validate the JWT signature.
* The JWT is missing a claim that the Identity Provider configuration requires. FusionAuth always requires the unique Id claim. When the linking strategy links on the email claim or the username claim, FusionAuth also requires that claim.
* The email verified claim is `false`, and the linking strategy links on email.
* The email address isn't in a domain that the Identity Provider manages.
* The linking strategy is `LinkByEmailForExistingUser`, and no user has the email address.
* The linking strategy links on email, and the user with the email address already has a link to the IdP with a different unique Id.
