
<APIField name="identityProvider.attributeMappings" type="Map<String, String>" since="1.65.0">
  A map of attribute mappings that FusionAuth applies during user reconciliation when the Identity Provider has no reconcile Lambda.

  Each key is a FusionAuth target field path. Each key begins with `user.` or `registration.`. Each value is a source expression in the payload of the IdP response.

  When **`identityProvider.linkingStrategy`** is `LinkAnonymously`, FusionAuth ignores this field.

  FusionAuth ignores a mapping that resolves to null, that FusionAuth can't extract, or that FusionAuth can't write to the target field. A mapping to `user.password` doesn't set a password.
</APIField>
