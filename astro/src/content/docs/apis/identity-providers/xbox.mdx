<PlanBlurb plan="starter" />

<AvailableSince since="1.28.0"/>

The Xbox identity provider type will use the Xbox OAuth v2.0 login API. It will also provide a <Breadcrumb>Login with Xbox</Breadcrumb> button on FusionAuth's login page that will direct a user to the Xbox login page.

This identity provider will call Xbox's API to load the user's `email` and `gtg` (Gamer Tag) and use those as `email` and `username` to lookup or create a user in FusionAuth depending on the linking strategy configured for this identity provider. Additional claims returned by Xbox can be used to reconcile the user to FusionAuth by using an Xbox Reconcile Lambda.

## Create Xbox Identity Provider

### Request

Create the Xbox Identity Provider with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/identity-provider" authentication={["api-key"]} title="Create a Xbox Identity Provider using a randomly generated Id"/>

<API method="POST" uri="/api/identity-provider/{identityProviderId}" authentication={["api-key"]} title="Create a Xbox Identity Provider with the provided unique Id"/>

The **type** in the request JSON indicates this is the Xbox Identity Provider type.

#### Path Parameters

<APIBlock>
  <APIField name="identityProviderId" type="UUID" optional immutable defaults="secure random UUID" since="1.61.0">
    The Id to use for the new Identity Provider. If an Id is not provided, a secure random UUID is generated. If neither an Id nor **identityProvider.name** are provided, the legacy fixed Xbox IdP Id `af53ab21-34c3-468a-8ba2-ecb3905f67f2` will be used.
  </APIField>
</APIBlock>

##### Request Body

<OauthIdpRequestBody idp_lowercase="xbox"
                     idp_type="Xbox"
                     idp_display_name="Xbox"
                     idp_linking_strategy="CreatePendingLink"
                     idp_since="12800" />

### Response

<StandardPostResponseCodes conflict_detection never_search_error />

#### Response Body

<OauthIdpResponseBody idp_lowercase="xbox"
                      idp_type="Xbox"
                      idp_display_name="Xbox"
                      idp_linking_strategy="CreatePendingLink"
                      idp_since="12800"
                      idp_id="af53ab21-34c3-468a-8ba2-ecb3905f67f2" />
