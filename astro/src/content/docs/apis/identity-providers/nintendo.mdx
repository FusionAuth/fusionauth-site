<PlanBlurb plan="starter" />

<AvailableSince since="1.36.0"/>

The Nintendo identity provider type will use the Nintendo OAuth login API. It will also provide a <Breadcrumb>Login with Nintendo</Breadcrumb> button on FusionAuth's login page.

If the linking strategy depends on a username or email address, FusionAuth will leverage the `/users/me` API that is part of the Nintendo specification. The email address and username returned in the response will be used to create or lookup the existing User. Additional claims from the response can be used to reconcile the User in FusionAuth by using an Nintendo Reconcile Lambda. Unless you assign a reconcile lambda to this provider or configure the IdP options to use different claims, the `email` and `preferred_username` will be used from the available claims returned by the Nintendo identity provider.

## Create Nintendo Identity Provider

### Request

Create the Nintendo Identity Provider with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/identity-provider" authentication={["api-key"]} title="Create a Nintendo Identity Provider using a randomly generated Id"/>

<API method="POST" uri="/api/identity-provider/{identityProviderId}" authentication={["api-key"]} title="Create a Nintendo Identity Provider with the provided unique Id"/>

The **type** in the request JSON indicates this is the Nintendo Identity Provider type.

#### Path Parameters

<APIBlock>
  <APIField name="identityProviderId" type="UUID" optional immutable defaults="secure random UUID" since="1.61.0">
    The Id to use for the new Identity Provider. If an Id is not provided, a secure random UUID is generated. If neither an Id nor **identityProvider.name** are provided, the legacy fixed Nintendo IdP Id `b0ac2e16-d4af-483e-98c8-7f6693610665` will be used.
  </APIField>
</APIBlock>

##### Request Body

<OauthIdpRequestBody idp_lowercase="nintendo"
                     idp_type="Nintendo"
                     idp_display_name="Nintendo"
                     idp_linking_strategy="CreatePendingLink"
                     idp_since="13600"
                     optional_tag={true} />

### Response

<StandardPostResponseCodes conflict_detection never_search_error />

#### Response Body

<OauthIdpResponseBody idp_lowercase="nintendo"
                      idp_type="Nintendo"
                      idp_display_name="Nintendo"
                      idp_linking_strategy="CreatePendingLink"
                      idp_since="13600"
                      idp_id="b0ac2e16-d4af-483e-98c8-7f6693610665"
                      optional_tag={true} />
