<PlanBlurb plan="starter" />

<AvailableSince since="1.28.0"/>

The Epic Games identity provider type will use the Epic Games OAuth login API. It will also provide a <Breadcrumb>Login with Epic Games</Breadcrumb> button on FusionAuth's login page that will direct a user to the <Breadcrumb>Epic Games login page</Breadcrumb>.

This identity provider will call Epic Games' API to load the Epic Games user's `displayName` and use that as `username` to lookup or create a user in FusionAuth depending on the linking strategy configured for this identity provider. However, Epic Games does not allow access to user emails, so neither email linking strategy can be used and user's will not be able to login or be created.

## Create Epic Games Identity Provider

### Request

Create the Epic Games Identity Provider with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/identity-provider" authentication={["api-key"]} title="Create a Epic Games Identity Provider using a randomly generated Id"/>

<API method="POST" uri="/api/identity-provider/{identityProviderId}" authentication={["api-key"]} title="Create a Epic Games Identity Provider with the provided unique Id"/>

The **type** in the request JSON indicates this is the Epic Games Identity Provider type.

#### Path Parameters

<APIBlock>
  <APIField name="identityProviderId" type="UUID" optional immutable defaults="secure random UUID" since="1.61.0">
    The Id to use for the new Identity Provider. If an Id is not provided, a secure random UUID is generated. If neither an Id nor **identityProvider.name** are provided, the legacy fixed Epic Games IdP Id `1b932b19-61a8-47c7-9e81-27dbf9011dad` will be used.
  </APIField>
</APIBlock>

##### Request Body

<OauthIdpRequestBody idp_lowercase="epicgames"
                     idp_type="EpicGames"
                     idp_display_name="Epic Games"
                     idp_linking_strategy="CreatePendingLink"
                     idp_since={12800} />

### Response

<StandardPostResponseCodes conflict_detection never_search_error />

#### Response Body

<OauthIdpResponseBody idp_lowercase="epicgames"
                      idp_type="EpicGames"
                      idp_display_name="Epic Games"
                      idp_linking_strategy="CreatePendingLink"
                      idp_since={12800}
                      idp_id="1b932b19-61a8-47c7-9e81-27dbf9011dad" />
