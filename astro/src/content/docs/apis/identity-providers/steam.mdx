<PlanBlurb plan="starter" />

<AvailableSince since="1.28.0"/>

The Steam identity provider type will use the Steam OAuth login API. It will also provide a <Breadcrumb>Login with Steam</Breadcrumb> button on FusionAuth's login page that will direct a user to the Steam login page. The Steam login uses the implicit OAuth grant and will return to the [[callback URL]] with `token` and `state` in the URL Fragment. This is handled by the FusionAuth `/oauth2/implicit` JavaScript function to pass those values to the `/oauth2/callback` endpoint.

This identity provider will call Steam's API to load the Steam user's `personaname` and use that as `username` to lookup or create a user in FusionAuth depending on the linking strategy configured for this identity provider.  However, Steam does not allow access to user emails, so neither email linking strategy can be used and user's will not be able to login or be created.

## Create Steam Identity Provider

### Request

Create the Steam Identity Provider with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/identity-provider" authentication={["api-key"]} title="Create a Steam Identity Provider using a randomly generated Id"/>

<API method="POST" uri="/api/identity-provider/{identityProviderId}" authentication={["api-key"]} title="Create a Steam Identity Provider with the provided unique Id"/>

The **type** in the request JSON indicates this is the Steam Identity Provider type.

#### Path Parameters

<APIBlock>
  <APIField name="identityProviderId" type="UUID" optional immutable defaults="secure random UUID" since="1.61.0">
    The Id to use for the new Identity Provider. If an Id is not provided, a secure random UUID is generated. If neither an Id nor **identityProvider.name** are provided, the legacy fixed Steam IdP Id `e4f39345-7833-4b1d-b331-ca03bdc2c4be` will be used.
  </APIField>
</APIBlock>

##### Request Body

<OauthIdpRequestBody idp_lowercase="steam"
                     idp_type="Steam"
                     idp_display_name="Steam"
                     idp_linking_strategy="CreatePendingLink"
                     idp_since="12800" />

### Response

<StandardPostResponseCodes conflict_detection never_search_error />

#### Response Body

<OauthIdpResponseBody idp_lowercase="steam"
                      idp_type="Steam"
                      idp_display_name="Steam"
                      idp_linking_strategy="CreatePendingLink"
                      idp_since="12800"
                      idp_id="e4f39345-7833-4b1d-b331-ca03bdc2c4be" />
