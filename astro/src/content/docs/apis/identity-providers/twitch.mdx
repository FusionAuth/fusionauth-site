<PlanBlurb plan="starter" />

<AvailableSince since="1.28.0"/>

The Twitch identity provider type will use the Twitch OAuth v2.0 login API. It will also provide a <Breadcrumb>Login with Twitch</Breadcrumb> button on FusionAuth's login page that will direct a user to the Twitch login page.

This identity provider will call Twitch's API to load the user's `email` and `preferred_username` and use those as `email` and `username` to lookup or create a user in FusionAuth depending on the linking strategy configured for this identity provider. Additional claims returned by Twitch can be used to reconcile the user to FusionAuth by using a Twitch Reconcile Lambda.

FusionAuth will also store the Twitch `refresh_token` returned from the Twitch API in the link between the user and the identity provider. This token can be used by an application to make further requests to Twitch APIs on behalf of the user.

## Create Twitch Identity Provider

### Request

Create the Twitch Identity Provider with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/identity-provider" authentication={["api-key"]} title="Create a Twitch Identity Provider using a randomly generated Id"/>

<API method="POST" uri="/api/identity-provider/{identityProviderId}" authentication={["api-key"]} title="Create a Twitch Identity Provider with the provided unique Id"/>

The **type** in the request JSON indicates this is the Twitch Identity Provider type.

#### Path Parameters

<APIBlock>
  <APIField name="identityProviderId" type="UUID" optional immutable defaults="secure random UUID" since="1.61.0">
    The Id to use for the new Identity Provider. If an Id is not provided, a secure random UUID is generated. If neither an Id nor **identityProvider.name** are provided, the legacy fixed Twitch IdP Id `bf4cf83f-e824-42d7-b4a3-5b10847a66b2` will be used.
  </APIField>
</APIBlock>

##### Request Body

<OauthIdpRequestBody idp_lowercase="twitch"
                     idp_type="Twitch"
                     idp_display_name="Twitch"
                     idp_linking_strategy="CreatePendingLink"
                     idp_since="12800" />

### Response

<StandardPostResponseCodes conflict_detection never_search_error />

#### Response Body

<OauthIdpResponseBody idp_lowercase="twitch"
                      idp_type="Twitch"
                      idp_display_name="Twitch"
                      idp_linking_strategy="CreatePendingLink"
                      idp_since="12800"
                      idp_id="bf4cf83f-e824-42d7-b4a3-5b10847a66b2" />
