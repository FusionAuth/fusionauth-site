The Identity Provider connection testing API allows you to test an Identity Provider connection, even when disabled, to ensure that the configuration is correct and that FusionAuth can connect to the 3rd party provider. This API is useful for troubleshooting connectivity issues with an Identity Provider.

<Aside type="note">
    This API does not create or update users or registrations, or generate an authorization code or tokens.
</Aside>



## Start an Identity Provider Connection Test

### Request

Start a connection test for a given Identity Provider and Tenant.

<API method="POST" uri="/api/identity-provider/test" authentication={["api-key"]} title="Start an Identity Provider Connection Test for a given IdP and Tenant "/>

#### Request Body

<APIBlock>
  <APIField name="identityProviderId" type="UUID" required>
    The unique Id of the Identity Provider to test.
  </APIField>
  <APIField name="tenantId" type="UUID" required>
    The unique Id of the Tenant for the test.
  </APIField>
</APIBlock>

<JSON title="Example Identity Provider Test Request JSON" src="identity-providers/idp-test-request.json" />

### Response

<StandardPostResponseCodes never_search_error />

#### Response Body

<APIBlock>
  <APIField name="connectionTestId" type="String">
    The unique Id of the connection test.
  </APIField>
</APIBlock>

<JSON title="Example Identity Provider Test Response JSON" src="identity-providers/idp-test-response.json" />

<Aside type="note">
    The returned `connectionTestId` is temporary and expires after the Tenant-configured external identifier TTL. Configure this value using `tenant.externalIdentifierConfiguration.identityProviderConnectionTestTimeToLiveInSeconds` (default `1800` seconds).
</Aside>

## Retrieve Identity Provider Connection Test Results

### Request

Retrieve the results of a connection test by its Id.

<API method="GET" uri="/api/identity-provider/test?connectionTestId={connectionTestId}" authentication={["api-key"]} title="Retrieve Identity Provider Connection Test Results"/>
#### Query Parameters
<APIBlock>
  <APIField name="connectionTestId" type="String" required>
    The connection test Id returned by the Start Identity Provider Connection Test API.
  </APIField>
</APIBlock>

### Response
<StandardGetResponseCodes never_search_error />
#### Response Body

<APIBlock>
  <APIField name="result.success" type="Boolean">
    `true` when the test has at least one step and every step succeeded.
  </APIField>
  <APIField name="result.startInstant" type="DateTime">
    The instant the test began.
  </APIField>
  <APIField name="result.identityProviderId" type="UUID">
    The Id of the Identity Provider that FusionAuth tested.
  </APIField>
  <APIField name="result.identityProviderUserId" type="String" optional>
    The third-party user Id that FusionAuth resolved during the test, when available.
  </APIField>
  <APIField name="result.email" type="String" optional>
    The reconciled email address, when available.
  </APIField>
  <APIField name="result.username" type="String" optional>
    The reconciled username, when available.
  </APIField>
  <APIField name="result.steps" type="Array<Object>">
    The trace steps from the test, in order.
  </APIField>
  <APIField name="result.steps[].title" type="String">
    The title of the step.
  </APIField>
  <APIField name="result.steps[].success" type="Boolean">
    `true` when the step succeeded.
  </APIField>
  <APIField name="result.steps[].detail" type="String">
    More detail about the step.
  </APIField>
</APIBlock>
