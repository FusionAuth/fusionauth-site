<PlanBlurb plan="starter" />

<AvailableSince since="1.28.0"/>

The Sony PlayStation Network identity provider type will use the Sony OAuth v2.0 login API. It will also provide a <Breadcrumb>Login with Playstation Network</Breadcrumb> button on FusionAuth's login page that will direct a user to the Sony login page.

This identity provider will call Sony's API to load the user's `email` and `online_id` and use those as `email` and `username` to lookup or create a user in FusionAuth depending on the linking strategy configured for this identity provider. Additional claims returned by Sony PlayStation Network can be used to reconcile the user to FusionAuth by using a Sony PlayStation Network Reconcile Lambda.

## Create Sony PlayStation Network Identity Provider

### Request

Create the Sony PlayStation Network Identity Provider with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/identity-provider" authentication={["api-key"]} title="Create a Sony PlayStation Network Identity Provider using a randomly generated Id"/>

<API method="POST" uri="/api/identity-provider/{identityProviderId}" authentication={["api-key"]} title="Create a Sony PlayStation Network Identity Provider with the provided unique Id"/>

The **type** in the request JSON indicates this is the Sony PlayStation Network Identity Provider type.

#### Path Parameters

<APIBlock>
  <APIField name="identityProviderId" type="UUID" optional immutable defaults="secure random UUID" since="1.61.0">
    The Id to use for the new Identity Provider. If an Id is not provided, a secure random UUID is generated. If neither an Id nor **identityProvider.name** are provided, the legacy fixed Sony PlayStation Network IdP Id `7764b5c7-165b-4e7e-94aa-02ebe2a0a5fb` will be used.
  </APIField>
</APIBlock>

##### Request Body

<OauthIdpRequestBody idp_lowercase="sonypsn"
                     idp_type="SonyPSN"
                     idp_display_name="Sony PlayStation Network"
                     idp_linking_strategy="CreatePendingLink"
                     idp_since="12800" />

### Response

<StandardPostResponseCodes conflict_detection never_search_error />

#### Response Body

<OauthIdpResponseBody idp_lowercase="sonypsn"
                      idp_type="SonyPSN"
                      idp_display_name="Sony PlayStation Network"
                      idp_linking_strategy="CreatePendingLink"
                      idp_since="12800"
                      idp_id="7764b5c7-165b-4e7e-94aa-02ebe2a0a5fb" />
