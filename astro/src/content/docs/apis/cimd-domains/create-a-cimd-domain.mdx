<PlanBlurb plan="enterprise" />

<AvailableSince since="1.XX.0"/>

This API is used to create a [CIMD domain](/docs/get-started/core-concepts/cimd-domains). Specifying an Id on the URI will instruct FusionAuth to use that Id when creating the CIMD domain. Otherwise, FusionAuth will generate an Id for the CIMD domain.

## Request

<API method="POST" uri="/api/cimd/domain" authentication={["api-key"]} title="Create a CIMD Domain with a randomly generated Id"/>

<API method="POST" uri="/api/cimd/domain/{cimdDomainId}" authentication={["api-key"]} title="Create a CIMD Domain with the provided unique Id"/>

#### Request Headers

<XFusionauthTenantIdHeaderCreateOperation />

### Request Parameters

<APIBlock>
  <APIField name="cimdDomainId" type="UUID" optional immutable defaults="a generated UUID">
    The Id to use for the new CIMD domain, which must be unique across all Tenants. If not specified a secure random UUID will be generated.
  </APIField>
</APIBlock>

#### Request Body

<CimdDomainRequestBody is_create />

## Response

The response for this API contains the information for the CIMD domain that was created.

<StandardPostResponseCodes never_search_error />
