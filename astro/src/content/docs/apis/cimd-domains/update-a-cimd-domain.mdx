<Aside type="note">
You can't update a CIMD domain's custom OAuth scopes via this API. This prevents you from accidentally removing all the scopes of a CIMD domain. Any value supplied for **domain.scopes** is ignored.

To create, update, or remove a custom OAuth scope on a CIMD domain, call one of these APIs:

* [Create a CIMD Domain OAuth Scope](/docs/apis/cimd-domain-scopes#create-a-cimd-domain-oauth-scope)
* [Update a CIMD Domain OAuth Scope](/docs/apis/cimd-domain-scopes#update-a-cimd-domain-oauth-scope)
* [Delete a CIMD Domain OAuth Scope](/docs/apis/cimd-domain-scopes#delete-a-cimd-domain-oauth-scope)

</Aside>
