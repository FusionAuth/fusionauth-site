<AvailableSince since="1.XX.0"/>

This API is used to delete a [CIMD domain](/docs/get-started/core-concepts/cimd-domains). You must specify the Id of the CIMD domain on the URI.

<Aside type="caution">
This is always a permanent, hard delete and cannot be reversed. There is no soft delete for a CIMD domain.

Deleting a CIMD domain also removes every client that registered through the domain and revokes those clients' refresh tokens. Clients from this origin will no longer be able to register or authenticate until you create the domain again.
</Aside>

## Request

<API method="DELETE" uri="/api/cimd/domain/{cimdDomainId}" authentication={["api-key"]} title="Permanently delete a CIMD Domain. This operation cannot be reversed."/>

#### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

### Request Parameters

<APIBlock>
  <APIField name="cimdDomainId" type="UUID" required>
    The Id of the CIMD domain to delete.
  </APIField>
</APIBlock>

## Response

This API does not return a JSON response body.
