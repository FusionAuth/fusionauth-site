This API is used to search for [CIMD domains](/docs/get-started/core-concepts/cimd-domains) and may be called using the `GET` or `POST` HTTP methods. Examples of each are provided below. The `POST` method is provided to allow for a richer request object without worrying about exceeding the maximum length of a URL. Calling this API with either the `GET` or `POST` HTTP method will provide the same search results given the same query parameters.

<Aside type="note">
Unlike the other CIMD domain APIs, this operation does not require the CIMD feature to be enabled on your license. You can always search your existing CIMD domain configuration.
</Aside>
