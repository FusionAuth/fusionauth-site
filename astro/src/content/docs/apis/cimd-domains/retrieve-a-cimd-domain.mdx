<AvailableSince since="1.XX.0"/>

This API is used to retrieve one or all of the configured [CIMD domains](/docs/get-started/core-concepts/cimd-domains). Specifying an Id on the URI will retrieve a single CIMD domain. Leaving off the Id will retrieve all of the CIMD domains.

<Aside type="note">
Unlike the other CIMD domain APIs, this operation does not require the CIMD feature to be enabled on your license. You can always read your existing CIMD domain configuration.
</Aside>

## Response

The response for this API contains either a single CIMD domain or all of the CIMD domains. When you call this API with an Id the response will contain just that CIMD domain. When you call this API without an Id the response will contain all of the CIMD domains. If the request contains an `X-FusionAuth-TenantId` header, or the supplied API key is scoped to a specific Tenant, the request is limited to that Tenant's CIMD domains.
