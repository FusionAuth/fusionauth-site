This page contains the APIs that are used to authenticate users without passwords using one-time passwords.

You also may find the [One-Time Passwords documentation](/docs/lifecycle/authenticate-users/one-time-passwords/) helpful.

<Aside type="tip">
Prior to version `1.41.0`, one-time passwords were the only form of passwordless authentication supported by FusionAuth.

Therefore the user interface and API use the term `passwordless`, even though versions `1.41.0` and beyond support multiple kinds of passwordless authentication, including [Passkeys](/docs/lifecycle/authenticate-users/passkeys/).
</Aside>
