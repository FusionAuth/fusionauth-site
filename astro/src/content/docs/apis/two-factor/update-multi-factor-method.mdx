This API updates the display name of a single configured multi-factor method for a User.

This operation only updates the method display name. It does not modify the MFA method type or delivery configuration.

## Request

Update the display name of a multi-factor method by providing the User Id and the method Id.

<API method="PUT" uri="/api/user/two-factor/{userId}?methodId={methodId}" authentication={["api-key"]} title="Update a single multi-factor method by User Id"/>

<AvailableSince since="1.68.0"/>

### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

### Path Parameters

<APIBlock>
  <APIField name="userId" type="UUID" required>
    The Id of the User for whom to update Multi-Factor authentication.
  </APIField>
</APIBlock>

### Query Parameters

<APIBlock>
  <APIField name="methodId" type="String" required>
    The Id of the multi-factor method to update.
  </APIField>
</APIBlock>

### Request Body

<APIBlock>
  <APIField name="name" type="String" optional>
    The display name for the configured multi-factor method.

    The maximum length is 256 characters.

    If omitted, the method name will be cleared.
  </APIField>
</APIBlock>
