FusionAuth writes a Token Exchange audit log entry for every [token exchange](/docs/lifecycle/authenticate-users/oauth/token-exchange) attempt, successful or not. This API searches and paginates through those entries. To retrieve the chain of exchanges behind a single issued token, use the [Retrieve a Token Exchange Chain](/docs/apis/system/retrieve-a-token-exchange-chain) API.

FusionAuth deletes entries after the number of days set in **`systemConfiguration.tokenExchangeAuditLogConfiguration.numberOfDaysToRetain`** in the [System Configuration](/docs/apis/system/update-the-system-configuration). The default is 7 days.

## Request

<API method="GET" uri="/api/system/token-exchange-audit-log/search?exchangerClientId={exchangerClientId}&outcome={outcome}&start={start}&end={end}" authentication={["api-key"]} title="Searches the Token Exchange audit log using the given search criteria"/>

When calling the API using a `GET` request, send the search criteria as query parameters. The example URL doesn't show every parameter, but any of the documented query parameters can be added to the URL.

Use a `POST` request to send the search criteria in a JSON request body instead.

<API method="POST" uri="/api/system/token-exchange-audit-log/search" authentication={["api-key"]} title="Searches the Token Exchange audit log using the given search criteria"/>

### Query Parameters

<APIBlock>
  <APIField name="end" type="Long" optional>
    The end [instant](/docs/reference/data-types#instants) of the date/time range to search within.
  </APIField>
  <APIField name="exchangerClientId" type="UUID" optional>
    The Id of the exchanger Entity. Despite the name, this value is the Entity's Id, not its OAuth client Id.
  </APIField>
  <APIField name="numberOfResults" type="Integer" optional defaults="25">
    The number of results to return from the search.
  </APIField>
  <APIField name="orderBy" type="String" optional defaults="insertInstant DESC, eventId DESC">
    The column to order the search results on plus the order direction. The possible columns are `eventId` and `insertInstant`. For example, `insertInstant ASC` returns the oldest entries first.
  </APIField>
  <APIField name="outcome" type="String" optional>
    The outcome of the exchange attempt. See **`tokenExchangeAuditLogs[x].outcome`** in the [response body](#response-body) for the possible values.
  </APIField>
  <APIField name="start" type="Long" optional>
    The start [instant](/docs/reference/data-types#instants) of the date/time range to search within.
  </APIField>
  <APIField name="startRow" type="Integer" optional defaults="0">
    The offset row to return results from. If the search has 200 records in it and this is 50, it starts with row 50.
  </APIField>
  <APIField name="tenantId" type="UUID" optional>
    Restricts the results to entries belonging to the given Tenant. This parameter is overridden if the request contains an `X-FusionAuth-TenantId` header, or if the API key is scoped to a specific Tenant.
  </APIField>
</APIBlock>

### Request Body

The request body accepts the same fields as the query parameters, nested in a **`search`** object. For example, **`search.outcome`** corresponds to the **outcome** query parameter.

```json title="Example JSON Request"
{
  "search": {
    "exchangerClientId": "4b8f3b1a-6c2d-4f0e-9a7b-2d1c3e4f5a6b",
    "outcome": "POLICY_DENIED",
    "start": 1792592000000,
    "end": 1792678400000,
    "numberOfResults": 50
  }
}
```

## Response

The response for this API contains the entries matching the search criteria in reverse chronological order.
