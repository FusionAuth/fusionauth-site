<PlanBlurbApi plan="enterprise" feature="Token Exchange" />

<AvailableSince since="1.70.0"/>

An exchanged token can itself be exchanged again. This API returns the entry for the exchange that issued a token, followed by the entries for each earlier exchange in its chain. The entries come from the Token Exchange audit log. To search the audit log, use the [Search the Token Exchange Audit Log](/docs/apis/system/search-the-token-exchange-audit-log) API.

## Request

<API method="GET" uri="/api/system/token-exchange-audit-log/chain?issuedTokenJti={issuedTokenJti}" authentication={["api-key"]} title="Retrieve the exchange chain for an issued token"/>

### Query Parameters

<APIBlock>
  <APIField name="issuedTokenJti" type="String" required>
    The `jti` claim of the issued token.
  </APIField>
  <APIField name="tenantId" type="UUID" optional>
    Restricts the chain to entries belonging to the given Tenant. This parameter is overridden if the request contains an `X-FusionAuth-TenantId` header, or if the API key is scoped to a specific Tenant. Without a Tenant, the chain includes entries from every Tenant.
  </APIField>
</APIBlock>

## Response

<StandardGetResponseCodes success_message="The request was successful. The response contains the exchange chain." missing_message="No retained entry issued a token with the given jti, or the entry belongs to a different Tenant." />

### Response Body

<APIBlock>
  <APIField name="tokenExchangeAuditLogs" type="Array">
    The entries in the chain, starting with the exchange that issued the requested token and ending with the first exchange.

    The chain stops early when an earlier entry is no longer retained, or when a subject token wasn't itself issued through token exchange.
  </APIField>
  <TokenExchangeAuditLogResponseBody base_field_name="tokenExchangeAuditLogs[x]" />
</APIBlock>
