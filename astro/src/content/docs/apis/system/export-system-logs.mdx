This API is used to export the System Logs, the response will be a compressed zip archive containing the logs from the configured log directory. When running FusionAuth on Docker or other container service where logs are written to `stdout` and not written to the file system, this API will return an empty archive.

## Request

<API method="GET" uri="/api/system/log/export?dateTimeSecondsFormat={dateTimeSecondsFormat}&includeArchived=true&zoneId={zoneId}" authentication={["global-api-key"]} title="Export the System Logs"/>

Use a `POST` request instead to send the export criteria in a JSON request body.

<API method="POST" uri="/api/system/log/export" authentication={["global-api-key"]} title="Export the System Logs"/>
