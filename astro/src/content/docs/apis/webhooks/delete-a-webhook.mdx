This API is used to delete a Webhook.


## Request

<API method="DELETE" uri="/api/webhook/{webhookId}" authentication={["global-api-key"]} title="Delete a Webhook by Id"/>

### Path Parameters

<APIBlock>
  <APIField name="webhookId" type="UUID" required>
    The Id of the Webhook to delete.
  </APIField>
</APIBlock>
