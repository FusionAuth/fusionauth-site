<Aside type="note">
Starting in version `1.70.0`, this endpoint also accepts the Tenant Id as a URL segment (e.g. <code>{props.endpoint}/30663132-6464-6665-3032-326466613934</code>). The [OpenID Configuration](/docs/apis/oauth/openid-configuration) endpoint advertises this form. When a request includes both the URL segment and a **tenantId** parameter, FusionAuth uses the **tenantId** parameter.
</Aside>
