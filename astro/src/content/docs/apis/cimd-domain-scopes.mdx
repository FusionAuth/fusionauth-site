<PlanBlurb plan="enterprise" />

<AvailableSince since="1.XX.0"/>

This page contains the APIs for managing the custom OAuth scopes of a [CIMD domain](/docs/get-started/core-concepts/cimd-domains). These scopes are requestable by any client that registers through the domain, in addition to the standard OpenID Connect scopes enabled by the domain's **providedScopePolicy**.

A CIMD domain's initial scopes may be supplied when [creating the domain](/docs/apis/cimd-domains/create-a-cimd-domain). Every change after that goes through the APIs on this page — the [Update a CIMD Domain](/docs/apis/cimd-domains/update-a-cimd-domain) API ignores the **domain.scopes** field.

<Aside type="note">
There is no API to retrieve all of a CIMD domain's scopes as a collection. The full `scopes` list is returned on the domain itself by the [Retrieve a CIMD Domain](/docs/apis/cimd-domains/retrieve-a-cimd-domain) API.
</Aside>

## Create a CIMD Domain OAuth Scope

This API is used to create a custom OAuth scope for a CIMD domain. Specifying an Id on the URI will instruct FusionAuth to use that Id when creating the OAuth scope. Otherwise, FusionAuth will generate an Id for the OAuth scope.

### Request

<API method="POST" uri="/api/cimd/domain/{cimdDomainId}/scope" authentication={["api-key"]} title="Create a CIMD Domain OAuth Scope with a randomly generated Id" />

<API method="POST" uri="/api/cimd/domain/{cimdDomainId}/scope/{scopeId}" authentication={["api-key"]} title="Create a CIMD Domain OAuth Scope with a provided unique Id" />

#### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

#### Request Parameters

<APIBlock>
  <APIField name="cimdDomainId" type="UUID" required>
    The Id of the CIMD domain.
  </APIField>
  <APIField name="scopeId" type="UUID" optional immutable defaults="secure random UUID">
    The Id to use for the new OAuth scope. If not specified a secure random UUID will be generated.
  </APIField>
</APIBlock>

##### Request Body

<ScopeRequestBody json_dir="cimd-domain-scopes" />

### Response

The response for this API contains the information for the OAuth scope that was created.

<StandardPostResponseCodes never_search_error />

#### Response Body

<ScopeResponseBody is_cimd json_dir="cimd-domain-scopes" />

## Retrieve a CIMD Domain OAuth Scope

This API is used to retrieve a single custom OAuth scope for a CIMD domain by unique Id.

<Aside type="note">
Unlike the other CIMD domain OAuth scope APIs, this operation does not require the CIMD feature to be enabled on your license. You can always read your existing scope configuration.
</Aside>

### Request

<API method="GET" uri="/api/cimd/domain/{cimdDomainId}/scope/{scopeId}" authentication={["api-key"]} title="Retrieve a CIMD Domain OAuth Scope by Id" />

#### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

#### Request Parameters

<APIBlock>
  <APIField name="cimdDomainId" type="UUID" required>
    The Id of the CIMD domain.
  </APIField>
  <APIField name="scopeId" type="UUID" required>
    The Id of the OAuth scope to retrieve.
  </APIField>
</APIBlock>

### Response

The response for this API contains a single OAuth scope.

<StandardGetResponseCodes never_search_error />

#### Response Body

<ScopeResponseBody is_cimd json_dir="cimd-domain-scopes" />

## Delete a CIMD Domain OAuth Scope

This API is used to permanently delete a custom OAuth scope from a CIMD domain. You must specify the Id of the CIMD domain and the Id of the OAuth scope on the URI.

<Aside type="caution">
This is a hard delete and cannot be reversed. OAuth workflows that continue to request the deleted scope will fail, because a CIMD domain always rejects unknown scopes.
</Aside>

### Request

<API method="DELETE" uri="/api/cimd/domain/{cimdDomainId}/scope/{scopeId}" authentication={["api-key"]} title="Delete a CIMD Domain OAuth Scope by Id" />

#### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

#### Request Parameters

<APIBlock>
  <APIField name="cimdDomainId" type="UUID" required>
    The Id of the CIMD domain.
  </APIField>
  <APIField name="scopeId" type="UUID" required>
    The Id of the OAuth scope to delete.
  </APIField>
</APIBlock>

### Response

This API does not return a JSON response body.

<StandardDeleteResponseCodes never_search_error />
