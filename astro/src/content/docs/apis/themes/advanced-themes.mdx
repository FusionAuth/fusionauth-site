<Aside type="version">
Available since version `1.8.0`
</Aside>

UI login themes can be configured to enable custom branding for your FusionAuth login workflow. Themes are configured per-Tenant or optionally by Application. This page assumes that the **`theme.type`** of your theme is `advanced`; for a simple theme, see [Simple Themes APIs](/docs/apis/themes/simple-themes).

<Aside type="caution">
Theme templates have access to sensitive configuration data including SSO cookies, tenant settings, JWT configuration, SMTP credentials, and user information. Only use themes from trusted sources and review all custom theme code before deployment.
</Aside>

## Create an Advanced Theme

Use this API to create a new Theme.

### Request

<API method="POST" uri="/api/theme" authentication={["global-api-key"]} title="Create a new Theme with a randomly generated Id"/>

<API method="POST" uri="/api/theme/{themeId}" authentication={["global-api-key"]} title="Create a Theme with the provided unique Id"/>

#### Request Parameters

<APIBlock>
  <APIField name="themeId" type="UUID" optional defaults="secure random UUID">
    The Id to use for the new Theme. If not specified a secure random UUID will be generated.
  </APIField>
</APIBlock>

#### Request Body

You can create a new theme in one of the following ways:

* make a copy of an existing theme as a starting point
* specify the entire theme in your request body

## Retrieve an Advanced Theme

This API is used to retrieve a single Theme by unique Id or all of the Themes.

### Request

<API method="GET" uri="/api/theme" authentication={["global-api-key"]} title="Retrieve all of the Themes"/>

<API method="GET" uri="/api/theme/{themeId}" authentication={["global-api-key"]} title="Retrieve a Theme by Id"/>

#### Request Parameters

<APIBlock>
  <APIField name="themeId" type="UUID" required>
    The unique Id of the Theme to retrieve.
  </APIField>
</APIBlock>

### Response

The response for this API contains either a single Theme or all of the Themes. When you call this API with an Id the response will contain a single Theme. When you call this API without an Id the response will contain all of the themes. Both response types are defined below along with an example JSON response.

## Search for Themes

<Aside type="version">
This API has been available since `1.45.0`
</Aside>

This API is used to search for Themes and may be called using the `GET` or `POST` HTTP methods. Examples of each are provided below. The `POST` method is provided to allow for a richer request object without worrying about exceeding the maximum length of a URL. Calling this API with either the `GET` or `POST` HTTP method will provide the same search results given the same query parameters.

### Request

<API method="GET" uri="/api/theme/search?name={name}" authentication={["global-api-key"]} title="Search for Themes"/>

Alternatively, make a `POST` request to send the search criteria in a JSON request body:

<API method="POST" uri="/api/theme/search" authentication={["global-api-key"]} title="Search for Themes"/>
