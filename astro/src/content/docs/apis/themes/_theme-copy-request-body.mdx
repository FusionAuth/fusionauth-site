<Aside type="caution" title="A copy replaces theme content from the request">
When the request includes **`sourceThemeId`**, FusionAuth reads only the fields listed below. FusionAuth replaces any messages, templates, stylesheet, or variables in the request with the values from the source Theme, and returns no error. To change those values on the new Theme, copy the Theme first, then send a `PATCH` or `PUT` request with the new Theme Id.
</Aside>

<APIBlock>
  <APIField name="sourceThemeId" type="UUID" required>
    The Id of an existing Theme to copy. FusionAuth copies the **`defaultMessages`** and **`localizedMessages`** from the source Theme to the new Theme.

    When the source Theme is an advanced Theme, FusionAuth also copies the **`templates`** and **`stylesheet`**.

    When the source Theme is a simple Theme, FusionAuth also copies the **`variables`**, and the new Theme is a simple Theme.
  </APIField>
  <APIField name="theme.name" type="String" required>
    A unique name for the Theme.
  </APIField>
  <APIField name="theme.data" type="Object" optional>
    An object that can hold any information about the Theme that should be persisted.
  </APIField>
</APIBlock>
