<APIField name="eventInfo" type="Object" optional>
  Information about the request. FusionAuth adds the information to the events the request triggers, as **`event.info`**. For more information, see [Pass Context From API Requests to Webhooks](/docs/events/webhooks/pass-request-context).
</APIField>
<APIField name="eventInfo.data" type="Object" optional>
  An object that holds any JSON you choose, such as a trace Id. FusionAuth copies the object to **`event.info.data`** without changes.
</APIField>
<APIField name="eventInfo.deviceDescription" type="String" optional>
  A description of the end user's device.{(props.login_api || props.login_fallback) && <> When this value is omitted, FusionAuth uses <strong><code>metaData.device.description</code></strong>.</>}
</APIField>
<APIField name="eventInfo.deviceName" type="String" optional>

</APIField>
<APIField name="eventInfo.deviceType" type="String" optional>

</APIField>
