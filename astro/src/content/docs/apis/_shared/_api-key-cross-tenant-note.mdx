Tenant-scoped keys have read-only access to entities that are shared between tenants. You can further limit these API keys by specifying required endpoints, permissions, and a tenant.

Use care when scoping an API key to the `Default` tenant. These API keys can make changes to User Registrations via the [User Registration API](/docs/apis/registrations) for the FusionAuth Admin application, which can then allow broadening the effective scope of the key to other tenants.
