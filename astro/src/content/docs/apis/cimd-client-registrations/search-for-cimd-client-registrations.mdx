<AvailableSince since="1.70.0"/>

This API is used to search for CIMD client registrations and may be called using the `GET` or `POST` HTTP methods. Examples of each are provided below. The `POST` method is provided to allow for a richer request object without worrying about exceeding the maximum length of a URL. Calling this API with either the `GET` or `POST` HTTP method will provide the same search results given the same query parameters.

To find the registration for a specific client, search by its `client_id` URL with the **clientId** parameter.

<Aside type="note">
Unlike deleting a registration, this operation does not require the CIMD feature to be enabled on your license.
</Aside>

The response for this API contains the CIMD client registrations matching the search criteria in paginated format.
