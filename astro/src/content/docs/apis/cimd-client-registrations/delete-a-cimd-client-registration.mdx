<AvailableSince since="1.70.0"/>

This API is used to delete a CIMD client registration. You must specify the Id of the registration on the URI.

<Aside type="caution">
This is always a permanent, hard delete and cannot be reversed. Deleting a registration also deletes the client's refresh tokens.

Deleting a registration doesn't block the client. The next time a user logs in with the client, FusionAuth fetches its metadata document and registers it again. To keep a client out, set the `decision` to `DENY` for it in the CIMD domain's [registration lambda](/docs/extend/code/lambdas/cimd-client-registration). See [Removing A CIMD Client](/docs/lifecycle/authenticate-users/oauth/client-registration#removing-a-cimd-client).
</Aside>

<API method="DELETE" uri="/api/cimd/registration/{registrationId}" authentication={["api-key"]} title="Permanently delete a CIMD Client Registration. This operation cannot be reversed."/>
