<AvailableSince since="1.70.0"/>

This API is used to retrieve a single CIMD client registration by Id. FusionAuth creates a registration the first time a [CIMD client](/docs/lifecycle/authenticate-users/oauth/client-registration#client-id-metadata-documents) logs in. To find a registration Id, use the [Search for CIMD Client Registrations API](/docs/apis/cimd-client-registrations/search-for-cimd-client-registrations).

<Aside type="note">
Unlike deleting a registration, this operation does not require the CIMD feature to be enabled on your license.
</Aside>

## Request

<API method="GET" uri="/api/cimd/registration/{registrationId}" authentication={["api-key"]} title="Retrieve a CIMD Client Registration by Id"/>

#### Request Headers

<XFusionauthTenantIdHeaderScopedOperation />

### Request Parameters

<APIBlock>
  <APIField name="registrationId" type="UUID" required>
    The Id of the CIMD client registration to retrieve.
  </APIField>
</APIBlock>

## Response

If the request contains an `X-FusionAuth-TenantId` header, or the supplied API key is scoped to a specific Tenant, FusionAuth only returns a registration that belongs to that Tenant.
