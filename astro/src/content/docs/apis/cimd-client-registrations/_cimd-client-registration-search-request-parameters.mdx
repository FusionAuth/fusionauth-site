<APIBlock>
  <APIField name={ props.parameter_prefix + "cimdDomainId" } type="UUID" optional>
    Restricts the results to registrations created through the given [CIMD domain](/docs/get-started/core-concepts/types/cimd-domains).
  </APIField>
  <APIField name={ props.parameter_prefix + "clientId" } type="String" optional>
    The client's `client_id` URL. This must be an exact match. Wildcards aren't supported.
  </APIField>
  <APIField name={ props.parameter_prefix + "numberOfResults" } type="Integer" optional defaults="25">
    The number of results to return from the search.
  </APIField>
  <APIField name={ props.parameter_prefix + "orderBy" } type="String" optional defaults="insertInstant DESC">
    The database field to order the search results as well as an order direction.

    The possible values are:

    * `id` - the unique Id of the registration
    * `insertInstant` - the [instant](/docs/reference/data-types#instants) when the registration was created

    The order direction is optional. Possible values of the order direction are `ASC` or `DESC`. If omitted, the default sort order is `ASC`.

    For example, to order the results by the insert instant in an ascending order, use `insertInstant ASC`.
  </APIField>
  <APIField name={ props.parameter_prefix + "startRow" } type="Integer" optional defaults="0">
    The offset into the total results. In order to paginate the results, increment this value by the **numberOfResults** for subsequent requests.

    For example, if the total search results are greater than the page size designated by **numberOfResults**, set this value to `25` to retrieve results 26 through 50, assuming the default page size.
  </APIField>
  <APIField name={ props.parameter_prefix + "tenantId" } type="UUID" optional>
    Restricts the results to registrations belonging to the given Tenant. This parameter will be overridden if the request contains an `X-FusionAuth-TenantId` header, or if the supplied API key is scoped to a specific Tenant.
  </APIField>
</APIBlock>
