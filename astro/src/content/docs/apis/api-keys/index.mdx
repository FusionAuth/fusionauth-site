This page describes the API for managing API keys, including creating, retrieving, updating and deleting them.

Most FusionAuth APIs are secured using an API key. This API can only be accessed using an API key that has a **keyManager** attribute of `true`, which can only be configured through the administrative user interface. In order to retrieve, update or delete an API key, an API key with equal or greater permissions must be used. A "tenant-scoped" API key can retrieve, create, update or delete an API key for the same tenant.

To get started scripting the creation of API keys, follow these steps:

1. [Create an API key](/docs/apis/authentication#managing-api-keys) with the [**Allow this key to manage other keys**](#the-key-manager-setting) setting enabled.
   * This can only be done using the administrative user interface <Breadcrumb>Settings -> API Keys -> Add</Breadcrumb> or [Kickstart](/docs/get-started/download-and-install/development/kickstart), not this API.
2. Use that key to [authenticate](/docs/apis/authentication) requests to this API.
3. Call this API to create, retrieve, update or delete additional API keys as needed.

Please refer to the [Authentication](/docs/apis/authentication#) document for more details about using API keys.

## The Key Manager Setting

<Aside type="note">
This API can only be used by API keys with the **Allow this key to manage other keys** setting enabled.
</Aside>

Below is an image of an API key being created in the administrative user interface with **Allow this key to manage other keys** enabled:

![The Key Manager Setting](/img/docs/apis/api-key-api-key-manager.png)

For security purposes, the **Allow this key to manage other keys** setting may be modified only using the administrative user interface or Kickstart. It can't be changed using this API.
