This API is used to create a new API Key. An API key with key manager permission set to `true` can create keys. An API key that is tenant scoped can create another key for the same tenant.

A key with key manager permissions cannot be created using this API. Only through the Admin UI or [Kickstart](/docs/get-started/develop/kickstart) can you create such a key.

## Request

This API supports two ways to create a Key, either as a brand new Key or by copying an existing Key's permissions.

### Create from Scratch

Use a randomly generated Id in most cases. Supply your own Id if you need a predictable identifier for the key.

<API method="POST" uri="/api/api-key" authentication={["api-key"]} title="Create a new Key with a randomly generated Id"/>

<API method="POST" uri="/api/api-key/{apiKeyId}" authentication={["api-key"]} title="Create a new Key with the provided unique Id"/>

#### Path Parameters

<APIBlock>
  <APIField name="apiKeyId" type="UUID" optional immutable defaults="a generated UUID">
    The unique Id of the API Key to create. If not specified a secure random UUID will be generated.
  </APIField>
</APIBlock>

### Copy Another API Key

To copy an existing key's permissions into a new key, use one of the following instead.

## Response

The response for this API contains the Key that was created. The **key** field is the value you'll supply in the `Authorization` header for subsequent requests.
