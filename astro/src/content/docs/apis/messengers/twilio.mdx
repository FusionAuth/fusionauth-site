The following APIs are provided to manage Twilio Messengers.


## Create the Twilio Messenger

### Request

<API method="POST" uri="/api/messenger" authentication={["global-api-key"]} title="Create a Twilio Messenger with a randomly generated Id."/>

<API method="POST" uri="/api/messenger/{messengerId}" authentication={["global-api-key"]} title="Create a Twilio Messenger with the provided unique Id."/>

The **type** in the request JSON is used to determine that you are creating the Twilio Messenger.

#### Request Parameters

<APIBlock>
  <APIField name="messengerId" type="UUID" optional defaults="secure random UUID">
    The Id to use for the new Messenger. If not specified a secure random UUID will be generated.
  </APIField>
</APIBlock>

##### Request Body

<TwilioRequestBody />

### Response

<StandardPostResponseCodes never_search_error />

#### Response Body

<TwilioResponseBody />
