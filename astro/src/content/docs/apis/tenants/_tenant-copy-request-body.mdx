<Aside type="caution" title="A copy ignores most request fields">
When the request includes **`sourceTenantId`**, FusionAuth reads only the fields listed below. FusionAuth ignores every other field in the **`tenant`** object, such as **`tenant.issuer`**, and returns no error. To change other values on the new Tenant, copy the Tenant first, then send a request to the [Update a Tenant](/docs/apis/tenants/update-a-tenant) API.
</Aside>

<APIBlock>
  <APIField name="sourceTenantId" type="UUID" required>
    The Id of an existing Tenant to copy. FusionAuth copies every configuration value from the source Tenant to the new Tenant, except the name and the Id. FusionAuth does not copy Webhook associations from the source Tenant.
  </APIField>
  <APIField name="tenant.name" type="String" required>
    The unique name of the new Tenant.
  </APIField>
  <APIField name="webhookIds" type="Array<UUID>" optional since="1.37.0">
    An array of Webhook Ids. For Webhooks that are not already configured for All Tenants, specifying an Id on this request will indicate the associated Webhook should handle events for the new Tenant.
  </APIField>
</APIBlock>
