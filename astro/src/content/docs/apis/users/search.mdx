Use this API to search for Users. You can call the API with either the `GET` or the `POST` HTTP method. Both methods return the same results for the same search parameters. Use `POST` when the search parameters might exceed the maximum length of a URL.

## Request

The available search parameters and their behavior depend on the search engine. For more information, see [Search Engines](/docs/users/search).

Every request must include one of the following parameters:

* **ids**
* **queryString**
* **query**, with the Elasticsearch search engine only
* **nextResults**, with the Elasticsearch search engine only

When a request includes none of these parameters, FusionAuth returns a `400` response. To list all Users, set **queryString** to `*`, and page through the results with **startRow** and **numberOfResults**:

```http
GET /api/user/search?queryString=*&numberOfResults=25&startRow=0
```
