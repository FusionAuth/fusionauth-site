This API is used to create a new User.

## Request

Create a User with either a randomly generated Id or one you provide on the URI.

<API method="POST" uri="/api/user" authentication={["api-key"]} title="Create a User with a randomly generated Id"/>

<API method="POST" uri="/api/user/{userId}" authentication={["api-key"]} title="Create a User with the provided unique Id"/>

### Request Headers

<XFusionauthTenantIdHeaderCreateOperation />

### Path Parameters

<APIBlock>
  <APIField name="userId" type="UUID" optional immutable defaults="secure random UUID">
    The Id to use for the new User. If not specified a secure random UUID will be generated.
  </APIField>
</APIBlock>

### Request Body

<UserRequestBody http_method="POST" />

## Response

The response for this API contains the User that was just created, including its `id`. The password, salt and other sensitive fields will not be returned on the API response.

To let this User log into an Application, register them next using the [Create a User Registration](/docs/apis/registrations/create-a-user-registration-for-an-existing-user) API, or use [Create a User and Registration (combined)](/docs/apis/registrations/create-a-user-and-registration-combined) to do both in a single request.

<StandardPostResponseCodes webhook_event create_user />

### Response Body

<UserResponseBody create_user />
