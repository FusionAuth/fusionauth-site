Use this API to refresh the User search index, so that changes made just before the request appear in search results right away. The search engine refreshes the index about once a second on its own, so most production code doesn't need this API. Tests that change a User and then search for the User can call this API between the two requests. This API applies only to the Elasticsearch search engine. For more information, see [Index Delay](/docs/users/search#index-delay).

## Request

Issue the flush with a single request that takes no parameters.

<API method="PUT" uri="/api/user/search" authentication={["api-key"]} title="Flushes the Search Engine"/>
