## Request

Use this API before you [change a user's password](/docs/apis/users/change-password). The API checks whether the password change requires an MFA `trustToken`. You can identify the user in the following ways:

* With a `changePasswordId`, without authentication.
* With a JWT.
* With a `loginId` and an API key.

In `1.62.0` and later, an [MFA Requirement Lambda](/docs/lambdas/login/mfa-requirement) can read the IP address and device metadata on the request. The lambda can use the values to decide whether to require MFA.

### Change Password Id

With a `changePasswordId`, the API also checks that the `changePasswordId` exists and hasn't expired. The [Start Forgot Password API](/docs/apis/users/forgot-password) and the Forgot Password workflow on the FusionAuth hosted login pages create the `changePasswordId`. Call this API when the user opens the link in the forgot password message, before you show the new password form. The check doesn't use up the `changePasswordId`.

<API method="GET" uri="/api/user/change-password/{changePasswordId}" authentication={["none"]} title="Validate a changePasswordId" />

### JWT

With a JWT or a `loginId`, the API checks only whether a password change for the user requires MFA. Call this API before you [change the user's password](/docs/apis/users/change-password) with a JWT or a `loginId`.

## Response

A successful response has no body. FusionAuth returns a JSON body only for a validation error.

The response doesn't include the **`state`** from the Start Forgot Password request. FusionAuth returns **`state`** in the response of the [Change a User's Password API](/docs/apis/users/change-password). When your app needs the **`state`** values before the password change, add the values to the link in the forgot password message. The **`state`** variable is available in the [Forgot Password email template](/docs/email/template-reference/account/forgot-password) and the [Forgot Password message template](/docs/messengers/template-reference/account/forgot-password).
