
The Id of the Application the user is to be logged into. This parameter is optional but there is not likely a production use case where you want to omit the value. If this parameter is omitted the user will still be authenticated but a login count will not be recorded for an Application.

The Login API doesn't create a Registration, even when the Application has self-service registration enabled. When the user has no Registration for the Application, the response has a `202` status code. For more information, see [Registrations and Self-Service Registration](/docs/concepts/types/registrations#registrations-and-self-service-registration).

See the difference between [authentication and authorization](/docs/concepts/authentication-authorization) for more detail.
