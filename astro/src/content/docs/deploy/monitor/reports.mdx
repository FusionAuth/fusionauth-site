The Admin UI includes reports that count logins, registrations, and active users. To open the reports, navigate to <Breadcrumb>Reports</Breadcrumb> in the Admin UI. An admin user needs the `admin` or `report_viewer` role to view reports. For more information, see [Admin UI Roles](/docs/concepts/types/roles#admin-ui-roles).

## Report Types

The Admin UI includes the following reports:

| Report | What the report counts | Intervals |
|---|---|---|
| Login | Logins, for one application or all applications. | `Hourly`, `Daily`, `Monthly`, `Yearly` |
| Registration | Registrations, for one application or all applications. | `Hourly`, `Daily`, `Monthly`, `Yearly` |
| Daily Active Users | Unique active users per day. A user who logs in several times in one day counts once. | `Daily`, `Monthly`, `Yearly` |
| Monthly Active Users | Unique active users per month. | `Monthly`, `Yearly` |
| Totals | Current and all-time registrations, plus logins, globally and for each application. | None |

The active user reports count more than logins. Creating a user, registering a user, and refreshing a JWT also make a user active. For the full list of events, see [What Makes a User Active](/docs/concepts/types/users#what-makes-a-user-active).

## Filter a Report

Every report except Totals shows a chart with the following controls:

* **Application** limits the report to one application. Select `All Applications` to count activity across every application.
* **Interval** sets what each bar or point in the chart covers. The interval also sets the date range of the chart. `Hourly` shows one day, `Daily` shows one calendar month, and `Monthly` shows one calendar year. `Yearly` shows eleven years, from five years before the selected year to five years after.
* **Range** shows the current date range. Use the arrows on either side to move the range back or forward.
* **User search** limits the Login report to one user. Only the Login report has this control.

The icons above the chart switch between a bar chart and a line chart.

## Totals

The Totals report has no chart. The report shows the following values for the whole instance:

* **Registered Users** is the number of users FusionAuth manages now.
* **Total Registrations** is a running total of registrations. Deleting a user doesn't lower the total.

The report then shows a table with one row for each application. Each row shows **Registered Users**, **Total Registrations**, and **Logins** for that application. When you have more than one tenant, the table adds a **Tenant** column. Removing a user's registration for an application doesn't lower that application's **Total Registrations**.

## Report Time Zone

FusionAuth stores activity in UTC. Reports group the activity into hours and days by the **Report timezone** setting, which decides where each day starts and ends. To change the setting, navigate to <Breadcrumb>Settings -> System -> Reports</Breadcrumb>.

## Monthly Active Users and Billing

FusionAuth bills paid plans by [[monthly active users]]. The Monthly Active Users report helps you track activity during the month. For more information about plans, see [Licensing](/docs/concepts/plans-and-limits/licensing).

## Retrieve Reports With the API

The Admin UI reports use the Report API. To retrieve the same data in your own tools, see the [Report API](/docs/apis/reports).
