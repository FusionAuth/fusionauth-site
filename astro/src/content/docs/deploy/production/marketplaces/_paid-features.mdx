Once you install FusionAuth into your environment using the marketplace, you can [add a license](/docs/concepts/plans-and-limits/licensing). Doing so will allow you to use [additional features](/docs/concepts/plans-and-limits/plans-features).

You can add a license:

* [using kickstart](/docs/get-started/develop/kickstart#set-your-license-id)
* manually using [the Reactor page in the Admin UI](/docs/concepts/plans-and-limits/licensing#add-your-license-to-your-instance)
* using the [Reactor API](/docs/apis/reactor)
