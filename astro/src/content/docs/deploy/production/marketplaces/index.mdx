FusionAuth is available in the following cloud marketplaces:

* [AWS](/docs/deploy/production/marketplaces/aws)
* [Google Cloud](/docs/deploy/production/marketplaces/google-cloud)
* [DigitalOcean](/docs/deploy/production/marketplaces/digitalocean)
* [Render](/docs/deploy/production/marketplaces/render)

The FusionAuth community provides the following templates:

* [EasyPanel template](https://easypanel.io/templates/fusionauth)
* [Pethost template](https://pethost.dev/templates/fusionauth/)
* [Railway template](https://railway.com/deploy/fusionauth)

Finally, you can use FusionAuth in your GitHub CI/CD workflows using [GitHub Actions](/docs/deploy/test/github-actions).

Know a marketplace FusionAuth isn't in but should be? Please [file a GitHub issue](https://github.com/FusionAuth/fusionauth-issues/issues/) with the details.
