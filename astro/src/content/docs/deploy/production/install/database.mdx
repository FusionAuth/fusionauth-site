FusionAuth requires a database that meets the [System Requirements](/docs/deploy/production/system-requirements). FusionAuth supports PostgreSQL and MySQL, and FusionAuth tests only with PostgreSQL.

<Tabs>
   <TabItem label="PostgreSQL">
      <PostgreSQLVersions />

      For FusionAuth versions before `1.43.0`, use PostgreSQL 14, because those versions don't support PostgreSQL 15 or newer.

      <Tabs>
        <TabItem label="Manual Install">
        To install PostgreSQL, follow the installation instructions for your platform at [postgresql.org](https://www.postgresql.org/download/).
        </TabItem>
        <TabItem label="Homebrew">

        To install PostgreSQL with Homebrew:

        <Steps>
           1. Install PostgreSQL:

              ```shell-session
              brew install postgresql@16
              ```
           1. Start PostgreSQL with Homebrew services:

              ```shell-session
              brew services start postgresql@16
              ```
           1. To add the PostgreSQL binaries to your `PATH`, add the following line to your `~/.zshrc` or `~/.bashrc` file:

              ```shell
              export PATH="$PATH:$(brew --prefix postgresql@16)/bin"
              ```
         </Steps>
        </TabItem>
      </Tabs>

      Then, configure PostgreSQL for FusionAuth:

      <Steps>
         1. Create the FusionAuth user, `fusionauth`, with password `fusionauth`:

            ```shell-session
            psql --command="CREATE USER fusionauth PASSWORD 'fusionauth'" --command="\du" postgres
            ```

         1. Create a database named `fusionauth` owned by the `fusionauth` user:

            ```shell-session
            createdb --owner=fusionauth fusionauth
            ```
      </Steps>
      </TabItem>
      <TabItem label="MySQL">

      To install MySQL, follow the installation instructions for your platform at [dev.mysql.com](https://dev.mysql.com/downloads/installer/).

      <Aside type="caution" title="MySQL limits the size of `data` fields">
      On MySQL, the **`data`** field of a User or Registration holds up to 16 MB. The **`data`** field of an Application or Tenant holds less than 64 KB, because the same column stores the rest of the configuration. On PostgreSQL, the API request limits cap a **`data`** field well before the column fills. For more information, see [Data Field Sizes](/docs/concepts/plans-and-limits/limitations#data-field-sizes).
      </Aside>

      FusionAuth stores 4-byte Unicode characters, so MySQL must use the `utf8mb4` character set. When MySQL uses a different character set, FusionAuth fails to start and logs an error. To configure the character set:

      <Steps>
         1. Add the following lines to `my.cnf` (`my.ini` on Windows):

            ```ini
            [client]
            default-character-set = utf8mb4

            [mysql]
            default-character-set = utf8mb4

            [mysqld]
            character-set-client-handshake = FALSE
            character-set-server = utf8mb4
            collation-server = utf8mb4_bin
            ```

         1. Restart MySQL to load the configuration.
      </Steps>

      The configuration changes the character set for the entire MySQL server. When other databases and applications share the MySQL server, check that the change doesn't break them.

      When FusionAuth still fails the `utf8mb4` check at startup after you configure MySQL, you can turn off the check with `database.mysql.enforce-utf8mb4`. For more information, see the [Configuration reference](/docs/deploy/production/configuration).

      FusionAuth also needs MySQL Connector/J, the MySQL JDBC driver. The Oracle license for the driver doesn't allow FusionAuth to bundle the driver, so you install the driver yourself:

      <Steps>
         1. Download MySQL Connector/J `8.0.23` or newer, using the Platform Independent option, from [Oracle](https://dev.mysql.com/downloads/connector/j/).
         1. Unzip or untar the archive.
         1. Copy the driver `.jar` file from the archive to `fusionauth-app/lib` in the FusionAuth installation directory. Newer versions name the file `mysql-connector-j-<version>.jar`, and older versions name the file `mysql-connector-java-<version>.jar`. For example, a DEB package on Debian Linux installs FusionAuth to `/usr/local/fusionauth`, so you copy the file to `/usr/local/fusionauth/fusionauth-app/lib`.
      </Steps>
   </TabItem>
</Tabs>
