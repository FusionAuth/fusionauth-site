The following lambda reconciles a user after a GitHub login. The lambda copies the GitHub avatar and name to the user, and sets the registration username to the GitHub login. The lambda stores the company and location in **`user.data`**, and removes the `@` that GitHub adds to organization names in the company field.

The lambda also calls the GitHub API with the access token from the `tokens` argument to list the user's GitHub organizations. The lambda maps each organization to a role with `orgRoles`, and drops organizations with no mapping. The call needs the `read:org` scope in the identity provider configuration. When the call fails, the lambda logs the error and keeps the current roles, so the login still succeeds. Calling an API from a lambda requires the Essentials plan or higher. See [Lambda HTTP Connect](/docs/lambdas/lambda-remote-api-calls).
