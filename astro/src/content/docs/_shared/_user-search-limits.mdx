A search returns whole User objects. You can't limit the results to certain fields. To keep only some fields, such as **`firstName`** and **`birthDate`**, filter the results in your code, or with a tool such as [`jq`](https://jqlang.org/).

In FusionAuth versions before `1.48.0`, a search with the Elasticsearch search engine returns at most 10,000 Users. In `1.48.0` and later, you can page through every result with **`nextResults`** tokens.

The Elasticsearch search index is eventually consistent. After an update through the API, a change appears in search results once FusionAuth sends the change to the search engine and the search engine refreshes the index. The search engine refreshes the index every second by default, so changes take at least one second to appear. For more information, see the [Elasticsearch `refresh_interval` setting](https://www.elastic.co/guide/en/elasticsearch/reference/current/index-modules.html#index-refresh-interval-setting).
