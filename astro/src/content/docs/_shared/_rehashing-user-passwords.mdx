When you import users with their existing password hashes, users log in without resetting their passwords. FusionAuth keeps each imported hash and the hash's scheme, which may be weak. To replace weak hashes, configure the Tenant to rehash passwords with a stronger scheme:

<Steps>

1. Import the users with their existing hashes. When FusionAuth doesn't support the old scheme, write a password hashing plugin for the scheme. For more information, see [Custom Password Hashing](/docs/migrate/password-hashes/custom-password-hashing).
1. In the Admin UI, navigate to <Breadcrumb>Tenants -> Your Tenant -> Password</Breadcrumb>.
1. In the <Breadcrumb>Cryptographic hash settings</Breadcrumb> section, set **Scheme** to the new scheme. FusionAuth also uses the new scheme for users that you create in the Tenant later.
1. Turn on **Re-hash on login or change**.
1. Click <IconButton icon="save" />.

</Steps>

FusionAuth then rehashes a user's password with the new scheme when the user logs in. In FusionAuth `1.42.0` and later, FusionAuth also rehashes the password when the password changes.
