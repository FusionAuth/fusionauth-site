The following diagram shows a login through {props.identity_provider_name ?? 'an Identity Provider'} on the FusionAuth hosted login pages:

```mermaid title="A user logs in through an Identity Provider on the FusionAuth hosted login pages."
sequenceDiagram
    participant User as User/Browser
    participant App as Your Application
    participant FusionAuth
    participant IdP as Identity Provider

    User ->> App : Click Login
    App ->> User : Redirect to the FusionAuth login page
    User ->> FusionAuth : Click the Identity Provider button
    FusionAuth ->> User : Redirect to the Identity Provider
    User ->> IdP : Log in
    IdP ->> User : Redirect to FusionAuth with the login result
    User ->> FusionAuth : Follow the redirect to the FusionAuth callback URL
    FusionAuth ->> IdP : Request the user's tokens or profile
    IdP ->> FusionAuth : Return the tokens or profile
    FusionAuth ->> FusionAuth : Reconcile, link, and create the user and registration as needed
    FusionAuth ->> User : Redirect to your application with an authorization code
    User ->> App : Follow the redirect
    App ->> FusionAuth : Exchange the authorization code for tokens
    FusionAuth ->> App : Return FusionAuth tokens
```

The user sees only the FusionAuth login page, the login page of {props.identity_provider_name ?? 'the Identity Provider'}, and your application. Your application completes a standard OAuth authorization code grant with FusionAuth, and FusionAuth handles the exchange with {props.identity_provider_name ?? 'the Identity Provider'}.
