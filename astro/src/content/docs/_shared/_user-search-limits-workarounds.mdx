  With the Elasticsearch search engine, page past 10,000 results with the **`nextResults`** token. For more information, see [Extended Pagination](/docs/users/search/user-search-with-elasticsearch#extended-pagination).
</AvailableSince>

In earlier versions, split a search into queries that each return fewer than 10,000 Users. To check whether a query matches more than 10,000 Users, set the **`accurateTotal`** parameter. For more information, see the [User Search API](/docs/apis/users/search).

For example, to download every User, query for email addresses that start with `a`, then `b`, and so on. For a script that uses this approach, see the [full user search example](https://github.com/FusionAuth/fusionauth-example-full-user-search).

When you self-host FusionAuth, you can also query the search engine directly. Each document Id in the result is a FusionAuth User Id. To retrieve the Users, send the Ids to the [User Search API](/docs/apis/users/search) with the **`ids`** parameter.
