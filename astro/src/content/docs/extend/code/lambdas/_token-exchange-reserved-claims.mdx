The following claims are reserved for Token Exchange and cannot be modified in the populate lambda:

- `act` - Actor claim chain (RFC 8693)
- `may_act` - Authorization for delegation (RFC 8693)
- `amr` - Authentication Methods References
- `applicationId` - FusionAuth application identifier  
- `auth_time` - Authentication timestamp
- `authenticationType` - FusionAuth authentication type
- `client_id` - OAuth client identifier
- `cnf` - Confirmation claim (RFC 8705)
- `gty` - Grant type
- `iat` - Issued at timestamp
- `iss` - Issuer
- `jti` - JWT ID
- `sid` - Session ID
- `sub` - Subject
- `tid` - Tenant ID
- `tty` - Token type

Additionally, `scope` and `exp` can only be reduced, never expanded.
