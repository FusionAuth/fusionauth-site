When links or codes expire before users use them, lengthen the external identifier durations. Navigate to <Breadcrumb>Tenants -> Your Tenant -> Advanced</Breadcrumb>. In the <Breadcrumb>External identifier durations</Breadcrumb> section, check **Email verification**, **Phone verification**, and **Registration verification**. FusionAuth sets a default for each duration.
