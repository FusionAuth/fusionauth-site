FusionAuth ships with a default form and a default theme template for each self-service account management page. You can add fields to the form, so users can update more of their profile. You can also edit the templates, so the account pages match the rest of your application.

This guide adds a **birthDate** field to the account edit form, then shows the field on the account home page.

## Add a Field to the Self-Service Form

Forms can collect any user data. The following steps add the built-in `Birthdate` field to the default self-service form:

<Steps>

1. Navigate to <Breadcrumb>Forms</Breadcrumb>.
1. Click <IconButton icon="edit" /> on `Default User Self Service provided by FusionAuth`.

   <Screenshot id="account-forms-list" url="/admin/form/" width={1400} alt="The Forms list with the Default User Self Service form highlighted.">
     <Highlight selector="[data-hl='self-service-form']" />
   </Screenshot>

   The form editor lists the fields on the form. Use the up and down arrows to reorder the fields.

   <Screenshot id="account-form-edit" url="/admin/form/" alt="The Default User Self Service form editor." />

1. Click <Breadcrumb>Add field</Breadcrumb>.
1. Select `Birthdate` and click <Breadcrumb>Submit</Breadcrumb>.

   <Screenshot id="account-form-add-field" url="/admin/form/" crop="[data-hl='add-field-dialog']" cropPadding={0} alt="The Add Field dialog with Birthdate selected." />

</Steps>

This example uses a built-in field. You can also add custom fields, such as `user.data.favColor`. Forms can also split fields into sections, mark fields as required or optional, and limit some fields to admins. For more information, see [Advanced Registration Forms](/docs/users/register/advanced-registration-forms).

## Check the Form Field

The self-service account pages are separate from the Admin UI. The <Breadcrumb>Manage</Breadcrumb> page for a user in the Admin UI shows the admin view of the user, not the account pages. To see the account pages as a user:

<Steps>

1. When the Application has no self-service form, navigate to <Breadcrumb>Applications -> Edit Application -> Registration</Breadcrumb>. Set **User Self-service** to the form you edited, and click <IconButton icon="save" />.
1. Navigate to <Breadcrumb>Applications</Breadcrumb> and click <IconButton icon="view" /> on the Application.
1. Copy the **Account URL**. The URL has the following format:

   ```uri
   https://<your-fusionauth-host>/account/?client_id=<client-id>
   ```

1. Open the URL in a private window or a different browser. The account pages use a separate session, and a private window keeps your admin session out of the way.
1. Log in as a user who is registered for the Application. The Admin UI has no option to log in as another user, so use the credentials of a test user.
1. Click <Breadcrumb>Edit profile</Breadcrumb>.

</Steps>

The account edit form now shows the **Birthdate** field:

<Screenshot id="account-edit-birthdate" url="/account/edit?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account edit form with the Birthdate field added." />

In your application, link to the Account URL from your navigation, so users can reach the account pages. For more information, see [Open the Self-Service Pages](/docs/users/account-management#open-the-self-service-pages).

## Edit the Account Templates

The account home page doesn't show the **Birthdate** field yet. To show the field, edit the account templates in an advanced theme:

<Steps>

1. Navigate to <Breadcrumb>Customizations -> Themes</Breadcrumb>.
1. Open the action menu on the default theme and click <Breadcrumb>Duplicate</Breadcrumb>. You can also create a new theme.
1. Click <IconButton icon="edit" /> on the new theme.

</Steps>

The following templates control the account pages:

* Account edit
* Account index
* Account two-factor disable
* Account two-factor edit
* Account two-factor enable
* Account two-factor index
* Account add WebAuthn [[passkey]] (available in `1.41.0` and later)
* Account delete WebAuthn passkey (available in `1.41.0` and later)
* Account WebAuthn index (available in `1.41.0` and later)

  <Highlight selector="[data-hl='account-templates']" />
</Screenshot>

For more information, see [Themes](/docs/theme).

## Show the Field on the Account Home Page

The Account index template renders the account home page. Click <Breadcrumb>Account index</Breadcrumb>. Find the Phone number field, and add the following after the Phone number field:

```ftl
<div>
  <div class="text-xs font-medium text-text mb-1">${theme.message("user.birthDate")}</div>
  <div class="text-sm text-text">${helpers.display(user, "birthDate")}</div>
</div>
```

The `helpers.display` function displays only top-level user fields, such as `birthDate`. To display a field in **`user.data`**, use FreeMarker directly: `${user.data.favColor}`. To handle defaults or format the value, use the [FreeMarker built-in functions](https://freemarker.apache.org/docs/ref_builtins.html).

Save the theme, and assign the theme to the tenant or the Application. For more information, see [Apply a Theme](/docs/theme#apply-a-theme) and [Application-Specific Themes](/docs/theme/application-specific-themes).

Reload the Account URL. The account home page shows the **Birthdate** field:
