With the phone method, FusionAuth sends a one-time code to the user's phone at login. FusionAuth sends the code by SMS, or by a voice call in `1.65.0` and later.

## Enable the Phone Method on the Tenant

FusionAuth doesn't enable the phone method by default. The phone method needs a messenger. For more information, see [Messengers](/docs/messengers).

To enable the phone method:

<Steps>

1. Navigate to <Breadcrumb>Tenants -> Edit Tenant -> Multi-Factor</Breadcrumb>.
1. Turn on **Enable SMS MFA**, **Enable voice MFA**, or both.
1. For each enabled message type, select a messenger and a template. FusionAuth ships with default templates that you can customize. An Application can override the templates on its <Breadcrumb>Multi-Factor</Breadcrumb> tab.

   <Screenshot id="account-tenant-mfa-phone" url="/admin/tenant/edit/30663132-6464-6665-3032-326466613934#multi-factor" showHash alt="The tenant Multi-Factor tab with the Phone settings highlighted.">
     <Highlight selector="[data-hl='section-box']" />
   </Screenshot>

</Steps>

## Add a Phone on the Account Pages

<Steps>

1. On the account page, click <Breadcrumb>Manage two-factor</Breadcrumb>.

   <Screenshot id="account-home" url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account page with the edit button and the two-factor and passkey links." />

1. Click <Breadcrumb>Add two-factor</Breadcrumb>.

   <Screenshot id="account-two-factor" url="/account/two-factor/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The two-factor page with no methods configured." />

1. Select `Phone`.

   <Screenshot id="account-two-factor-phone" url="/account/two-factor/enable?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The Enable two-factor form for a phone." />

1. Enter a phone number.
1. When the tenant enables both SMS and voice, select the message type.
1. Click <Breadcrumb>Send a one-time code</Breadcrumb>.
1. Optionally, enter a name for the method, such as `Work phone`.
1. Enter the code from the message.
1. Click <Breadcrumb>Enable</Breadcrumb>.

</Steps>

## Log In with a Phone

After the user enters a password at the next login, FusionAuth sends a code to the phone and asks for the code. When the tenant enables both SMS and voice, the user chooses the message type first.
