Phone two-factor is not enabled by default. Configure your tenant by navigating to <Breadcrumb>Tenants -> Edit Tenant -> Multi-Factor</Breadcrumb>.

## Enable MFA method on Tenant (Admin Facing)

<Screenshot id="account-tenant-mfa-phone" url="/admin/tenant/edit/30663132-6464-6665-3032-326466613934#multi-factor" alt="The tenant Multi-Factor tab with the Phone settings highlighted.">
  <Highlight selector="[data-hl='section-box']" />
</Screenshot>

You can enable the phone factor on the tenant level by following these steps:

- Set SMS and/or Voice to enabled
- For each enabled message type, select a `messenger` (previously created, see [documentation](/docs/email/))
- For each enabled message type, select a `template` (FusionAuth ships with a default to be customized if needed)

### Enable Phone Factor from Account Management (User Facing)

<Screenshot id="account-home" url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account page with the edit button and the two-factor and passkey links." />

1. Navigate back to your account page.
2. Click <Breadcrumb>Manage two-factor</Breadcrumb>
3. Click <Breadcrumb>Add two-factor</Breadcrumb>
4. There will be an option for Phone.

<Screenshot id="account-two-factor" url="/account/two-factor/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The two-factor page with no methods configured." />

<Screenshot id="account-two-factor-phone" url="/account/two-factor/enable?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The Enable two-factor form for a phone." />

Next,

1. Enter your phone number.
1. If SMS and Voice are both enabled, select which type of message to send.
1. Click on `Send a one-time-code`.
1. (Optional) Enter a name for this method (for example, `Work phone`).
1. Enter the provided code.
1. Click <Breadcrumb>Enable</Breadcrumb>.

## Recovery Codes (User Facing)

Now you will be presented with recovery codes. Save these in a safe space.

<Screenshot id="account-recovery-codes" url="/account/two-factor/enable?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The recovery codes shown after two-factor authentication is enabled." />

<Icon name="trophy" /> Success!

Upon the next login, you will be prompted for a code sent by phone in addition to your password. If the tenant has both SMS and Voice message types enabled you will be asked to choose which type to receive, otherwise the message will be sent automatically.

## See It in Action (User Facing)

With phone MFA enabled, if you log out and log back in you will be presented with the following screen in addition to the typical login screen.
