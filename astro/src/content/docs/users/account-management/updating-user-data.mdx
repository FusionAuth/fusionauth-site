On the self-service account pages, users can update their own profile data and passwords. The account edit page shows the fields of the Application's self-service form. To add fields to the form, see [Customizing Self-Service Account Management](/docs/users/account-management/customizing-account-management).

To open the account edit page, the user clicks <Breadcrumb>Edit profile</Breadcrumb> on the account page.

<Screenshot id="account-home" url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account page with the edit button and the two-factor and passkey links." />

## Update Profile Data

The user edits the form fields and clicks <Breadcrumb>Submit</Breadcrumb>. FusionAuth saves the changes to the user.

<Screenshot id="account-edit" url="/account/edit?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account edit form." />

## Change the Password

To change the password:

<Steps>

1. Turn on <Breadcrumb>Change password</Breadcrumb>. The form shows a password field and a confirmation field.
1. When the Application requires the current password, enter the current password.
1. Enter the new password in both fields.
1. Click <Breadcrumb>Submit</Breadcrumb>.

</Steps>

<Screenshot id="account-edit-password" url="/account/edit?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account edit form with Change password switched on." />

To require the current password, navigate to <Breadcrumb>Applications -> Edit Application -> Registration</Breadcrumb> and turn on **Require current password**.
