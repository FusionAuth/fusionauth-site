## Exact Match Fields

<AvailableSince since="1.49.1" />

Elasticsearch splits the **`username`** and **`fullName`** fields into words. A search on `username:bob.smith@example.com` can return other users whose usernames share words with `bob.smith@example.com`. To match the whole value, search the matching `.exact` field instead:

* `username.exact`: the whole username.
* `fullName.exact`: the whole full name.

An `.exact` search ignores case, so `fullName.exact:"bob smith"` matches a user named `Bob Smith`. When the value contains a space, wrap the value in double quotes. Without quotes, Elasticsearch searches each word separately, and the search can return more users. For an example request, see [Exact Username or Full Name](/docs/users/search/user-search-with-elasticsearch#exact-username-or-full-name).
