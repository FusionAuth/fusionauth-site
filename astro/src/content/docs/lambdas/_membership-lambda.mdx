The following lambda adds the names of the user's groups to the access token. The **`user.memberships`** argument holds only group Ids, so the lambda calls the [Groups API](/docs/apis/groups) for the names. The lambda reads a FusionAuth API key from a [lambda secret](/docs/lambdas#secrets) named `fusionauth-api-key`. Lambda secrets are available in FusionAuth `1.64.0` and later. The lambda calls the local FusionAuth HTTP port, `9012` by default, so the request doesn't leave the server. When the call fails, the lambda logs the error and issues the token with an empty `groups` claim.
