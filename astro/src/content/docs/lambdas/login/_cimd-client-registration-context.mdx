* `authenticationThreats`: the authentication threats FusionAuth detected for the request. FusionAuth only fills the list with [Advanced Threat Detection](/docs/security/account-protection/advanced-threat-detection). Currently, FusionAuth only adds `ImpossibleTravel`, when the impossible travel signal is `HIGH`. The possible values are `BlocklistedIp`, `BotDetected`, `DormantAccount`, `DormantPassword`, `ImpossibleTravel`, `RecentIdentityChange`, `RecentPasswordChange`, `SuspiciousUserAgent`, `UnrecognizedDevice`, and `UntrustedDevice`.
* `eventInfo`: information about the request. The value can be `null`. For the fields, see `eventInfo` on the [MFA requirement lambda](/docs/lambdas/login/mfa-requirement#the-context-object) page.
* `resource`: the resource the client requested, which is the value of the `resource` request parameter.
* `services`: access to [secrets](/docs/lambdas#secrets) through `context.services.secrets.get('<secret-name>')`.
