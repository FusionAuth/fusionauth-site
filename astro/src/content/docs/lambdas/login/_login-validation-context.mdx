* `authenticationType`: the method used to authenticate the user. The possible values follow this list.
* `identityProvider`: the Identity Provider for a login through a third-party IdP. FusionAuth only sets `identityProvider` for those logins. The `identityProvider` object has the following fields:
  * `id`: the Id of the IdP.
  * `name`: the name of the IdP.
  * `type`: the type of the IdP.
* `services`: <AvailableSince since="1.64.0"/> access to [secrets](/docs/lambdas#secrets) through `context.services.secrets.get('<secret-name>')`.
