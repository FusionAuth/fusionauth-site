* `fields`: an array of [Form Fields](/docs/apis/custom-forms/form-fields) in the current form step.
* `form`: the FusionAuth Form object. See the [Forms API](/docs/apis/custom-forms/forms).
* `step`: the current step number, starting at 1.
* `stepIndex`: the zero-indexed number of the current step, always `step` minus 1.
* `totalSteps`: the total number of steps in the form.
* `services`: <AvailableSince since="1.64.0"/> access to [secrets](/docs/lambdas#secrets) through `context.services.secrets.get('<secret-name>')`.
