When you use an [Advanced Registration Form](/docs/users/register/advanced-registration-forms), you can add a lambda that validates the form fields as the user completes each step.

When you create a lambda in the Admin UI, FusionAuth provides an empty function for you to implement.

## Lambda Structure

When you create the lambda with the API, make sure the function has the following signature:

```javascript
function validate(result, user, registration, context) {
  // Lambda code goes here
}
```

This lambda must contain a function named `validate` that accepts the following parameters:

* `result`: an object used for returning validation errors. You can modify this object.
* `user`: the FusionAuth User object. This object is read-only.
* `registration`: the FusionAuth UserRegistration object. This object is read-only.
* `context`: an object containing data about the current form state. This object is read-only.

The `result` object contains an [Errors](/docs/apis/errors) object. For more information about the `user` and `registration` objects, see the [User API](/docs/apis/users) and [Registration API](/docs/apis/registrations) documentation.

With this information, you can run any validation you need as the user steps through the self-service registration form. When the user submits a step with <Breadcrumb>Next</Breadcrumb> or <Breadcrumb>Register</Breadcrumb>, FusionAuth adds the user and registration fields from that step to the `user` and `registration` objects. Every object the lambda receives is immutable except `result`. The lambda returns validation errors to the form through `result`.

Give each field error a code that matches the invalid form field and a message defined in the theme. For example, when the form field `user.data.name` is invalid, use the error code `[invalid]user.data.name`.
