## Lambda Structure

When you create the lambda with the API, give the function the following signature:

```javascript
function reconcile(user, registration, userInfo, context) {
  // Lambda code goes here
}
```

This lambda must contain a function named `reconcile` that accepts the following parameters:

<ReconcileLambdaUserRegistrationParameters />
* `userInfo`: the response from the Xbox Live XSTS token request. This object is read-only.
* `context`: <AvailableSince since="1.64.0"/> an object containing the context of the request, including access to [secrets](/docs/lambdas#secrets). This object is read-only.

The [User API](/docs/apis/users) and [Registration API](/docs/apis/registrations) documentation describe the `user` and `registration` objects.

The player claims live in **`DisplayClaims.xui[0]`**. The **`gtg`** claim holds the gamertag. FusionAuth uses the gamertag as the username. The **`xid`** claim holds the Xbox user Id. The **`agg`** claim holds the age group: `Adult`, `Teen`, or `Child`.

## Example Lambda

The following lambda stores the gamertag, Xbox user Id, and age group in `user.data.xbox`. The lambda gives a player in the `Teen` or `Child` age group the `restricted` role. The lambda recalculates the role on every login, so the role goes away when the player becomes an adult. Add the `restricted` role to your application before you use the lambda.

## Assigning The Lambda

Assign the lambda to the Xbox Identity Provider. Navigate to <Breadcrumb>Settings -> Identity Providers</Breadcrumb>, then edit your Xbox Identity Provider. If you haven't configured Xbox yet, click <Breadcrumb>Add provider</Breadcrumb> and select Xbox.
