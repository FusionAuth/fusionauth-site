When a user logs in with a HYPR identity provider, FusionAuth uses the email address to reconcile the user. You can use a lambda to customize the user and registration during the login.

When you create a lambda in the Admin UI, FusionAuth provides an empty function.

## Lambda Structure

When you create the lambda with the API, give the function the following signature:

```javascript
function reconcile(user, registration, context) {
  // Lambda code goes here
}
```

This lambda must contain a function named `reconcile` that accepts the following parameters:

<ReconcileLambdaUserRegistrationParameters />
* `context`: <AvailableSince since="1.64.0"/> an object containing the context of the request, including access to [secrets](/docs/lambdas#secrets). This object is read-only.

The [User API](/docs/apis/users) and [Registration API](/docs/apis/registrations) documentation describe the `user` and `registration` objects. HYPR returns no profile data, so the lambda receives no third object.

## Assigning The Lambda

After you create the lambda, assign the lambda to the HYPR identity provider.

Navigate to <Breadcrumb>Settings -> Identity Providers</Breadcrumb>. Select your existing HYPR configuration. If you haven't configured HYPR yet, click <Breadcrumb>Add provider</Breadcrumb> and select HYPR.
