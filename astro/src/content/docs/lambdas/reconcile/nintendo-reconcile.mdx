## Lambda Structure

When you create the lambda with the API, give the function the following signature:

```javascript
function reconcile(user, registration, userInfo, context) {
  // Lambda code goes here
}
```

This lambda must contain a function named `reconcile` that accepts the following parameters:

<ReconcileLambdaUserRegistrationParameters />
* `userInfo`: the response from the Nintendo Account `users/me` API. This object is read-only.
* `context`: <AvailableSince since="1.64.0"/> an object containing the context of the request, including access to [secrets](/docs/lambdas#secrets). This object is read-only.

The [User API](/docs/apis/users) and [Registration API](/docs/apis/registrations) documentation describe the `user` and `registration` objects.

The fields in `userInfo` depend on the scopes you request. By default, FusionAuth reads the unique Id from **`id`**, the email from **`email`**, and the username from **`preferred_username`**. You can change these claim names in the identity provider configuration.

## Assigning The Lambda

After you create the lambda, assign the lambda to the Nintendo identity provider.

Navigate to <Breadcrumb>Settings -> Identity Providers</Breadcrumb>. Select your existing Nintendo configuration. If you haven't configured Nintendo yet, click <Breadcrumb>Add provider</Breadcrumb> and select Nintendo.
