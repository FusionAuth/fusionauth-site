A SCIM Group Request Converter lambda converts an incoming SCIM Group request into a FusionAuth group. FusionAuth runs the lambda before FusionAuth creates or updates the group.

When you create a lambda in the Admin UI, FusionAuth provides an empty function for you to implement.

## Lambda Structure

If you create the lambda with the API, the function must have the following signature:

```javascript
function convert(group, members, options, scimGroup, context) {
  // Lambda code goes here
}
```

The lambda must contain a function named `convert` that accepts the following parameters:

* `group`: the FusionAuth group. You can modify this object. FusionAuth passes a new, empty group.
* `members`: an empty array for the members of the group. You can modify this array. Add one object for each member, with the following properties:
  * `members[x].userId`: the Id of the FusionAuth user.
  * `members[x].data`: custom data for the membership. The default lambda stores the SCIM member URI in `members[x].data.$ref`, such as `https://login.piedpiper.com/api/scim/resource/v2/Users/902c246b-6245-4190-8e05-00816be7344a`.
* `options`: the request options. You can modify this object. The object has the following property:
  * `options.roleIds`: the Ids of the application roles to assign to the group.
* `scimGroup`: the SCIM request. This object is read-only.
* `context`: <AvailableSince since="1.64.0"/> the context of the request, including access to [secrets](/docs/lambdas#secrets). This object is read-only.

The [Group API](/docs/apis/groups) documents the FusionAuth group. The `scimGroup` object holds the SCIM Group request JSON. See [SCIM Group](https://datatracker.ietf.org/doc/html/rfc7643#section-4.2).

## Assign the Lambda

After you create the lambda, assign the lambda to a tenant on the <Breadcrumb>SCIM</Breadcrumb> tab of the tenant configuration.

## Default Lambda

FusionAuth provides a default SCIM Group Request Converter lambda. The default lambda names the group with the SCIM **`displayName`**. The lambda adds a member for each SCIM member and stores the member **`$ref`** in the member **`data`**.

## Example: Assign Roles by Group Name

The following lambda extends the default lambda. The lambda makes these changes:

* The lambda looks up the SCIM **`displayName`** in a map of application role Ids and sets **`options.roleIds`**. Members of the group receive those roles. A group with no entry in the map gets no roles. Replace each `replace-with-` value with a role Id from your applications.
* The lambda adds a `SCIM: ` prefix to the group name, so a provisioned group can't collide with a group created in FusionAuth. The lambda stores the original name in **`group.data.scimDisplayName`**.
* The lambda skips SCIM members that have no **`value`**.
