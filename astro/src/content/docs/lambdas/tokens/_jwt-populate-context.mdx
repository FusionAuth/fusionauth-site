* `application`: <AvailableSince since="1.70.2"/> the [Application](/docs/apis/applications) that FusionAuth issues the token for, without the client secret.
* `scopes`: <AvailableSince since="1.59.0"/> the scopes requested for the token. The array is empty when the token comes from the Login API.
* `services`: <AvailableSince since="1.64.0"/> access to [secrets](/docs/lambdas#secrets) through `context.services.secrets.get('<secret-name>')`.
