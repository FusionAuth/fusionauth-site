The [FusionAuth TypeScript client library](https://www.npmjs.com/package/@fusionauth/typescript-client) integrates FusionAuth with applications written for browsers or Node.js. The library supports applications written in TypeScript and JavaScript. The source code is in the [TypeScript client GitHub repository](https://github.com/FusionAuth/fusionauth-typescript-client).

## Install

### NPM Package

Run the following command:

```shell-session
npm install @fusionauth/typescript-client
```

### Browser Bundle

To use `FusionAuthClient` in a browser application, fetch the `npm` module from `esm.sh` or `cdn.jsDelivr` in a script tag.

```html {2} title="esm.sh"
<script type="module">
    import { FusionAuthClient } from 'https://esm.sh/@fusionauth/typescript-client';

    // first parameter is the API key, see the note below
    const client = new FusionAuthClient(null, 'https://your-fusionauth-url.com');

    client.exchangeOAuthCodeForAccessTokenUsingPKCE(...)
      .then(response => console.log('Success:', response))
      .catch(error => console.error('Error:', error));
  </script>
```

```html {2} title="cdn.jsDelivr"
<script type="module">
  import { FusionAuthClient } from 'https://cdn.jsdelivr.net/npm/@fusionauth/typescript-client/+esm';
  
  const client = new FusionAuthClient(null, 'https://your-fusionauth-url.com');
</script>
```

## Examples

<Aside type="note">
Frontend code such as a web browser has no secure place to store an API key. To make API requests that don't require an API key, pass `null` for the API key parameter.
</Aside>

<ExampleAssumptions />

Each example uses `retrieveUserByEmail` as a basic use case. The examples use TypeScript, and you can write the same code in plain JavaScript.

### Node.js

```typescript
import {FusionAuthClient} from '@fusionauth/typescript-client';
const client = new FusionAuthClient('bf69486b-4733-4470-a592-f1bfce7af580', 'https://local.fusionauth.io');
client.retrieveUserByEmail('user@example.com')
      .then(clientResponse => {
        console.log("User:", JSON.stringify(clientResponse.response.user, null, 2));
      }).catch(console.error);
```

For the full example, see the [Node.js example source code](https://github.com/FusionAuth/fusionauth-typescript-client/tree/main/examples/node-example).

### Browser

In the browser, the library exports all objects under the `FusionAuth` namespace. The namespace keeps the objects out of the global namespace.

```html
<script src="fusionauth-typescript-client.min.js"></script>
<script>
const client = new FusionAuth.FusionAuthClient('bf69486b-4733-4470-a592-f1bfce7af580', 'https://local.fusionauth.io');
client.retrieveUserByEmail('user@example.com')
      .then(clientResponse => {
        console.log("User:", JSON.stringify(clientResponse.response.user, null, 2));
      }).catch(console.error);
</script>
```

For the full example, see the [browser example source code](https://github.com/FusionAuth/fusionauth-typescript-client/tree/main/examples/browser-example).

### Hybrid

A hybrid project runs the same code as the Node.js example in the browser and in Node.js. Browser bundles expose any API key to users, so avoid API keys in hybrid code.

The build script is the difference. Instead of compiling with `tsc` and running Node.js on the resulting JavaScript, use a tool such as `browserify` or `webpack` to build the script. This example uses `browserify`.

Choose the command for your target. To compile for Node.js, run:

```shell-session
tsc
```

To compile for the browser, run:

```shell-session
npm run build-browser
```

Alternatively, build for the browser with the longer command:

```shell-session
npx browserify example.ts --debug -p tsify -t browserify-shim -o dist/example-browser.js
```

For the full example, see the [hybrid example source code](https://github.com/FusionAuth/fusionauth-typescript-client/tree/main/examples/hybrid-example).
