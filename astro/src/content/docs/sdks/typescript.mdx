The [FusionAuth TypeScript Client Library](https://www.npmjs.com/package/@fusionauth/typescript-client) helps integrate FusionAuth with applications written for browsers or Node.js.

This client supports applications written in both TypeScript and JavaScript.

## Install

### NPM Package

To install the FusionAuth Typescript Client package, run the following command:

```shell-session
npm install @fusionauth/typescript-client
```

### Browser bundle

To use `FusionAuthClient` in a browser application, use `esm.sh` or `cdn.jsDelivr` in a script tag to fetch the `npm` module.

```html title="esm.sh" {2}
<script type="module">
    import { FusionAuthClient } from 'https://esm.sh/@fusionauth/typescript-client';

    // Initialize the client; see the security warning below regarding the API key (the first parameter)
    const client = new FusionAuthClient(null, 'https://your-fusionauth-url.com');

    client.exchangeOAuthCodeForAccessTokenUsingPKCE(...)
      .then(response => console.log('Success:', response))
      .catch(error => console.error('Error:', error));
  </script>
```

```html title="cdn.jsDelivr" {2}
<script type="module">
  import { FusionAuthClient } from 'https://cdn.jsdelivr.net/npm/@fusionauth/typescript-client/+esm';
  
  const client = new FusionAuthClient(null, 'https://your-fusionauth-url.com');
</script>
```

## Examples

<Aside type="note">
When using this client library in frontend code such as a web browser, there is no secure way to store an API key. However, you can pass a value of `null` for the API key parameter to make API requests that do not require an API key.
</Aside>

The following examples assumes FusionAuth is running on `http://localhost:9011` and uses an API key `bf69486b-4733-4470-a592-f1bfce7af580`. You will need to supply your own API key, and if you are not running FusionAuth locally, your host parameter may be different.

The following examples all use `retrieveUserByEmail` as a basic use case of FusionAuth. Additionally, while the examples are written in TypeScript, this does not prevent you from using raw JavaScript instead in your own application.

### Node.js

```typescript
import {FusionAuthClient} from '@fusionauth/typescript-client';
const client = new FusionAuthClient('bf69486b-4733-4470-a592-f1bfce7af580', 'https://local.fusionauth.io');
client.retrieveUserByEmail('user@example.com')
      .then(clientResponse => {
        console.log("User:", JSON.stringify(clientResponse.response.user, null, 2));
      }).catch(console.error);
```

You can also find this example's [source code](https://github.com/FusionAuth/fusionauth-typescript-client/tree/main/examples/node-example) in the [typescript repo](https://github.com/FusionAuth/fusionauth-typescript-client).

### Browser

In the browser, all of the exported objects are under the namespace FusionAuth to prevent polluting the global namespace.

```html
<script src="fusionauth-typescript-client.min.js"></script>
<script>
const client = new FusionAuth.FusionAuthClient('bf69486b-4733-4470-a592-f1bfce7af580', 'https://local.fusionauth.io');
client.retrieveUserByEmail('user@example.com')
      .then(clientResponse => {
        console.log("User:", JSON.stringify(clientResponse.response.user, null, 2));
      }).catch(console.error);
</script>
```

You can also find this example's [source code](https://github.com/FusionAuth/fusionauth-typescript-client/tree/main/examples/browser-example) in the [GitHub repository](https://github.com/FusionAuth/fusionauth-typescript-client).

### Hybrid

You can write the hybrid exactly the same as the Node.js example (but keep in mind that API keys will be exported so it is not recommended to use API keys at all). The key difference in this case is the build script. Instead of just using `tsc` to compile and running Node.js on the resulting JavaScript, you will instead use a tool like `browserify` or `webpack` to build your script. This example uses `browserify` for simplicity.

We can build a hybrid project using one of two commands, each associated with the target.

Compile for Node.js:

```shell-session
tsc
```

Compile for browser:

```shell-session
npm run build-browser
```

Or use this longer command to build for the browser:

```shell-session
npx browserify example.ts --debug -p tsify -t browserify-shim -o dist/example-browser.js
```

You can also find this example's [source code](https://github.com/FusionAuth/fusionauth-typescript-client/tree/main/examples/hybrid-example) in the [GitHub repository](https://github.com/FusionAuth/fusionauth-typescript-client).
