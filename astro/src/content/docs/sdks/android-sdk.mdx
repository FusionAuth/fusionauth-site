The Android SDK adds OAuth 2.0 and OpenID Connect login to an Android app, with FusionAuth as the [[authorization server]]. The SDK also provides a Token Manager that stores, refreshes, and retrieves tokens. The SDK handles the dependencies for you, so you get a standardized starting point for a custom mobile app.

The SDK covers the following functionality:

* OAuth 2.0 Authorization Code Grant
* OAuth 2.0 Refresh Token Grant
* OpenID Connect UserInfo
* OpenID Connect End Session

The SDK uses [AppAuth-Android](https://github.com/openid/AppAuth-Android) for the Authorization Code Grant flow and the OpenID Connect functionality. Kotlin is the SDK language, and the SDK works with Java.

### Configure the SDK

{/* Source: https://github.com/FusionAuth/fusionauth-android-sdk/blob/033f1165b604c0c181100ef1e40354c026bd6a4e/README.md — forDocSiteGettingStarted; internal documentation links use current site paths. */}

1. Add the SDK dependency to your `build.gradle.kts` file:

   ```kotlin
   dependencies {
       implementation('io.fusionauth:fusionauth-android-sdk:<latest-version>')
   }
   ```

1. Initialize the `AuthorizationManager` with an `AuthorizationConfiguration`:

   ```kotlin
   AuthorizationManager.initialize(
       AuthorizationConfiguration(
           fusionAuthUrl = "http://10.0.2.2:9011",
           clientId = "e9fdb985-9173-4e01-9d73-ac2d60d1dc8e",
           allowUnsecureConnection = true
       )
   )
   ```

The `AuthorizationManager` is a singleton, so you can access the `AuthorizationManager` from anywhere in your app. The example `fusionAuthUrl` is the default address that the Android Emulator uses for your local machine. When FusionAuth runs on a different machine, replace **`fusionAuthUrl`** with the correct URL.

#### Read the Configuration from a Resource File

You can read the `AuthorizationConfiguration` from a resource file instead of setting the configuration in code:

```kotlin
AuthorizationManager.initialize(
    AuthorizationConfiguration.fromResources(this, R.raw.fusionauth_config)
)
```

Put the `fusionauth_config.json` file in the `res/raw` directory. The file looks like this:

```json
{
  "fusionAuthUrl": "http://10.0.2.2:9011",
  "clientId": "e9fdb985-9173-4e01-9d73-ac2d60d1dc8e",
  "allowUnsecureConnection": true
}
```

#### Store Tokens

The SDK stores tokens in `MemoryStorage` by default, so the app loses the tokens when the app closes. To keep tokens across restarts, use `DataStoreStorage` or implement your own `TokenStorage`.

## Use the SDK

{/* Source: https://github.com/FusionAuth/fusionauth-android-sdk/blob/033f1165b604c0c181100ef1e40354c026bd6a4e/README.md — forDocSiteUsage; internal documentation links use current site paths. */}

The following steps cover the login, token, and logout flow.

1. Call the `oAuth()` function on the `AuthorizationManager` to get the `OAuthAuthorizationService`, and then call `authorize` to start the OAuth 2.0 Authorization Code Grant:

   ```kotlin
   AuthorizationManager
       .oAuth(this@LoginActivity)
       .authorize(
           Intent(this@LoginActivity, TokenActivity::class.java),
           OAuthAuthorizeOptions(
               cancelIntent = Intent(this@LoginActivity, LoginActivity::class.java)
                   .setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP),
               state = "state-${System.currentTimeMillis()}"
           )
       )
   ```

   The `authorize` function opens the provided `Intent` when the flow completes. Use `OAuthAuthorizeOptions` to set additional options, such as **`cancelIntent`** and **`state`**.

1. Handle the redirect in the `TokenActivity`. The SDK opens the `TokenActivity` when the user completes the flow:

   ```kotlin
   AuthorizationManager.oAuth(this@TokenActivity)
       .handleRedirect(intent)
   ```

   The `handleRedirect` function retrieves the authorization response, validates the `state` when you provided one, and exchanges the authorization code for an access token. The SDK stores the result of the exchange in the `TokenManager`.

1. Call `getUserInfo()` to retrieve the [User Info](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) after the user is authorized:

   ```kotlin
   AuthorizationManager.oAuth(this@TokenActivity).getUserInfo()
   ```

1. Call `freshAccessToken` to get a valid access token for your API calls:

   ```kotlin
   val accessToken = AuthorizationManager.freshAccessToken(this@TokenActivity)
   ```

   The `TokenManager` returns a fresh access token. When the access token has expired, the `TokenManager` refreshes the access token automatically.

1. Call `logout` to sign out the user and remove the tokens from the `TokenManager`:

   ```kotlin
   AuthorizationManager
       .oAuth(this@TokenActivity)
       .logout(
           Intent(this@TokenActivity, LoginActivity::class.java)
               .setFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP)
       )
   ```

   The SDK opens the `LoginActivity` after the user signs out.
