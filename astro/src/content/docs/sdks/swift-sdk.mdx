The iOS SDK adds OAuth 2.0 and OpenID Connect login to an iOS app, with FusionAuth as the [[authorization server]]. The SDK also provides a Token Manager that stores, refreshes, and retrieves tokens. The SDK handles the dependencies for you, so you get a standardized starting point for a custom mobile app.

The SDK covers the following functionality:

* OAuth 2.0 Authorization Code Grant
* OAuth 2.0 Refresh Token Grant
* OpenID Connect UserInfo
* OpenID Connect End Session

The SDK uses [AppAuth-iOS](https://github.com/openid/AppAuth-iOS) for the Authorization Code Grant flow and the OpenID Connect functionality. Swift is the SDK language, and the SDK works with Objective-C.

### Configure the SDK

{/* Source: https://github.com/FusionAuth/fusionauth-swift-sdk/blob/acd677511e7a19e7bc86bb4a9bf7a0807cdc30af/README.md — forDocSiteGettingStarted; internal documentation links use current site paths. */}

1. Add the SDK repository as a dependency of your app.

1. Create a `FusionAuth.plist` file in the main bundle. The SDK reads the configuration from this file by default, and the file contains the following keys:

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
       <key>additionalScopes</key>
       <array>
           <string>profile</string>
           <string>email</string>
       </array>
       <key>fusionAuthUrl</key>
       <string>http://localhost:9011</string>
       <key>clientId</key>
       <string>e9fdb985-9173-4e01-9d73-ac2d60d1dc8e</string>
   </dict>
   </plist>
   ```

1. Initialize the `AuthorizationManager` in the `init` function of your app:

   ```swift
   @main
   struct QuickstartApp: App {
       init() {
           AuthorizationManager.instance.initialize()
       }
   }
   ```

1. Handle the callback from the browser:

   ```swift
   @main
   struct QuickstartApp: App {
       init() {
           AuthorizationManager.instance.initialize()
       }

       var body: some Scene {
           WindowGroup {
               ContentView()
                   .onOpenURL { url in
                       OAuthAuthorization.resume(with: url)
                   }
           }
       }
   }
   ```

#### Set the Configuration in Code

You can pass the configuration to the `initialize` function instead of using the `FusionAuth.plist` file:

```swift
@main
struct QuickstartApp: App {
    init() {
        AuthorizationManager.instance.initialize(configuration: AuthorizationConfiguration(
            clientId: "e9fdb985-9173-4e01-9d73-ac2d60d1dc8e",
            fusionAuthUrl: "http://localhost:9011",
            additionalScopes: ["email", "profile"]))
    }
}
```

#### Store Tokens

The SDK stores tokens in `MemoryStorage` by default. To use `KeyChainStorage` or `UserDefaultsStorage` instead, add the **`storage`** key to the `FusionAuth.plist` file with the value `keychain` or `userdefaults`.

## Use the SDK

{/* Source: https://github.com/FusionAuth/fusionauth-swift-sdk/blob/acd677511e7a19e7bc86bb4a9bf7a0807cdc30af/README.md — forDocSiteUsage; internal documentation links use current site paths. */}

The following steps cover the login, token, and logout flow.

1. Call the `oauth()` function on the `AuthorizationManager` to get the `OAuthAuthorizationService`, and then call `authorize` to start the OAuth 2.0 Authorization Code Grant:

   ```swift
   do {
       try await AuthorizationManager
           .oauth()
           .authorize(options: OAuthAuthorizeOptions())
   } catch let error as NSError {
       print("Error: \(error.localizedDescription)")
   }
   ```

   The `authorize` method opens the Safari browser and redirects to the FusionAuth login page. After a successful login, FusionAuth redirects the user back to the app with the authorization code. The SDK validates the `state` when you provided one, exchanges the authorization code for an access token and a refresh token, and stores the result in the `TokenManager`.

1. Call `userInfo()` to retrieve the [User Info](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) after the user is authorized:

   ```swift
   do {
       self.userInfo = try await AuthorizationManager
           .oauth()
           .userInfo()
   } catch let error as NSError {
       print("JSON decode failed: \(error.localizedDescription)")
   }
   ```

1. Call `freshAccessToken` to get a valid access token for your API calls:

   ```swift
   let accessToken = AuthorizationManager.oauth().freshAccessToken()
   ```

   The `TokenManager` returns a fresh access token. When the access token has expired, the `TokenManager` refreshes the access token automatically.

1. Call `logout` to sign out the user and remove the tokens from the `TokenManager`:

   ```swift
   do {
       try await AuthorizationManager
           .oauth()
           .logout(options: OAuthLogoutOptions())
   } catch let error as NSError {
       print("Error: \(error.localizedDescription)")
   }
   ```

   The SDK clears the auth state after the user signs out.
