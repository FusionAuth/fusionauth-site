The Swift SDK adds login and logout to an iOS app, with FusionAuth as the [[authorization server]]. The SDK runs the OAuth 2.0 Authorization Code grant with [[PKCE]] through [AppAuth-iOS](https://github.com/openid/AppAuth-iOS), then stores and refreshes the tokens for you. The SDK works from Swift and Objective-C. To build a complete app step by step, see the [iOS QuickStart](/docs/quickstarts/app/quickstart-swift-ios-native).

## Prerequisites

* iOS 15 or later.
* A FusionAuth [[Application]] configured as a [[public client]]. On the <Breadcrumb>OAuth</Breadcrumb> tab of the Application:
  * Set **Client Authentication** to `Not required when using PKCE`, because an iOS app can't keep a client secret.
  * Add `<bundle id>:/oauth2redirect/ios-provider` to **Authorized redirect URLs**, where `<bundle id>` is the bundle identifier of your app, such as `io.fusionauth.app:/oauth2redirect/ios-provider`. The SDK uses this URL after login and after logout.

## Add Login to Your App

<Steps>

1. In Xcode, select <Breadcrumb>File -> Add Package Dependencies</Breadcrumb>. Enter `https://github.com/FusionAuth/fusionauth-swift-sdk`, and add the `FusionAuth` library to your app target.

1. Create a file named `FusionAuth.plist` in the main bundle of your app. Set **`fusionAuthUrl`** to the URL of your FusionAuth instance and **`clientId`** to the client Id of your FusionAuth Application:

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
       <key>fusionAuthUrl</key>
       <string>http://localhost:9011</string>
       <key>clientId</key>
       <string>e9fdb985-9173-4e01-9d73-ac2d60d1dc8e</string>
       <key>additionalScopes</key>
       <array>
           <string>profile</string>
           <string>email</string>
       </array>
       <key>storage</key>
       <string>keychain</string>
   </dict>
   </plist>
   ```

   **`additionalScopes`** requests the `profile` and `email` scopes, so the user's name and email address appear in the user info. **`storage`** keeps the tokens in the keychain. Without **`storage`**, the SDK keeps the tokens in memory, and the user logs in again each time the app starts. To keep the tokens in `UserDefaults`, set **`storage`** to `userdefaults`.

1. Initialize the `AuthorizationManager` when your app starts, and pass the URL that FusionAuth opens after login to `OAuthAuthorization.resume`:

   ```swift
   import FusionAuth
   import SwiftUI

   @main
   struct MyApp: App {
       init() {
           AuthorizationManager.instance.initialize()
       }

       var body: some Scene {
           WindowGroup {
               ContentView()
                   .onOpenURL { url in
                       OAuthAuthorization.resume(with: url)
                   }
           }
       }
   }
   ```

1. Call `authorize` to start login:

   ```swift
   do {
       try await AuthorizationManager
           .oauth()
           .authorize(options: OAuthAuthorizeOptions())
   } catch {
       print("Login failed: \(error.localizedDescription)")
   }
   ```

   `authorize` opens the FusionAuth login page in a browser. After the user logs in, the SDK exchanges the authorization code for an access token and a refresh token, and stores the tokens.

1. Call `logout` to log the user out:

   ```swift
   do {
       try await AuthorizationManager
           .oauth()
           .logout(options: OAuthLogoutOptions())
   } catch {
       print("Logout failed: \(error.localizedDescription)")
   }
   ```

   `logout` ends the FusionAuth session and removes the stored tokens.

1. Run the app and start login. The FusionAuth login page opens. After you log in, FusionAuth returns you to your app.

</Steps>

## Get the User's Profile

Call `userInfo` to load the user's [UserInfo](https://openid.net/specs/openid-connect-core-1_0.html#UserInfo) claims, such as the email address:

```swift
let userInfo = try await AuthorizationManager
    .oauth()
    .userInfo()
```

## Call Your APIs with an Access Token

Call `freshAccessToken` before each API call. The SDK returns the stored access token, and refreshes the token first when the token has expired:

```swift
let accessToken = try await AuthorizationManager.instance.freshAccessToken()
```

Send the token in the `Authorization` header as `Bearer <token>`.

## Set the Configuration in Code

To skip the `FusionAuth.plist` file, pass an `AuthorizationConfiguration` and a storage type to `initialize`:

```swift
AuthorizationManager.instance.initialize(
    configuration: AuthorizationConfiguration(
        clientId: "e9fdb985-9173-4e01-9d73-ac2d60d1dc8e",
        fusionAuthUrl: "http://localhost:9011",
        additionalScopes: ["email", "profile"]
    ),
    storage: KeyChainStorage()
)
```

For every type and option in the SDK, see the [Swift SDK reference](https://github.com/FusionAuth/fusionauth-swift-sdk/blob/main/Documentation/Reference/README.md).
