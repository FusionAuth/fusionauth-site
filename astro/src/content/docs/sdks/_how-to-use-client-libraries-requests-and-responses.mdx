Each library maps a request object to the JSON that the matching API method requires. Depending on the API call, the request object is a set of string parameters or a complex object. When you use a language without static typing, read the API documentation for the operation to learn the expected fields.

Each library returns a response object with these fields:

* A status that matches the HTTP status code from the API. The status is `-1` when no HTTP request succeeded.
* A JSON success object when the call succeeds.
* A JSON error object with a message when the status is `4xx` or `5xx`.
* An exception object when the library sent no request or the server returned no usable response.
