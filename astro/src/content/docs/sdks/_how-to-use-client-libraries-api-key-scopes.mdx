When a script calls endpoints with different API key scopes, create one client instance per scope. For example, Entities accept a tenant-scoped API key, but Entity Types and Lambdas require a global API key.

Follow these rules when your library lets you set a Tenant Id on the client instance:

* Set the Tenant Id on the tenant-scoped client only.
* Don't change the Tenant Id on a shared client between calls.
* Don't send a tenant header to a global-only endpoint. The endpoint [fails with a `401`](/docs/apis/authentication#global-api-key-authentication).
