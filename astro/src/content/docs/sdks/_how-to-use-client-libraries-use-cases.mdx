Client libraries wrap the [REST API](/docs/apis). You can use a client library for two tasks.

The main task is calling the FusionAuth APIs from code. You get auto-completion and typed objects, which helps when you script configuration, automate common tasks, or copy existing Applications and Groups. The API documentation lists the JSON structure of every request and which fields each call requires. When you need the details, read the API documentation and the library source code.

The secondary task is exchanging an authorization code for tokens in the Authorization Code grant. For this task, use an OAuth library for your language instead. For a list of libraries, see the [community curated list](https://oauth.net/code/).

Client libraries don't provide higher level functionality such as token management. To request that functionality, comment on or upvote the [open issue](https://github.com/FusionAuth/fusionauth-issues/issues/1674).

When a client library doesn't fit your needs, call the REST API directly.
