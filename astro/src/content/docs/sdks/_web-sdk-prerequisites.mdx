* FusionAuth `1.45.0` or later, which adds the hosted backend.
* A FusionAuth [[Application]]. On the <Breadcrumb>OAuth</Breadcrumb> tab of the Application, add the URL that FusionAuth returns users to after login to **Authorized redirect URLs**. The SDK calls this URL **`redirectUri`**.
* [[CORS]] that accepts requests from your application. Under <Breadcrumb>Settings -> System -> CORS</Breadcrumb>, enable **Include credentials in CORS requests**, add the origin of your application to **Allowed origins**, and allow the `GET` and `POST` methods. The SDK sends the token cookies with each request to FusionAuth, so FusionAuth must accept credentials from your origin.
* {props.framework} <code>{props.version}</code> or later.

</Aside>
