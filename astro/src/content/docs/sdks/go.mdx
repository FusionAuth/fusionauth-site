The Go client library integrates FusionAuth with your Go application. The source code is in the [Go client GitHub repository](https://github.com/FusionAuth/go-client).

## Install

Initialize a Go module for your project and fetch the dependencies:

```bash
go mod init example.com/test/fusionauth
go mod tidy
```

## Retrieve a User

Put the following code in a file named `fusionauth.go`. The code retrieves a User by email address.

```go
package main

import (
    "net/http"
    "net/url"
    "time"
    "fmt"

    "github.com/FusionAuth/go-client/pkg/fusionauth"
)

const host = "http://localhost:9011"

var apiKey = "YOUR_API_KEY"

var httpClient = &http.Client{
	Timeout: time.Second * 10,
}

var baseURL, _ = url.Parse(host)

{/*  Construct a new FusionAuth Client */}
var client = fusionauth.NewClient(httpClient, baseURL, apiKey)

func main() {
    response, errors, err := client.RetrieveUserByEmail("user@example.com")
    if err != nil {
        // transport layer error, such as a failed connection
        fmt.Println(err)   
        return
    }
    if errors != nil {
        // FusionAuth response error, such as a missing user
        fmt.Println(response.StatusCode)
        return
    }
    fmt.Println(response.User.Email)   
    fmt.Println(response.User.FirstName)   
    fmt.Println(response.User.LastName)   
}
```

Build an executable:

```bash
go build
```

Run the executable:

```bash
./fusionauth
```
