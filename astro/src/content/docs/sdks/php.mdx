The PHP client library integrates FusionAuth with your PHP application. The source code is in the [PHP client GitHub repository](https://github.com/FusionAuth/fusionauth-php-client).

## Install

To install the library, choose one of the following options:

* Copy the PHP source files from the `src` directory into your project.
* Install the [Packagist package](https://packagist.org/packages/fusionauth/fusionauth-client) with Composer.

To install the Composer package, run:

```bash
composer require fusionauth/fusionauth-client
```

Then include the Composer autoloader:

```php
require __DIR__ . '/vendor/autoload.php';
```

## Create the Client

<ExampleAssumptions />

```php
$apiKey = "5a826da2-1e3a-49df-85ba-cd88575e4e9d";
$client = new FusionAuth\FusionAuthClient($apiKey, "http://localhost:9011");
```

## Log In a User

The following code logs in a User with a login Id and password:

```php
$applicationId = "68364852-7a38-4e15-8c48-394eceafa601";

$request = array();
$request["applicationId"] = $applicationId;
$request["loginId"] = "joe@fusionauth.io";
$request["password"] = "abc123";
$result = $client->login($request);
if (!$result->wasSuccessful()) {
 // Error
}

{/*  Hooray! Success */}
```
