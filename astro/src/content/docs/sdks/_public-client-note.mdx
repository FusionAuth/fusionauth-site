You can use this client library in an application that can't securely store secrets, such as a native mobile application or a single page application running in the browser.

For these applications, turn off **Require authentication** in the FusionAuth Application configuration. Then use [PKCE](https://tools.ietf.org/html/rfc7636) to secure communication with the Token endpoint. To exchange the authorization code, call the `exchangeOAuthCodeForAccessTokenUsingPKCE` client method.
