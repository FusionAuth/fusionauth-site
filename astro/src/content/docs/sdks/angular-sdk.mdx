The Angular SDK adds login, registration, and logout to an Angular application, and tracks whether the user is logged in. To build a complete application step by step, see the [Angular QuickStart](/docs/quickstarts/spa/quickstart-javascript-angular-web).

## Add Login to Your Application

<Steps>

1. Install the SDK:

   ```shell-session
   npm install @fusionauth/angular-sdk
   ```

1. Add the SDK providers to `src/app/app.config.ts`. Set **`clientId`** to the client Id of your FusionAuth Application, **`serverUrl`** to the URL of your FusionAuth instance, and **`redirectUri`** to the URL you added to **Authorized redirect URLs**:

   ```typescript
   import { ApplicationConfig, importProvidersFrom } from '@angular/core';
   import { FusionAuthModule } from '@fusionauth/angular-sdk';

   export const appConfig: ApplicationConfig = {
     providers: [
       importProvidersFrom(
         FusionAuthModule.forRoot({
           clientId: 'e9fdb985-9173-4e01-9d73-ac2d60d1dc8e',
           serverUrl: 'http://localhost:9011',
           redirectUri: 'http://localhost:4200',
           shouldAutoRefresh: true,
         }),
       ),
     ],
   };
   ```

   **`shouldAutoRefresh`** refreshes the access token before the token expires. For every option, see [Web SDK Configuration](/docs/sdks/web-sdk-configuration). In an application that uses NgModules, add `FusionAuthModule.forRoot()` to the **`imports`** of the root module instead.

1. Inject `FusionAuthService` in a component to add login, registration, and logout buttons:

   ```typescript
   import { Component, inject, OnInit, signal } from '@angular/core';
   import { FusionAuthService, UserInfo } from '@fusionauth/angular-sdk';

   @Component({
     selector: 'app-auth-buttons',
     template: `
       @if (isLoggedIn()) {
         @if (userInfo()?.given_name) {
           <p>Welcome {{ userInfo()?.given_name }}!</p>
         }
         <button (click)="fusionAuth.logout()">Log Out</button>
       } @else {
         <button (click)="fusionAuth.startLogin()">Log In</button>
         <button (click)="fusionAuth.startRegistration()">Register</button>
       }
     `,
   })
   export class AuthButtonsComponent implements OnInit {
     fusionAuth = inject(FusionAuthService);
     isLoggedIn = this.fusionAuth.isLoggedInSignal;
     userInfo = signal<UserInfo | null>(null);

     async ngOnInit() {
       if (this.fusionAuth.isLoggedIn()) {
         this.userInfo.set(await this.fusionAuth.getUserInfo<UserInfo>());
       }
     }
   }
   ```

   `startLogin` and `startRegistration` send the browser to the FusionAuth login and registration pages. `logout` ends the session and returns the browser to **`redirectUri`**. To return users to a different page after logout, set **`postLogoutRedirectUri`** and add the URL to **Authorized redirect URLs**.

1. Start your application and click <Breadcrumb>Log In</Breadcrumb>. The browser opens the FusionAuth login page. After you log in, FusionAuth returns you to your application, and the component shows <Breadcrumb>Log Out</Breadcrumb>.

</Steps>

To load the profile as an RxJS observable, call `getUserInfoObservable` instead of `getUserInfo`. For every method on `FusionAuthService`, see the [Angular SDK reference](https://github.com/FusionAuth/fusionauth-javascript-sdk/tree/main/packages/sdk-angular/docs).

## Use the Pre-Built Buttons

Instead of writing your own buttons, use the styled buttons from the SDK. Import `FusionAuthModule` in the component, then place the `fa-login`, `fa-register`, and `fa-logout` elements in the template:

```typescript
import { Component } from '@angular/core';
import { FusionAuthModule } from '@fusionauth/angular-sdk';

@Component({
  selector: 'app-header',
  imports: [FusionAuthModule],
  template: `
    <fa-login></fa-login>
    <fa-register></fa-register>
    <fa-logout></fa-logout>
  `,
})
export class HeaderComponent {}
```

## Return Users to a Page After Login

To return users to the page they started from, pass a string to `startLogin` or `startRegistration`. The SDK passes the string to the **`onRedirect`** function when the browser returns from FusionAuth. Set **`onRedirect`** in the `FusionAuthModule.forRoot()` options:

```typescript
FusionAuthModule.forRoot({
  // ...
  onRedirect: (state?: string) => {
    if (state) window.location.assign(state);
  },
}),
```

```typescript
this.fusionAuth.startLogin(window.location.pathname);
```

The `fa-login` and `fa-register` elements accept the same string in the **`state`** input.

## Use Server-Side Rendering

The SDK works in Angular applications that use server-side rendering, with no extra configuration. During server rendering, the SDK reports the user as logged out until the application runs in the browser.

## Call APIs in DPoP Mode

In [[DPoP]] mode, the SDK calls FusionAuth directly instead of the hosted backend, and binds each token to a key that the browser generates. A stolen DPoP token doesn't work without the key. DPoP mode requires Angular SDK `2.1.0` and FusionAuth `1.63.0` or later. To configure FusionAuth for DPoP, see [Use DPoP in a Browser App](/docs/authentication/oauth/dpop/browser-app).

To enable DPoP mode, set **`useDpop`** to `true`:

```typescript
FusionAuthModule.forRoot({
  clientId: 'e9fdb985-9173-4e01-9d73-ac2d60d1dc8e',
  serverUrl: 'http://localhost:9011',
  redirectUri: 'http://localhost:4200',
  useDpop: true,
  dpopTokenStorage: 'localStorage',
}),
```

With `localStorage`, the user stays logged in across page reloads. With `memory`, a reload logs the user out.

In DPoP mode, `FusionAuthService` also provides `dpopFetch`, `generateProof`, and `getAccessToken`. Call `dpopFetch` like `fetch`. `dpopFetch` adds the DPoP headers and retries when the server asks for a new nonce:

```typescript
const response = await this.fusionAuth.dpopFetch('https://api.example.com/data', { method: 'GET' });
```

When you use an HTTP library such as axios, build the headers with `getAccessToken` and `generateProof`:

```typescript
const accessToken = this.fusionAuth.getAccessToken();
const proof = await this.fusionAuth.generateProof('https://api.example.com/data', 'GET', accessToken ?? undefined);

await axios.get('https://api.example.com/data', {
  headers: { Authorization: `DPoP ${accessToken}`, DPoP: proof },
});
```

The three methods throw an error when **`useDpop`** is `false`.
