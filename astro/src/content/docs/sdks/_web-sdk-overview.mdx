FusionAuth sends your users to the themeable hosted login pages. After login, FusionAuth sends your users back to your {props.framework} application.

When authentication succeeds, the server sets these secure, HTTP-only cookies:

* `app.at`: an OAuth [access token](/docs/authentication/oauth/tokens#access-token).
* `app.rt`: a [refresh token](/docs/authentication/oauth/tokens#refresh-token) that the SDK uses to get a new `app.at`. The server sets this cookie only when you enable refresh tokens on your FusionAuth instance.

Present the access token to your APIs to authorize requests. Use the refresh token to get a new access token.

The SDK works with either of these servers:

* A server you host that performs the OAuth token exchange and meets the [server code requirements for FusionAuth Web SDKs](https://github.com/FusionAuth/fusionauth-javascript-sdk-express#server-code-requirements).
* The hosted backend on your FusionAuth instance, which requires no server code.

The SDK works with any version of FusionAuth and any OIDC-compliant identity server.
