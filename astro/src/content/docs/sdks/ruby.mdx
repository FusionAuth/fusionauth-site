The Ruby client library integrates FusionAuth with your Ruby application. The source code is in the [Ruby client GitHub repository](https://github.com/FusionAuth/fusionauth-ruby-client).

## Install

Install the [`fusionauth_client` gem](https://rubygems.org/gems/fusionauth_client):

```bash
gem install fusionauth_client
```

## Register a User

<ExampleAssumptions />

The following example uses the `register` method to create a User and a Registration:

```ruby
require 'fusionauth/fusionauth_client'
require 'securerandom'
require 'pp'

# Construct the FusionAuth Client
client = FusionAuth::FusionAuthClient.new(
    'REPLACE_ME',
    'http://localhost:9011'
)

application_id = '85a03867-dccf-4882-adde-1a79aeec50df'

# Create a user + registration
id = SecureRandom.uuid
response = client.register(id, {
    user: {
        firstName: 'Ruby',
        lastName: 'User',
        email: 'ruby_user@example.com',
        password: 'password'
    },
    registration: {
        applicationId: application_id,
        data: {
            foo: 'bar'
        },
        preferredLanguages: %w(en fr),
        roles: %w(dev)
    }
})

if response.success_response
  pp response.success_response
else
  if response.exception
    # no connection
    print response.exception
  end
  print "status: #{response.status}"
  print response.error_response
  exit
end

```
