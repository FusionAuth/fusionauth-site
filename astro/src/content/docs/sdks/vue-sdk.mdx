The Vue SDK provides methods and reactive values that manage authentication state in your Vue application.

## Install

For a full tutorial on FusionAuth and Vue, see the [FusionAuth Vue Quickstart](/docs/quickstarts/spa/quickstart-javascript-vue-web).

To install the SDK with npm, run:

```bash
npm install @fusionauth/vue-sdk
```

To install the SDK with Yarn, run:

```bash
yarn add @fusionauth/vue-sdk
```

## Configure the SDK

Configure and initialize the `FusionAuthVuePlugin` when you create your Vue application:

```typescript
import { createApp } from 'vue';
import FusionAuthVuePlugin, { type FusionAuthConfig } from '@fusionauth/vue-sdk';

const config: FusionAuthConfig = {
  clientId: "", // Your application's FusionAuth client Id
  serverUrl: "", // The url of the server that performs the token exchange
  redirectUri: "", // The URI that the user is directed to after the login/register/logout action
  shouldAutoFetchUserInfo: true, // Automatically fetch userInfo when logged in. Defaults to false.
  shouldAutoRefresh: true, // Enables automatic token refresh. Defaults to false.
  onRedirect: (state?: string) => { }, // Optional callback invoked upon redirect back from login or register.
  // useDpop: true, // Opt-in to DPoP mode. See "Use DPoP Mode" below. Defaults to false.
}

const app = createApp(App);

app.use(FusionAuthVuePlugin, config);
app.mount('#app')
```

For a full list of configuration options, see [Web SDK Configuration](/docs/sdks/web-sdk-configuration).

To use the pre-styled buttons, import the CSS file:

```typescript
import '@fusionauth/vue-sdk/dist/style.css';
```

### Configure with Nuxt

When you use [Nuxt](https://nuxt.com/), pass the [`useCookie`](https://nuxt.com/docs/api/composables/use-cookie) composable in the config object of your plugin definition:

```typescript
import { useCookie } from "#app";

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(FusionAuthVuePlugin, {
    ...config,
    nuxtUseCookie: useCookie,
  });
});
```

#### Define the Nuxt Plugin with createFusionAuth

The `createFusionAuth` function gives you more control over the SDK configuration:

```typescript
export default defineNuxtPlugin({
  setup(nuxtApp) {
    const fusionauth = createFusionAuth(config);
    nuxtApp.vueApp.use(FusionAuthVuePlugin, { instance: fusionauth })
    return {
      provide: { fusionauth }
    };
  },
})
```

## Usage

### Use the useFusionAuth Composable

The `useFusionAuth` composable gives your components access to the SDK through [Vue's Composition API](https://vuejs.org/guide/reusability/composables). For more information, see the [useFusionAuth API documentation](https://github.com/FusionAuth/fusionauth-javascript-sdk/blob/main/packages/sdk-vue/docs/modules.md#usefusionauth).

The following component shows a welcome message and the login, registration, and logout buttons:

```html
<script setup lang="ts">
import { computed } from 'vue';
import { useFusionAuth } from "@fusionauth/vue-sdk";

const {
  isLoggedIn,
  userInfo,
  isFetchingUserInfo,
  login,
  register,
  logout
} = useFusionAuth();

const welcomeMessage = computed(() => {
  const name = userInfo.value?.given_name
  return name
    ? `Welcome ${name}!`
    : 'Welcome!';
});
</script>

<template>
  <p>{{ welcomeMessage }}</p>

  <div v-if="isLoggedIn">
    <p v-if="isFetchingUserInfo">
      Loading...
    </p>
    <button @click="logout()">Logout</button>
  </div>

  <div v-if="!isLoggedIn">
    <button @click="login()">Login</button>
    <p>or</p>
    <button @click="register()">Register</button>
  </div>
</template>
```

### Pass State Through Login

The `login` and `register` functions accept an optional string parameter named `state`. The SDK passes the value to the optional `onRedirect` callback on your `FusionAuthConfig`. You can pass any value. A common choice is the page the user was on before login, so your application can return the user to that page after authentication.

## Use DPoP Mode

By default, the SDK calls a hosted backend that stores tokens in [[HttpOnly cookies]]. In DPoP mode, the SDK calls FusionAuth endpoints directly and binds tokens to a private key that the browser generates. To enable DPoP mode, set `useDpop` to `true` on `FusionAuthConfig`. The default is `false`.

The following configuration enables DPoP mode:

```typescript
const config: FusionAuthConfig = {
  clientId: "",
  redirectUri: "",
  serverUrl: "",
  useDpop: true, // Opt-in to DPoP mode.
  dpopTokenStorage: 'localStorage', // 'localStorage' (default, persists across reloads) or 'memory'.
}
```

When `useDpop` is `true`, `useFusionAuth()` also returns `dpopFetch`, `generateProof`, and `getAccessToken`. These values are `undefined` when `useDpop` is `false` or missing.

The following code calls an API with each function:

```html
<script setup lang="ts">
import { useFusionAuth } from "@fusionauth/vue-sdk";

const { dpopFetch, generateProof, getAccessToken } = useFusionAuth();

const response = await dpopFetch('https://api.example.com/data', { method: 'GET' });

const accessToken = getAccessToken();
const proof = await generateProof('https://api.example.com/data', 'GET', accessToken);
// axios.get('https://api.example.com/data', {
//   headers: { Authorization: `DPoP ${accessToken}`, DPoP: proof }
// });
</script>
```

In DPoP mode, the login and register redirect finishes asynchronously, because no hosted backend sets cookies before the application reloads. The SDK calls `onRedirect` only after `isLoggedIn` and the tokens are fully updated. Use `onRedirect` for post-login navigation:

```typescript
const config: FusionAuthConfig = {
  // ...
  useDpop: true,
  onRedirect: () => router.push('/account'),
}
```

## Components

### Protect Content

The `RequireAuth` and `RequireAnonymous` components restrict content based on authentication and authorization:

```html
<template>
  <RequireAuth :with-role="['ADMIN', 'SUPER-ADMIN']">
    <!-- only displays for users with specified role -->
    <button>Delete user</button>
  </RequireAuth>
</template>

<template>
  <RequireAnonymous>
    <!-- content for unauthenticated users -->
  </RequireAnonymous>
</template>
```

### Use the Pre-Built Buttons

The SDK includes pre-styled login, logout, and registration buttons. Place the buttons anywhere in your application without further configuration:

```html
<template>
  <FusionAuthLoginButton />
  <FusionAuthLogoutButton />
  <FusionAuthRegisterButton />
</template>

<style>
  :root {
    --fusionauth-button-background-color: #096324;
    --fusionauth-button-text-color: #fff;
  }
</style>
```

Set the CSS variables to match the buttons to your application's style.
