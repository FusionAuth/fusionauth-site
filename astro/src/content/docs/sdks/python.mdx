The Python client library integrates FusionAuth with your Python application. The source code is in the [Python client GitHub repository](https://github.com/FusionAuth/fusionauth-python-client).

## Install

Install the [`fusionauth-client` package from PyPI](https://pypi.org/project/fusionauth-client/):

```bash
pip install fusionauth-client
```

## Create and Retrieve a User

<ExampleAssumptions api_key="6b87a398-39f2-4692-927b-13188a81a9a3" />

The following example uses the `create_user` method to create a User. Then the example uses the `retrieve_user_by_email` method to retrieve the User by email address:

```python
from fusionauth.fusionauth_client import FusionAuthClient

# supply your own API key and URL
client = FusionAuthClient('6b87a398-39f2-4692-927b-13188a81a9a3', 'http://localhost:9011')

user_request = {
    'sendSetPasswordEmail': False,
    'skipVerification': True,
    'user': {
        'email': 'art@vandaleyindustries.com',
        'password': 'password'
    }
}

client_response = client.create_user(user_request)

# Create a User
if client_response.was_successful():
    print(client_response.success_response)
else:
    print(client_response.error_response)

# Retrieve a user by email address
client_response = client.retrieve_user_by_email('art@vandaleyindustries.com')
if client_response.was_successful():
    print(client_response.success_response)
else:
    print(client_response.error_response)
```
