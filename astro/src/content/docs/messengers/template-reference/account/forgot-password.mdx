FusionAuth sends this message when a user starts the forgot password workflow with a phone number, on the hosted login pages or through the [Forgot Password](/docs/apis/users/forgot-password) API. The default template is also known as the Change Password template. Assign the template in **Forgot password** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
