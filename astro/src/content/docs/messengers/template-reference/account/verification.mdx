FusionAuth sends this message to verify a phone number: after a user registers or changes a phone number, when you call the [Identity Verify](/docs/apis/identity-verify) API, and for [identity pre-verification](/docs/users/verify/identity-pre-verification-using-phone). Assign the template in **Verification template** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set **Verification template** on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.

## Replacement Variables

<APIBlock>
  <Variable kind="message" name="application" />
  <Variable kind="message" name="baseUrl" />
  <Variable kind="message" name="phoneNumber" description="The phone number to verify." />
  <APIField name="state" type="Object">
    The **`state`** from the verification request. The variable is present only when the request includes **`state`**.
  </APIField>
  <Variable kind="message" name="tenant" />
  <APIField name="verificationId" type="String">
    The verification Id for the [Identity Verify](/docs/apis/identity-verify) API.
  </APIField>
  <APIField name="verificationOneTimeCode" type="String">
    The one-time code for the `FormField` verification strategy. The user enters the code to verify the phone number.
  </APIField>
</APIBlock>

The template receives no **`user`**, because FusionAuth can send the message before the user exists, during identity pre-verification. Use **`phoneNumber`** to refer to the recipient.
