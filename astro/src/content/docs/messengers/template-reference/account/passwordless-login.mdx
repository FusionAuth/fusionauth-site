FusionAuth sends this message when a user requests a passwordless login with a phone number, on the hosted login pages or through the [Passwordless](/docs/apis/passwordless) API. Assign the template in **Passwordless login** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.

## Replacement Variables

<APIBlock>
  <Variable kind="message" name="application" />
  <Variable kind="message" name="baseUrl" />
  <APIField name="code" type="String">
    The code for the [Complete a Passwordless Login](/docs/apis/passwordless/complete-a-passwordless-login) API. Put the code in a login link.
  </APIField>
  <APIField name="oneTimeCode" type="String">
    The one-time code the user enters on a form, for the `FormField` login strategy. Check for the variable before you use it, as the default template does.
  </APIField>
  <Variable kind="message" name="phoneNumber" />
  <APIField name="state" type="Object">
    The **`state`** from the passwordless start request. The variable is present only when the request includes **`state`**.
  </APIField>
