FusionAuth sends this message when you create a user without a password and set **`sendSetPasswordIdentityType`** to `phone` on the [Create a User](/docs/apis/users/create) request. Assign the template in **Set up password** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
