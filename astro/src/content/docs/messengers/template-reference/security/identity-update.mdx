FusionAuth sends this message when a user's phone number changes. FusionAuth sends the message to the previous phone number, then to the new phone number. When the change removes the phone number, only the previous phone number gets the message. Assign the template in **Identity update** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
