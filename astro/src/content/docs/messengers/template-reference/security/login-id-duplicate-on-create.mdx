<PlanBlurb plan="enterprise" />

FusionAuth sends this message when someone tries to create a user with an email address, username, or phone number that already belongs to another user. The message goes to the phone number of the existing account in **`event.existing`**, whichever login Id matched. Don't put details about **`user`** in the message, because the recipient doesn't own that account. Assign the template in **Login Id duplicate on create** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
