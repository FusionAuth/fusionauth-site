FusionAuth sends this message when a user's password changes outside the forgot password workflow, such as through the [Update a User](/docs/apis/users/update) API or the self-service account pages. For the forgot password workflow, see [Password Reset Success](/docs/messengers/template-reference/security/password-reset-success). Assign the template in **Password update** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
