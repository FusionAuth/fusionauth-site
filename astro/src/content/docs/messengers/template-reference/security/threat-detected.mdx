<PlanBlurb plan="enterprise" />

FusionAuth sends this message when a user logs in from a new device, or when a login is suspicious. The default template handles both cases by checking **`event.type`**. Assign the template in **Login with new device**, **Suspicious login**, or both, on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab. For more about the events, see [Advanced Threat Detection](/docs/security/account-protection/advanced-threat-detection).
