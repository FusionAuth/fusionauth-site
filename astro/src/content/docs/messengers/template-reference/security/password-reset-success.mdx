FusionAuth sends this message after a user completes the forgot password workflow. For other password changes, see [Password Update](/docs/messengers/template-reference/security/password-update). Assign the template in **Password reset success** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
