FusionAuth sends this message when an administrator removes one of a user's two-factor methods in the Admin UI. FusionAuth sends the message only to a verified phone number. Assign the template in **Admin two-factor method removal** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab.
