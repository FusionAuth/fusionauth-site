Password hashing plugins let FusionAuth check passwords that an old system hashed with a scheme FusionAuth doesn't support. Password hashing is the only extension point that plugins offer.

To add a plugin to FusionAuth:

1. Write the plugin by implementing the `PasswordEncryptor` interface.
1. Install the plugin, and restart FusionAuth. FusionAuth loads plugins only at startup.

Leave a password hashing plugin installed while any user's password uses the plugin's scheme. For more information, see [Remove a Plugin](/docs/migrate/password-hashes/custom-password-hashing#remove-a-plugin).
