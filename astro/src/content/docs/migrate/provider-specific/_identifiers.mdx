When you create an object with the FusionAuth API, you can set the object's Id. The Id must be a [UUID](/docs/apis/data-types#uuids). Users, Applications, Tenants, and most other objects accept an Id.

When other systems depend on the Ids in {props.migration_source_name}, keep the Ids:

* When an Id is a valid UUID, set the same Id on the FusionAuth object.
* Otherwise, store the old Id in **`user.data`**, such as in **`user.data.original_user_id`**. You can then search for a user by the old Id.
