When FusionAuth doesn't send email codes, check the SMTP settings. For more information, see [Email Troubleshooting](/docs/deploy/troubleshoot/troubleshooting#troubleshooting-email).

When FusionAuth doesn't send SMS or voice codes, test the messenger, turn on debugging for the messenger, and check the Event Log at <Breadcrumb>System -> Event Log</Breadcrumb>.

When a user has an MFA method but FusionAuth doesn't ask for a code at login, check the following:

* The Tenant turns on the user's method. FusionAuth doesn't challenge a user whose only methods the Tenant turns off.
* The login policy of the Tenant or the Application. A risk-based policy skips the challenge when the risk is below the policy level.
* Whether the user chose to trust the device at an earlier login.

When FusionAuth asks for a code but can't send one, check that the Tenant turns on the method and the message type, such as SMS or voice. For more information, see [Turn Off an MFA Method](/docs/authentication/multi-factor-authentication/contextual#turn-off-an-mfa-method).
