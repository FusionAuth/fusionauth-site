After a user logs in, FusionAuth and each of your applications keep a session for the user. The FusionAuth [[SSO session]] logs the user in to every Application in a Tenant. Your applications decide how long their own sessions last, and can hand that control to FusionAuth with refresh tokens. For how the sessions fit together, start with [How Sessions Work](/docs/authentication/sessions/how-sessions-work).

Choose a page by task:

* To let users log in once for every application, see [Enable SSO](/docs/authentication/sessions/enable-sso).
* To change how long users stay logged in, see [Configure Session Lifetimes](/docs/authentication/sessions/configure-session-lifetimes).
* To log users out of one application or all of them, see [Log Users Out](/docs/authentication/sessions/log-users-out).
* To end a user's sessions from the Admin UI or a server, see [View and Revoke Sessions](/docs/authentication/sessions/revoke-sessions).
* To look up a timeout, unit, or default, see [Session Settings](/docs/authentication/sessions/session-settings).
