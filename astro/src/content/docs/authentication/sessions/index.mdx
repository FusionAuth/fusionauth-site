After a user logs in, FusionAuth and each of your applications keep a session for the user. The FusionAuth [[SSO session]] logs the user in to every Application in a Tenant. Your applications decide how long their own sessions last, and can hand that control to FusionAuth with refresh tokens. For a high-level overview, see [How Sessions Work](/docs/authentication/sessions/how-sessions-work).

Choose a page by task:

* To let users log in once for every application, see [Enable SSO](/docs/authentication/sessions/enable-sso).
* To change how long users stay logged in, see [Configure Session Lifetimes](/docs/authentication/sessions/configure-session-lifetimes).
* To log users out of one application or all of them, see [Log Users Out](/docs/authentication/sessions/log-users-out).
* To end a user's sessions from the Admin UI or a server, see [View and Revoke Sessions](/docs/authentication/sessions/revoke-sessions).
* To look up a timeout, unit, or default, see [Session Settings](/docs/authentication/sessions/session-settings).

## Runnable Examples

The following example repositories are complete, runnable versions of the tasks, each with a Docker Compose file and a Kickstart that configure FusionAuth:

* [SSO and front-channel logout](https://github.com/FusionAuth/fusionauth-example-node-sso) between two Express applications. For the steps, see [Log Users Out](/docs/authentication/sessions/log-users-out).
* [An application dashboard](https://github.com/FusionAuth/fusionauth-example-multiapp-dashboard) in a custom theme Index page. For the steps, see [Enable SSO](/docs/authentication/sessions/enable-sso#link-to-your-applications-from-one-page).
* [Centralized sessions](https://github.com/FusionAuth/fusionauth-example-node-centralized-sessions) across two applications. For the steps, see [Centralized Sessions](/docs/authentication/sessions/centralized-sessions).
* [A device limit enforced by a webhook](https://github.com/FusionAuth/fusionauth-example-device-limit-simple) and [a device limit with a session picker](https://github.com/FusionAuth/fusionauth-example-device-limit-friendly). For the steps, see [Limit Concurrent Sessions](/docs/authentication/sessions/limit-concurrent-sessions).
