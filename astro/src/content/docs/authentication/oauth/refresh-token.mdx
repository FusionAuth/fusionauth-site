Access tokens expire quickly. A [[Refresh Token]] lasts longer. Your app exchanges the refresh token for a new access token without asking the user to log in again.

To issue refresh tokens, turn on **Generate refresh tokens** and enable `Refresh Token` in **Enabled grants** on the <Breadcrumb>OAuth</Breadcrumb> tab of the Application. New Applications have both settings on. Your app then gets a refresh token from the [[token endpoint]] when the request asks for the `offline_access` scope.

## Exchange a Refresh Token for an Access Token

Send the refresh token to the `/oauth2/token` endpoint with **`grant_type`** set to `refresh_token`. The example uses the refresh token from the [Authorization Code grant example](/docs/authentication/oauth/authorization-code#exchange-the-code-for-tokens), and adds line breaks for readability.

```plaintext title="Example HTTP Request"
POST /oauth2/token HTTP/1.1
Host: piedpiper.fusionauth.io
Content-Type: application/x-www-form-urlencoded

client_id=06494b74-a796-4723-af44-1bdb96b48875
    &client_secret=example-client-secret-do-not-use
    &grant_type=refresh_token
    &refresh_token=ze9fi6Y9sMSf3yWp3aaO2w7AMav2MFdiMIi2GObrAi-i3248oo0jTQ
```

Replace `example-client-secret-do-not-use` with the **Client secret** from the <Breadcrumb>OAuth</Breadcrumb> tab of your Application.
