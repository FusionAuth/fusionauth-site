FusionAuth supports the OAuth 2.0 grants defined in [RFC 6749](https://tools.ietf.org/html/rfc6749), [RFC 8628](https://tools.ietf.org/html/rfc8628), and [RFC 8693](https://datatracker.ietf.org/doc/html/rfc8693), plus [OpenID Connect Core](https://openid.net/specs/openid-connect-core-1_0.html) and [RFC 9207](https://www.rfc-editor.org/rfc/rfc9207) issuer identification. A grant is the series of requests an app makes to get tokens. Use the Authorization Code grant to log users in, unless your app has a requirement that another grant meets better.

| Grant | Use the grant when |
|---|---|
| [Authorization Code](/docs/authentication/oauth/authorization-code) | A user logs in to a web, single-page, or mobile app. |
| [Refresh Token](/docs/authentication/oauth/refresh-token) | Your app needs a new access token without asking the user to log in again. |
| [Client Credentials](/docs/authentication/oauth/client-credentials) | One service calls another service with no user involved. |
| [Device Authorization](/docs/authentication/oauth/device) | A user logs in on a device with no browser or keyboard, such as a TV. |
| [Token Exchange](/docs/authorization/token-exchange-delegation) | A service calls another service on behalf of a user. Requires the Enterprise plan and FusionAuth `1.70.0` or later. |
| [Implicit](/docs/authentication/oauth/legacy-grants#implicit-grant) | An existing integration already uses the grant. Don't use the grant for new apps. |
| [Password](/docs/authentication/oauth/legacy-grants#password-grant) | An existing integration already uses the grant. Don't use the grant for new apps. |

Every grant except Client Credentials runs against an Application. Configure the Application first, as described in [Configure Application OAuth Settings](#configure-application-oauth-settings). The Client Credentials grant runs between [[Entity::Entities]] instead. See [Configure Entities](/docs/authentication/oauth/client-credentials#configure-entities).

[OAuth Modes](/docs/authentication/oauth/modes) describe higher-level ways to use OAuth, built from the individual grants. [Response Modes](/docs/authentication/oauth/response-modes) control how FusionAuth delivers authorization response parameters to your app: `query`, `fragment`, or `form_post`.

## Configure Application OAuth Settings

Each app that logs users in through FusionAuth needs an Application with OAuth settings. To add an Application, navigate to <Breadcrumb>Applications</Breadcrumb> and click <IconButton icon="add" />. To configure an existing Application, click <IconButton icon="edit" /> on the Application. Then fill out the <Breadcrumb>OAuth</Breadcrumb> tab. The example shows an Application named `Pied Piper`:

### OAuth Scopes

Grants that involve a user accept a space-delimited list of OAuth scopes in the **`scope`** parameter. To configure scope policies, add custom scopes, or ask users to consent to scopes for third-party apps, see [Scopes](/docs/authorization/oauth-scopes).
