Managed domains connect email domains, such as `example.com`, to an Identity Provider. The OpenID Connect, SAML v2, and External JWT Identity Providers support managed domains. The [Lookup API](/docs/apis/identity-providers/#lookup-an-identity-provider) uses managed domains to find the Identity Provider for an email address.

## Managed Domains on the Login Page

The OpenID Connect and SAML v2 Identity Providers use managed domains on the FusionAuth login page. When users share an email domain, managed domains shorten the login:

1. The login page asks the user for an email address.
1. When the email domain matches a managed domain of an Identity Provider, FusionAuth redirects the user to the Identity Provider to authenticate.
1. When the email domain doesn't match, the user continues with the standard email and password login.

When you enable an Identity Provider with managed domains for an Application, the login page of the Application changes for every user. Every user must enter an email address first.

## Managed Domains for External JWT

The External JWT Identity Provider has no login page. The [Reconcile API](/docs/apis/jwt/reconcile-a-jwt-using-the-external-jwt-provider) checks the email address in a JWT against the managed domains, and rejects a JWT whose email address isn't in a managed domain. FusionAuth skips the check for a JWT without an email address. For more information, see [Add an External JWT IdP](/docs/authentication/identity-providers/external-jwt#managed-domains).

## Domain Rules

One Identity Provider can manage several email domains, and several Identity Providers can have managed domains. In each Tenant, at most one Identity Provider can manage an email domain. Across a FusionAuth instance, an email domain belongs to one of the following:

* A single global Identity Provider
* Any number of tenant-scoped Identity Providers

For more information about global and tenant-scoped Identity Providers, see [Identity Provider Scope](/docs/authentication/identity-providers/identity-provider-scope).

## Configure Managed Domains

To configure managed domains, navigate to <Breadcrumb>Settings -> Identity Providers</Breadcrumb> in the Admin UI, and edit an OpenID Connect, SAML v2, or External JWT Identity Provider. On the <Breadcrumb>Managed domains</Breadcrumb> tab, enter one domain on each line.
