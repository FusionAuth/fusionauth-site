Add a Login with Facebook button to the FusionAuth login page. This guide shows how to collect the credentials from Facebook and configure the Facebook Identity Provider, a [[Social login]] option.

After you configure the Identity Provider, you can enable the Facebook login button for one or more FusionAuth Applications. The following login page shows the Facebook Identity Provider:

## Create a Facebook Account

When you don't have a Facebook account, create one at [Facebook](https://www.facebook.com/).

## Add a Facebook Application

The Login with Facebook option needs a Facebook application. To create one, open your [Facebook developer account](https://developers.facebook.com/apps/).

### Create a New App Id

Click <Breadcrumb>Create App</Breadcrumb>. Facebook shows the **Display Name** of the application to users when they log in to FusionAuth with Facebook. Complete the form and click <Breadcrumb>Create App</Breadcrumb>.

![The Facebook form to add a new application.](/img/docs/lifecycle/authenticate-users/identity-providers/social/facebook-add-new-app-id.png)

### Configure Facebook Login

Add the <Breadcrumb>Facebook Login</Breadcrumb> product to the new application:

<Steps>

1. Open the <Breadcrumb>Add a Product</Breadcrumb> page. Facebook usually shows the page after you create the application. Otherwise, find the <Breadcrumb>Products +</Breadcrumb> or <Breadcrumb>Add Product</Breadcrumb> section.
1. On the <Breadcrumb>Facebook Login</Breadcrumb> tile, click <Breadcrumb>Set Up</Breadcrumb>. The <Breadcrumb>Products</Breadcrumb> section of the application now lists <Breadcrumb>Facebook Login</Breadcrumb>.
1. In the left navigation, under <Breadcrumb>Facebook Login</Breadcrumb>, click <Breadcrumb>Settings</Breadcrumb>.
1. Review the settings against your security requirements. The default Client OAuth Settings usually work.
1. When you use the redirect login method, add the absolute URL of the FusionAuth callback endpoint, such as `https://login.piedpiper.com/oauth2/callback`, to **Valid OAuth Redirect URIs**.
1. When you use the popup login method, fill in **App Domains**, **User Data Deletion**, and **Privacy Policy URL**. In **App Domains**, add the top-level domain of the login page. For example, a login page at `https://login.piedpiper.com` needs `piedpiper.com`.

</Steps>

![The Facebook Login settings page.](/img/docs/lifecycle/authenticate-users/identity-providers/social/facebook-login-settings.png)

### Collect the App ID and App Secret

The FusionAuth configuration needs the **App ID** and the **App Secret**. To find the values, navigate to <Breadcrumb>Settings -> Basic</Breadcrumb> in the left navigation. Record the values, or keep the page open to copy the values in the next step.

The application starts in `development` mode. To make the application public, switch <Breadcrumb>App Mode</Breadcrumb> to `live`. Facebook then asks you to complete other settings. You can log in with the application in `development` mode.

![The Facebook basic application settings, with the App ID and App Secret.](/img/docs/lifecycle/authenticate-users/identity-providers/social/facebook-app-basic-settings.png)

## Create a Facebook Identity Provider

Create the Facebook Identity Provider in FusionAuth. Fill in **App Id** and **App secret** with the values from the Facebook console. **Button text** is required and defaults to `Login with Facebook`.

### Form Fields

<APIBlock>
  <APIField name="Id" optional since="1.61.0">
    An optional UUID. When you leave out the Id, FusionAuth generates a unique Id.
  </APIField>
  <APIField name="Tenant" optional since="1.62.0">
    The Tenant that this Identity Provider belongs to. The field appears only when you select a specific Tenant on the previous page. When you select `Global identity provider` on the previous page, the field doesn't appear.
  </APIField>
  <APIField name="Name" required since="1.61.0">
    A unique name for the Identity Provider. FusionAuth uses the name for display only, and you can change the name later.
  </APIField>
  <APIField name="App Id" required>
    The **App ID** from the settings of your Facebook application.
  </APIField>
  <APIField name="App secret" required>
    The **App Secret** from the settings of your Facebook application.
  </APIField>
  <APIField name="Button text" required>
    The text of the button on the login form. The default value is `Login with Facebook`.
  </APIField>
  <APIField name="Fields" optional defaults="email">
    The fields that FusionAuth requests from the user during login. `email` is the minimum that login requires. When you leave the field blank during an edit, FusionAuth keeps the existing value.

    To request more fields, such as the name and birthday, list the fields: `email,name,first_name,last_name,birthday`. For more information, see the [Facebook Graph API documentation](https://developers.facebook.com/docs/graph-api/using-graph-api/).
  </APIField>
  <APIField name="Login Method" optional>
    What happens after the user clicks the Identity Provider button, such as `Login with Facebook`:

    * `Use redirect for login`: FusionAuth redirects the user to a Facebook login page. After the user authenticates, Facebook redirects the user back to FusionAuth. Set the [[redirect URL]] to an absolute URL in the Facebook console for your application. For a hostname of `login.piedpiper.com`, the redirect URL is `https://login.piedpiper.com/oauth2/callback/`.
    * `Use popup for login`: FusionAuth opens a popup where the user logs in with Facebook. After the user authenticates, the popup closes. Fill in **App Domain**, **User Data Deletion**, and **Privacy Policy URL** in your Facebook application settings, and turn on **Login with the JavaScript SDK**.

    When the OAuth [[Authorize endpoint]] request includes an `idp_hint`, FusionAuth uses the redirect method, even when you select `Use popup for login`.
  </APIField>
  <APIField name="Permissions" optional defaults="email">
    The permissions that FusionAuth requests from the user during login. `email` is the minimum that login requires. When you leave the field blank during an edit, FusionAuth keeps the existing value. For more information, see the [Facebook Login documentation](https://developers.facebook.com/docs/facebook-login/).
  </APIField>
  <APIField name="Linking strategy" optional>
    How FusionAuth links a Facebook user to a FusionAuth user. For more information, see [Linking Strategies](/docs/authentication/identity-providers/linking-strategies).

    <LinkingStrategyEditLimit />
  </APIField>
  <APIField name="Reconcile lambda" optional since="1.17.0">
    A lambda that maps custom claims from Facebook to the user.

    To create a lambda, navigate to <Breadcrumb>Customizations -> Lambdas</Breadcrumb>.
  </APIField>
  <APIField name="Enable debug logging" optional defaults="false">
    Creates Event Log entries that help you debug integration errors. To read the entries, navigate to <Breadcrumb>System -> Event Log</Breadcrumb>.
  </APIField>
</APIBlock>
