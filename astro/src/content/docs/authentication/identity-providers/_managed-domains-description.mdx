The email domains that this Identity Provider manages, one domain on each line. For example, to use the {props.type} Identity Provider only for employees, add the company domain, such as `piedpiper.com`.

With managed domains, the login page doesn't show a button for this Identity Provider. Instead, the login page first asks the user for an email address. When the email address matches a managed domain, FusionAuth redirects the user to this Identity Provider to authenticate. Otherwise, the login page asks for a password, and FusionAuth authenticates the user.

The [Lookup API](/docs/apis/identity-providers/#lookup-an-identity-provider) also uses managed domains. For more information, see [Managed Domains](/docs/authentication/identity-providers/managed-domains).
