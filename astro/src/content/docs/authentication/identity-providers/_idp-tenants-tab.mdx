The <Breadcrumb>Tenants</Breadcrumb> tab limits the number of links that each user in a Tenant can have to this Identity Provider. Links to other Identity Providers don't count toward the limit. On a global Identity Provider, the tab starts empty. To set a limit for a Tenant, click <Breadcrumb>Add tenant configuration</Breadcrumb>. On a tenant-scoped Identity Provider, the tab lists only the Identity Provider's Tenant.

<APIBlock>
  <APIField name="Limit links per user" optional defaults="false" since="1.32.0">
    When turned on, FusionAuth enforces **Maximum link count** for users in the Tenant.
  </APIField>
  <APIField name="Maximum link count" optional since="1.32.0">
    The maximum number of links that a user can have to this Identity Provider. When a user reaches the limit, FusionAuth rejects a new link. The [Link API](/docs/apis/identity-providers/links) returns a `400`, and the hosted login pages show an error.
  </APIField>
</APIBlock>

For more information, see [Identity Providers and Tenants](/docs/authentication/identity-providers/identity-provider-scope#link-limits).
