With the FusionAuth [[hosted login pages]], a hint skips the login page and sends the user straight to an Identity Provider. A hint names an Identity Provider Id, an email address, or an email domain.

<Aside type="note">
Hints work with most Identity Providers. An `idp_hint` for a HYPR or SAML v2 IdP Initiated Identity Provider shows an error that the Identity Provider doesn't support the redirect workflow.
</Aside>

## Hint by Identity Provider Id

Add the `idp_hint` parameter with an Identity Provider Id to the Login URL of an Application. For example, to send a user straight to the login page of the OpenID Connect Identity Provider with the Id `44449786-3dff-42a6-aac6-1f1ceecb6c46`, append `&idp_hint=44449786-3dff-42a6-aac6-1f1ceecb6c46`.

## Hint by Email Address or Domain

Add the `login_hint` parameter with an email address or a domain to the Login URL of an Application. For example, to send a user straight to the login page of an OpenID Connect Identity Provider with the managed domain `example.com`, append `&login_hint=example.com`. The Identity Provider decides how to use the parameter, so some Identity Providers may not support `login_hint`. For more information about managed domains, see [Managed Domains](/docs/authentication/identity-providers/managed-domains).

For more information about the `login_hint` and `idp_hint` parameters, see the [OAuth endpoints](/docs/apis/oauth).
