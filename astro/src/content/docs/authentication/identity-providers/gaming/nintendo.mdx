## Create a Nintendo Developer Account

Log in to the Nintendo Developer Portal with an existing account, or create a Nintendo developer account. Copy the client Id and the client secret of an existing application, or request them by following the Nintendo documentation. For more information, contact Nintendo Developer support. For the portal, see the [Nintendo Developer Portal](https://developer.nintendo.com).

### Options

The <Breadcrumb>Options</Breadcrumb> tab sets the names of the claims that FusionAuth reads from Nintendo.

<Screenshot id="idp-nintendo-options" url="/admin/identity-provider/add/Nintendo?identityProvider.tenantId=30663132-6464-6665-3032-326466613934&global=false#options" crop="#screenshot-band" cropPadding={0} alt="The Options tab of the Nintendo Identity Provider form." />

<APIBlock>
  <APIField name="Unique Id claim" optional defaults="id">
    The name of the claim that contains the immutable unique Id of the user.
  </APIField>
  <APIField name="Email claim" optional defaults="email">
    The name of the claim that contains the user's email address.
  </APIField>
  <APIField name="Username claim" optional defaults="preferred_username">
    The name of the claim that contains the user's username.
  </APIField>
</APIBlock>
