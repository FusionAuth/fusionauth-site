## Create an Epic Games Account

Get a client Id and a client secret from the [Epic Games Developer Portal](https://dev.epicgames.com/portal/). For instructions, see [Get Started with Epic Account Services](https://dev.epicgames.com/docs/epic-online-services/accounts-and-social/eos-epic-account-services/getting-started#authenticate-on-a-web-site).

In the Epic Games Developer Portal, enable the `basic_profile` permission for the application. Then set **Scope** on the Identity Provider to `basic_profile`. FusionAuth reads the account Id and the display name from Epic Games. Epic Games doesn't share the email address of the user.
