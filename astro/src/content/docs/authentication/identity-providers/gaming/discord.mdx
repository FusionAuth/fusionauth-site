Add a <Breadcrumb>Login with Discord</Breadcrumb> button to the FusionAuth login pages. FusionAuth connects to Discord through the OpenID Connect Identity Provider. After you configure the Identity Provider, you can enable the button for one or more Applications.

For more information about Discord OAuth, see [Discord OAuth2](https://docs.discord.com/developers/topics/oauth2/).

## Register a Discord OAuth2 Application

<Steps>

1. Log in to the [Discord Developer Portal](https://discord.com/developers/applications/), and create an application.
1. In the left navigation, open <Breadcrumb>Selected App -> Settings -> OAuth2</Breadcrumb>.

   ![The Discord OAuth2 settings for an application, with the client Id, the client secret, and a redirect URL.](/img/docs/lifecycle/authenticate-users/identity-providers/gaming/discord-openid-connect-register-application.png)

1. Add the [[redirect URL]] of FusionAuth, which is the FusionAuth URL followed by `/oauth2/callback`. For FusionAuth at `https://login.piedpiper.com`, the redirect URL is `https://login.piedpiper.com/oauth2/callback`.
1. Copy the `CLIENT ID` and the `CLIENT SECRET`. The FusionAuth Identity Provider needs both values.

</Steps>

## Configure the OpenID Connect Identity Provider

<Steps>

1. In the Admin UI, navigate to <Breadcrumb>Settings -> Identity Providers</Breadcrumb>, and add an OpenID Connect Identity Provider. For the full add steps, see [Add an OpenID Connect IdP](/docs/authentication/identity-providers/overview-oidc#create-an-openid-connect-identity-provider).
1. Set **Client Id** and **Client secret** to the `CLIENT ID` and `CLIENT SECRET` values from Discord.
1. Set **Button text** to `Login with Discord`.
1. Turn off **Discover endpoints**. Discord documents the user fields of the `/users/@me` endpoint, not the userinfo endpoint in the Discord discovery document. Enter the following endpoints:

   * **Authorization endpoint**: `https://discord.com/oauth2/authorize`
   * **Token endpoint**: `https://discord.com/api/v10/oauth2/token`
   * **Userinfo endpoint**: `https://discord.com/api/v10/users/@me`

1. Set **Scope** to `identify email`.
1. Set **Client authentication** to `Request body (client_secret_post)`. Discord also accepts `HTTP basic authentication (client_secret_basic)`.
1. On the <Breadcrumb>Options</Breadcrumb> tab, set **Unique Id claim** to `id` and **Email verified claim** to `verified`. Discord doesn't use the standard claim names. Without `verified`, FusionAuth links on Discord email addresses that Discord hasn't verified. For more information, see [Options](/docs/authentication/identity-providers/overview-oidc#options).

   <Screenshot id="idp-discord-options" url="/admin/identity-provider/edit/OpenIDConnect/00000000-0000-0000-0000-f20000000104#options" crop="#screenshot-band" cropPadding={0} alt="The Options tab of an OpenID Connect Identity Provider for Discord, with the Discord claim names." />

1. On the <Breadcrumb>Applications</Breadcrumb> tab, turn on **Enabled** for each Application that offers Discord login. To register new users for an Application, turn on **Create registration**.
1. Click <IconButton icon="save" />.

</Steps>

The login page of each enabled Application then shows the <Breadcrumb>Login with Discord</Breadcrumb> button.

## Add Discord Profile Data

The Discord implementation of OpenID Connect doesn't follow the full specification. To add more profile data to the user, such as the Discord username and the avatar URL, set a **Reconcile lambda** on the Identity Provider. For more information, see the [OpenID Connect reconcile lambda](/docs/lambdas/reconcile/openid-connect-response-reconcile).
