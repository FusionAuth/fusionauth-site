## Create an Xbox Account

Get a client Id and a client secret from Microsoft. Register an application in the Azure Portal under Microsoft Entra ID, and set the supported account types to personal Microsoft accounts only. For more information, see [Xbox Services Sign-In for Title Websites](https://learn.microsoft.com/en-us/gaming/gdk/docs/services/fundamentals/s2s-auth-calls/service-authentication/live-website-authentication).

Set **Scope** on the Identity Provider to `XboxLive.signin XboxLive.offline_access`. Microsoft requires `XboxLive.signin` to issue Xbox tokens, and approves the scope for each application. `XboxLive.offline_access` returns a refresh token, which FusionAuth stores. Microsoft doesn't allow other scopes in the same request. FusionAuth reads the gamertag and the Xbox user Id, and doesn't receive an email address.
