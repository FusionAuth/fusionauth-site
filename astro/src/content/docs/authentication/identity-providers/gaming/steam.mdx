## Create a Steam Account

Get a client Id and a Web API key from Steam. Steam doesn't offer a self-service client Id. To request a client Id, contact Valve. For the request details, see [Steam OAuth](https://partner.steamgames.com/doc/webapi_overview/oauth).

Steam offers user Web API keys and publisher Web API keys. For more information, see [Authentication Using Web API Keys](https://partner.steamgames.com/doc/webapi_overview/auth).
