## Create a Sony PlayStation Network Account

Get a client Id and a client secret from Sony. Sony publishes PlayStation Network OAuth documentation only to approved partners. To apply, register at [PlayStation Partners](https://partners.playstation.net/).

Sony assigns the scopes for each client. Set **Scope** on the Identity Provider to the scope string from Sony, such as `psn:s2s`. FusionAuth reads the user Id, the Online ID, and the email address from Sony.
