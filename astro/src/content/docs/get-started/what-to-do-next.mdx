You have a running instance of FusionAuth and an admin account. If you haven't finished [First Time Setup](/docs/get-started/first-time-setup) yet, start there. Then pick the task that matches your next goal.

## Add Login to Your App

* Follow a [quickstart](/docs/quickstarts) for your language or framework. Each quickstart adds login and logout to a sample app.
* [Add an application](/docs/concepts/types/applications#add-an-application) in the Admin UI. Every app that users log into needs an application in FusionAuth.
* Decide between the [hosted login pages and the Login API](/docs/authentication#hosted-login-pages-or-the-login-api).
* Learn [how FusionAuth works](/docs/concepts): tenants, applications, users, and registrations.

## Create and Manage Users

* Let users [sign themselves up](/docs/users/register/basic-registration-forms).
* [Register a user and log in](/docs/users/register/register-user-login-api) with the API.
* [Verify email addresses](/docs/users/verify/gate-accounts-until-user-email-verified) before users can log in.
* Bring existing users from another system with a [migration](/docs/migrate).

## Call the API

* Create an [API key](/docs/apis/authentication) in the Admin UI.
* Install a [client library](/docs/sdks) for your language.
* Browse the [API reference](/docs/apis).

## Add Login Methods

* Enable [passkeys](/docs/authentication/passkeys) or [one-time passwords](/docs/authentication/one-time-passwords).
* Require [multi-factor authentication](/docs/authentication/multi-factor-authentication).
* Let users log in with Google, Apple, or another [identity provider](/docs/authentication/identity-providers).

## Control Access

* Give users [roles](/docs/concepts/types/roles) in each application.
* Learn the other options in [Authorization](/docs/authorization).

## Customize the Experience

* Match your brand with a [theme](/docs/theme) for the hosted login pages.
* [Configure an email server](/docs/get-started/first-time-setup#configure-an-email-server) and customize the [email templates](/docs/email).
* Add claims to tokens with a [lambda](/docs/lambdas).

## React to Changes

* Send [webhooks](/docs/events) to your app when users log in, register, or change.

## Protect Your Users

* Turn on [CAPTCHA](/docs/security/account-protection/advanced-threat-detection#captcha) and [rate limiting](/docs/security/account-protection/advanced-threat-detection#customizable-rate-limiting).
* Review the other options in [Security](/docs/security).

## Prepare for Production

* Write [tests that run against a real instance](/docs/deploy/test/test-against-fusionauth).
* Plan your [production deployment](/docs/deploy).
* [Harden your instance](/docs/deploy/harden/harden-a-production-instance) before customers log in.
