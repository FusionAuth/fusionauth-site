This QuickStart adds login and a protected page to an Angular web app using a preconfigured, local version of FusionAuth in the following steps:

1. Create a new Angular app.
1. Customize the app with home and account pages.
1. Add login to protect the account page.
1. Add a button to the account page to fetch the user's information.

## Prerequisites

This QuickStart requires:

* [Node.js](https://nodejs.org/en/download) 26 or later
* [Docker](https://docs.docker.com/get-started/get-docker/) 23 or later
* On macOS and Windows, one of the following container management tools:
  * [Docker desktop](https://www.docker.com/products/docker-desktop/)
  * [OrbStack](https://docs.orbstack.dev/quick-start) (to use Orbstack for `docker compose` commands after install, run `docker context use orbstack`)
  * [Podman](https://podman.io/docs/installation) (in the commands below, replace `docker` with `podman`)

Be sure to open your container management tool to configure and install any dependencies needed by that tool, including Rosetta and Developer Tools on macOS.

## Install and Run FusionAuth

To begin, clone the [GitHub repository for this QuickStart](https://github.com/FusionAuth/fusionauth-quickstart-javascript-angular-web) to your local machine:

```shell-session
git clone https://github.com/FusionAuth/fusionauth-quickstart-javascript-angular-web
```

The repository contains:

* `backend_fusionauth`, a preconfigured version of FusionAuth
* `frontend_steps`, a runnable version of each development step of the Angular application

Navigate to `fusionauth-quickstart-javascript-angular-web/backend_fusionauth`:

```shell-session
cd fusionauth-quickstart-javascript-angular-web/backend_fusionauth
```

If you are not using Linux, then open OrbStack or Docker Compose to start the docker daemon.

To start a local instance of FusionAuth, run the following command:

```shell-session
docker compose up
```

<Aside type="note">
During the Docker compose process, the included `kickstart/kickstart.json` file uses the FusionAuth API to:

* Generate an API key
* Configure CORS (<Breadcrumb>Settings -> System -> CORS</Breadcrumb>)
* Create your app ("QuickStart App") with appropriate settings and redirect URIs (<Breadcrumb>Applications -> Edit Application</Breadcrumb>).
* Create an admin user (admin@example.com) and register the user with your app (<Breadcrumb>Users</Breadcrumb>)
* Create a user (richard@example.com) and register the user with your app
* Create a custom theme ("QuickStart Theme") using `backend_fusionauth/kickstart/css/styles.css` and apply it to your default tenant (<Breadcrumb>Customizations -> Themes</Breadcrumb>)
</Aside>

Once Docker compose completes, open a browser window and navigate to the Admin UI of your FusionAuth instance at [http://localhost:9011/admin](http://localhost:9011/admin). Use the following admin account credentials to log in:

* Username: `admin@example.com`
* Password: `password`

After authenticating, you should see the FusionAuth Admin UI, which shows information about active users, logins, registrations, and more:

![The FusionAuth Admin UI.](/img/quickstarts/react/fusionauth-admin.png)

## Create the Angular app

Open a new terminal in the `fusionauth-quickstart-javascript-angular-web` directory to create the frontend app.

1. Run the command below to create a new Angular app using a minimal template:

```shell-session
npx @angular/cli@22.2.6 new app --defaults --inline-template --inline-style --style=css --skip-git --skip-tests --ssr=false --ai-config=none # https://angular.dev/cli/new
```

1. Run the app:

```shell-session
cd app
npx @angular/cli@22.2.6 serve --host=0.0.0.0 --port=3000
```

You can now browse to the web app at http://localhost:3000 (which matches the allowed authentication URL defined in the FusionAuth Kickstart file).

As you follow this guide, the app should hot-reload when you change the `.ts` files, but if not, push <kbd>Ctrl C</kbd> to stop the Angular server and restart it by pushing <kbd>Up Enter</kbd> to rerun the `serve` command.

<Aside type="note">
This FusionAuth configuration specifies the following values:

* `redirectUri`: URI to open after a successful login.
* `postLogoutRedirectUri`: URI to open after logout.
* `shouldAutoRefresh`: Set to automatically renew the access token.
* `scope`: OAuth 2.0 permissions for the access token.
* `clientId`: ID of the application in the FusionAuth instance.
* `serverUrl`: Base URL for the FusionAuth authorization server.
* `onRedirect`: Callback that executes when a redirect occurs.
</Aside>

### Test authentication

1. Open a _private browser window_ so you don't retain your login status from previous sections.

1. Navigate to the Angular app at [http://localhost:3000](http://localhost:3000).

   ![The landing page of the Angular app.](/img/quickstarts/react/landing-page.png)

1. Click the login button. Your browser should redirect to FusionAuth at `http://localhost:9011`.

   ![The fusionauth login screen.](/img/quickstarts/react/login-fusionauth.png)

1. Authenticate with the credentials for the user created in `backend_fusionauth/kickstart/kickstart.json`:

   * Username: `richard@example.com`
   * Password: `password`

FusionAuth validates the credentials, then redirects back to the `redirectUri` set in `src/app/app.config.ts`. The home page checks whether the user is logged in. After a successful login, the app navigates to the account page.

Right now, you should see the account page containing the stub text `User info will display here`:

![The home page, not yet populated with user data.](/img/quickstarts/react/home-sans-data.png)

Some require additional licensing. For details, see the [pricing page](/pricing).
