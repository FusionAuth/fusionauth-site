FusionAuth will always have a powerful, full featured free-to-use Community plan. This is the foundation of FusionAuth and the community surrounding it. FusionAuth is committed to improving the Community plan with both features and bug fixes.


FusionAuth has several different **plans** (also called **editions**) which enable advanced features:

* **Community** has all features not otherwise labeled in the documentation.
* **Licensed Community** has all licensed community features.
* **Starter** has all starter features, but some may have some numeric or usage limits.
* **Essentials** has all essentials and starter features, but some may have some numeric limits.
* **Enterprise** has all enterprise, essentials and starter features and no limits.

To gain access to the features enabled by a certain plan, purchase [a FusionAuth license](/docs/get-started/core-concepts/licensing).

You can learn more about purchasing a FusionAuth license on the [pricing page](/pricing).
