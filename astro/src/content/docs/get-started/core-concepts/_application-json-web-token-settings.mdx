<APIBlock>
  <APIField name="Issuer" readonly>
    The issuer used in the `iss` claim when building the Access Token and Id Token. This is a read-only value in this configuration. It can be modified in the Tenant configuration.
  </APIField>
  <APIField name="JWT duration" required>
    The duration in seconds for which a JWT will be valid after creation. After this time has passed the JWT will expire and can no longer be used.
  </APIField>
  <APIField name="Access token signing key" optional>

    The signing key used to sign the Access Token (which is a JWT) when a user authenticates against this Application. When this value is not selected, FusionAuth will generate a new key pair and assign it to this configuration.
  </APIField>
  <APIField name="Access token verification keys" optional since="1.69.0">
    These are the keys that FusionAuth uses to verify access token signatures. If a verification key is expiring, add its replacement here so either key can be used to verify until the old one expires or is removed. The *Access token signing key* value does not need to be explicitly added here.
  </APIField>
  <APIField name="Id token signing key" optional>
    The signing key used to sign the Id Token (which is a JWT) when a user authenticates against this Application. When this value is not selected, FusionAuth will generate a new key pair and assign it to this configuration.
  </APIField>
  <APIField name="Id token verification keys" optional since="1.69.0">
    These are the keys that FusionAuth uses to verify Id token signatures. If a verification key is expiring, add its replacement here so either key can be used to verify until the old one expires or is removed. The *Id token signing key* value does not need to be explicitly added here.
  </APIField>
</APIBlock>
