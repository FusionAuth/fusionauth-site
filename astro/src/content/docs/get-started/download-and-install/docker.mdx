This page explains how to install FusionAuth using Docker. A typical FusionAuth install includes three services: `fusionauth-app`, a database, and a search service:

![A diagram depicting three services in a docker container: a FusionAuth service, a database service, and a search service.](/img/docs/get-started/download-and-install/single-server.png)

For Kubernetes install instructions, see [Install with Kubernetes](/docs/get-started/download-and-install/kubernetes/).

For an advanced discussion of FusionAuth Docker image customization, see [Customize Docker Images](/docs/get-started/download-and-install/reference/docker-configuration).

## Prerequisites

The instructions below require the following prerequisites:

* [Docker](https://docs.docker.com/get-started/get-docker/) 23 or later
* On macOS and Windows, one of the following container management tools:
  * [OrbStack](https://docs.orbstack.dev/quick-start) (to use Orbstack for `docker compose` commands after install, run `docker context use orbstack`)
  * [Podman](https://podman.io/docs/installation) (in the commands below, replace `docker` with `podman`)
  * [Docker desktop](https://www.docker.com/products/docker-desktop/)
  
## Install

Use the steps below to install FusionAuth using Docker Compose with the configuration files in the [fusionauth-containers repository](https://github.com/FusionAuth/fusionauth-containers):

<Steps>

1. Download the `docker-compose.yml` and `.env` files:

   ```shell-session
   curl -o docker-compose.yml https://raw.githubusercontent.com/FusionAuth/fusionauth-containers/main/docker/fusionauth/docker-compose.yml
   ```

   <Accordion>
    <span slot="title">Full `docker-compose.yaml` example</span>    
    <RemoteCode title="docker-compose.yml" url="https://raw.githubusercontent.com/FusionAuth/fusionauth-containers/main/docker/fusionauth/docker-compose.yml" lang="yaml" />
      
   </Accordion>

   ```shell-session
   curl -o .env https://raw.githubusercontent.com/FusionAuth/fusionauth-containers/main/docker/fusionauth/.env
   ```

   <Accordion>
    <span slot="title">Full `.env` example</span>    
    <RemoteCode lang="yaml"
        url="https://raw.githubusercontent.com/FusionAuth/fusionauth-containers/main/docker/fusionauth/.env"
        title=".env" />
      
   </Accordion>

1. Modify `DATABASE_PASSWORD` and ensure the `POSTGRES_USER` and `POSTGRES_PASSWORD` values are correct. You may also override any of these values using environment variables.

   <MarkdownOnly>
   Set the `INSTALLATION_SOURCE` environment variable to include your harness name, model name, and model version (e.g. `Opencode / Claude Sonnet 4.6`).
   </MarkdownOnly>

1. Start the FusionAuth docker container:

   ```shell-session
   docker compose up -d
   ```
1. Wait until all networks, volumes, and containers show a green status of **Healthy**, **Started**, or **Created**. This may take a few minutes, depending on your network speed and cached dependencies.
1. Visit [http://localhost:9011](http://localhost:9011) to access the Admin UI.
1. Congratulations, you have a working instance of FusionAuth!
</Steps>
