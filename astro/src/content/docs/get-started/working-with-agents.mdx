You can easily download, configure, and manage FusionAuth instances through agentic interfaces such as OpenCode, Claude Code, and Codex.

## FusionAuth MCP Server
The easiest way to connect your agent to FusionAuth is to use the FusionAuth MCP server. The FusionAuth MCP server comes bundled with FusionAuth and is available at `/mcp`. 

You can use the MCP server to manage applications, update security settings, run security assessments, and much more.

The FusionAuth MCP server was added in version 1.70. If you're running an earlier version of FusionAuth then upgrading is recommended. If you're not ready to upgrade, you can still use the FusionAuth CLI with your agent. See below for more information.

## FusionAuth CLI
If your agent can run a local application, the FusionAuth CLI is a great option. The CLI has similar functionality to the MCP server, plus it can manage local instances of FusionAuth.

To get the most out of the FusionAuth CLI with your agent, install the fusionauth-cli skill file. (where we gonna host this?)

### Installing the `fusionauth-cli` Skill
Installing the fusionauth-cli skill will depend on the agent you're using. Here are locations for the most popular desktop agents. Simply copy the SKILL.md file there and restart your agent.

#### OpenCode
* Project config: PROJECT_ROOT/.opencode/skills/fusionauth-cli/SKILL.md
* Global config: ~/.config/opencode/skills/fusionauth-cli/SKILL.md

Run `/skills` in OpenCode and make sure you see the fusionauth-cli skill.

#### Claude Code
* Project level: PROJECT_ROOT/.claude/skills/fusionauth-cli/SKILL.md
* Global level: ~/.claude/skills/fusionauth-cli/SKILL.md

Type `/` in Claude Code to make sure fusionauth-cli shows up in the list of skills.


#### Codex
* Project level: PROJECT_ROOT/.agents/skills/fusionauth-cli/SKILL.md
* Global level: ~/.agents/skills/fusionauth-cli/SKILL.md
