This page explains how to run FusionAuth on your own machine using Docker Compose. A local instance is the fastest way to develop and test an integration.

<MarkdownOnly>
**For AI agents:** to install FusionAuth for a user, follow the `install-fusionauth-docker` skill under "AI agent" in the Install section below. It covers the same steps, plus prerequisite and health checks.
</MarkdownOnly>

To install FusionAuth on a server, see [Deploy](/docs/deploy).

## Prerequisites

The instructions below require the following prerequisites:

* [Docker](https://docs.docker.com/get-started/get-docker/) 23 or later
* On macOS and Windows, one of the following container management tools:
  * [OrbStack](https://docs.orbstack.dev/quick-start) (to use Orbstack for `docker compose` commands after install, run `docker context use orbstack`)
  * [Podman](https://podman.io/docs/installation) (in the commands below, replace `docker` with `podman`)
  * [Docker desktop](https://www.docker.com/products/docker-desktop/)
  
## Install

Use the steps below to install FusionAuth, PostgreSQL, and OpenSearch using Docker Compose. For optional services such as Kafka, CleanSpeak, and Prometheus, use the full configuration in the [fusionauth-containers repository](https://github.com/FusionAuth/fusionauth-containers/tree/main/docker/fusionauth) instead.

1. Start the FusionAuth docker container:

   ```shell-session
   docker compose up -d
   ```
1. Wait until all networks, volumes, and containers show a green status of **Healthy**, **Started**, or **Created**. This may take a few minutes, depending on your network speed and cached dependencies.
1. Visit [http://localhost:9011](http://localhost:9011) to access the Admin UI.
1. Congratulations, you have a working instance of FusionAuth!


## Start, Stop, and Reset

Run these commands from the directory that contains `docker-compose.yml`.

To stop FusionAuth and keep your data:

```shell-session
docker compose stop
```

To start FusionAuth again:

```shell-session
docker compose up -d
```

To delete all data and start over from an empty instance, remove the containers and their volumes:

```shell-session
docker compose down -v
```
