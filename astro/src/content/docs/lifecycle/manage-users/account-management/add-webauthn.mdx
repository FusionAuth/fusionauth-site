WebAuthn is disabled by default on a tenant. To toggle navigate to <Breadcrumb>Tenants -> Edit Tenant -> WebAuthn</Breadcrumb>. In order for the user to use the registered passkey, at least one WebAuthn workflow must be enabled for the tenant.

## Enable WebAuthn on Tenant (Admin Facing)

WebAuthn is disabled by default at the tenant level. It can be toggled on and off as needed.

<Screenshot id="account-tenant-webauthn" url="/admin/tenant/edit/30663132-6464-6665-3032-326466613934#webauthn" alt="The tenant WebAuthn tab with the Bootstrap passkey authentication settings highlighted.">
  <Highlight selector="[data-hl='section-box']" />
</Screenshot>

In order for a user to use a passkey, one or more WebAuthn workflows must be enabled at the tenant or application level. See the [WebAuthn Admin Guide](/docs/lifecycle/authenticate-users/passkeys/) for more details on configuration.

## Add a Passkey from Account Management (User Facing)

<Screenshot id="account-home" url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account page with the edit button and the two-factor and passkey links." />

1. Navigate back to your <Breadcrumb>account page</Breadcrumb>
2. Click <Breadcrumb>Manage passkeys</Breadcrumb>
3. Click <Breadcrumb>Add passkey</Breadcrumb>

<Screenshot url="/oauth2/authorize?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&response_type=code&redirect_uri=https%3A%2F%2Fexample.com&prompt=login" alt="The self-service passkeys management page." id="passkeys-self-service" />

<Screenshot id="account-passkey-add" url="/account/webauthn/add?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The Add passkey form with a display name entered." />

Next,

1. Enter a display name for the new passkey. You should choose something that helps you remember the authenticator and browser it was registered.
2. Click the <Breadcrumb>Submit</Breadcrumb> button.
3. Complete the WebAuthn registration with your authenticator of choice.

## See It in Action (User Facing)

You can use a registered passkey to complete enabled WebAuthn workflows. This example uses the bootstrap authentication workflow by clicking the <Breadcrumb>Fingerprint, device or key</Breadcrumb> button on the login screen.

<Screenshot url="/oauth2/authorize?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&response_type=code&redirect_uri=https%3A%2F%2Fexample.com&prompt=login" alt="The FusionAuth login page showing the Fingerprint, device or key button." id="passkeys-bootstrap-button">
  <Highlight selector="[data-hl='webauthn-bootstrap-btn']" />
</Screenshot>


1. Click the <Breadcrumb>Fingerprint, device or key</Breadcrumb> button to go to the WebAuthn bootstrap login page.
2. Enter your username or email address.
3. Click the <Breadcrumb>Submit</Breadcrumb> button.
4. Complete the WebAuthn authentication with the registered passkey.
