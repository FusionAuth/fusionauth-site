
Not able to get your account management page up and running?  Below are common issues and how to fix them.

### Not Registered

Please note, if you are not registered for an application, you will not be able to manage your account information from these self service account management.

From the admin UI click on <Breadcrumb>Users -> Manage -> Registrations Tab -> Add registration -> Add User</Breadcrumb>.  Another option is to be programmatically added to the application through an API call.

<Screenshot id="account-not-registered" url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account page warning a user who is not registered for the application." />

### Registered But Configuration Needed

If you see this, you have to select a form to use.

<Screenshot id="account-configuration-incomplete" url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e" alt="The account page warning that no self-service form is configured." />

To set a self service form, click under <Breadcrumb>Applications -> Edit Application -> Registration</Breadcrumb>

<Screenshot id="account-application-self-service-form" url="/admin/application/edit?applicationId=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e#registration" alt="The application Registration tab with the User Self-service form setting highlighted.">
  <Highlight selector="#application_formConfiguration_selfServiceFormId-form-row" />
</Screenshot>

Select the form you would like to use. A default form is shipped with FusionAuth.
