## Nintendo Developer Account

Create a new Nintendo developer account or log into the [Nintendo Developer Portal](https://developer.nintendo.com) with an existing account. Retrieve an existing `Client Id` and `Client secret` or follow Nintendo documentation to request them. Contact Nintendo Developer support for additional information.

#### Form Fields

<APIBlock>
  <APIField name="Unique Id claim" optional defaults="id">
    The name of the claim that contains the immutable unique Id of the user.
  </APIField>
  <APIField name="Email claim" optional defaults="email">
    The name of the claim that will contain an email address.
  </APIField>
  <APIField name="Username claim" optional defaults="preferred_username">
    The name of the claim that will contain the user's username.
  </APIField>
</APIBlock>
