FusionAuth sends this email when a user registers for an Application that requires registration verification. Assign the template in **Verification template** on the Application's <Breadcrumb>Registration</Breadcrumb> tab.

## Replacement Variables

<APIBlock>
  <Variable kind="email" name="application" since="1.21.0" always />
  <Variable kind="email" name="baseUrl" />
  <APIField name="registration" type="Object">
    The User Registration object. For field definitions, see the [Registration API](/docs/apis/registrations).
  </APIField>
  <Variable kind="email" name="tenant" since="1.18.2" />
  <Variable kind="email" name="user" />
  <APIField name="verificationId" type="String">
    The verification Id for the [Verify a User Registration](/docs/apis/registrations/verify-a-user-registration) API.
  </APIField>
  <APIField name="verificationOneTimeCode" type="String">
    The one-time code for the gated registration workflow. The user enters the code to verify the registration.
  </APIField>
</APIBlock>
