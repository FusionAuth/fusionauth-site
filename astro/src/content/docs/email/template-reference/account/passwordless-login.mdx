FusionAuth sends this email when a user requests a passwordless login, on the hosted login pages or through the [Passwordless](/docs/apis/passwordless) API. Assign the template in **Passwordless login** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.

## Replacement Variables

<APIBlock>
  <Variable name="application" since="1.21.0" />
  <Variable name="baseUrl" />
  <APIField name="code" type="String">
    The code for the [Complete a Passwordless Login](/docs/apis/passwordless/complete-a-passwordless-login) API. Put the code in a login link.
  </APIField>
  <APIField name="oneTimeCode" type="String" since="1.59.0">
    The one-time code the user enters on a form, for the `FormField` login strategy. Check for the variable before you use it, as the default template does.
  </APIField>
  <APIField name="state" type="Object">
    The **`state`** from the passwordless start request. The variable is present only when the request includes **`state`**.
  </APIField>
  <Variable name="tenant" since="1.18.2" />
  <Variable name="user" />
</APIBlock>
