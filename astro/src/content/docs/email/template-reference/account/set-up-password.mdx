FusionAuth sends this email when you create a user without a password and ask FusionAuth to send a set up password email. Assign the template in **Set up password** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
