<PlanBlurb plan="enterprise" />

FusionAuth sends this email when a user finishes the forgot password workflow and sets a new password. Assign the template in **Password reset success** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
