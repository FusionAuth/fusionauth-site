FusionAuth sends this email with a code when a user completes a multi-factor login with the email method, or enables or disables the email method. Assign the template in **Template** under <Breadcrumb>Tenants -> Your Tenant -> Multi-Factor -> Email settings</Breadcrumb>. To override the template for one Application, set **Email template** on the Application's <Breadcrumb>Multi-Factor</Breadcrumb> tab.

The **`application`** variable is missing when a request that sends the code has no **`applicationId`**. The requests are the following:

* [Start Multi-Factor](/docs/apis/two-factor/start-multi-factor).
* The [Login API](/docs/apis/login/authenticate), when multi-factor authentication is required. A production login request should always include **`applicationId`**.
* The requests that send a code to [enable](/docs/apis/two-factor/send-a-multi-factor-code-when-enabling-mfa) or [disable](/docs/apis/two-factor/send-a-multi-factor-code-when-disabling-mfa) a method.
