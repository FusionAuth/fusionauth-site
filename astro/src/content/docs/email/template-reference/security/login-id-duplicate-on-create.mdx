<PlanBlurb plan="enterprise" />

FusionAuth sends this email when someone tries to create a user with an email address, username, or phone number that already belongs to another user. The email goes to the existing account in **`event.existing`**, not to **`user`**. Don't put details about **`user`** in the email, because the recipient doesn't own that account. Assign the template in **Login Id duplicate on create** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
