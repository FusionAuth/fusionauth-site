FusionAuth sends this email when [breached password detection](/docs/security/account-protection/breached-password-detection) finds the user's password at login, and the tenant's action is to notify the user. Assign the template in **Notify user template** under <Breadcrumb>Tenants -> Your Tenant -> Password -> Breach detection settings</Breadcrumb>.

## Replacement Variables

<APIBlock>
  <Variable name="application" since="1.27.2" />
  <Variable name="baseUrl" />
  <APIField name="breachResult.loginIds" type="Array<String>">
    The email addresses or usernames from the breach that match the user. An empty array means only the password matched.
  </APIField>
  <APIField name="breachResult.match" type="String">
    The match type. The possible values are:

          * `ExactMatch`: The user's login Id and password appear in the breach exactly.
          * `SubAddressMatch`: The password and a sub-address of the email address appear in the breach. For example, `joe+test@example.com` is a sub-address of `joe@example.com`.
          * `PasswordOnly`: The password appears in the breach, but not with the user's login Id.
          * `CommonPassword`: The password is one of the most commonly breached passwords.
  </APIField>
  <Variable name="tenant" />
  <Variable name="user" />
</APIBlock>
