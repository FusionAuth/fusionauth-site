FusionAuth sends this email when a user adds a two-factor method. Assign the template in **Two-factor method added** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
