<PlanBlurb plan="enterprise" />

FusionAuth sends this email when a user removes a two-factor method. When an administrator removes the method, see [Admin Two-Factor Method Removed](/docs/email/template-reference/security/admin-two-factor-method-removed). Assign the template in **Two-factor method removed** on the <Breadcrumb>Tenants -> Your Tenant -> Identities</Breadcrumb> tab. To override the template for one Application, set the template on the <Breadcrumb>Applications -> Your Application -> Identities</Breadcrumb> tab.
