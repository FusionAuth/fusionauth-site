FusionAuth sends a User Action email when someone applies a [User Action](/docs/users/user-actions) to a user, and asks FusionAuth to email the user. A time-based action can send an email in each phase: start, modify, cancel, and end. An action without a duration sends only the start email. Assign the templates in **Start template**, **Modify template**, **Cancel template**, and **End template** on the action under <Breadcrumb>Settings -> User Actions</Breadcrumb>.

FusionAuth sends the email only when the action has **Email user when action is taken** enabled, and the request sets **`action.emailUser`** to `true`. All four templates receive the same variables, so one template can serve every phase by checking **`phase`**.

## Replacement Variables

<APIBlock>
  <APIField name="action" type="Object">
    The User Action object, such as **`action.name`**. For field definitions, see the [User Actions API](/docs/apis/user-actions).
  </APIField>
  <Variable name="baseUrl" />
  <APIField name="event" type="Object">
    The [User Action](/docs/events/reference/user/user-actions) event, with details such as **`event.reason`** and **`event.expiry`**. The variable is missing when a CleanSpeak moderation decision triggers the action.
  </APIField>
  <APIField name="phase" type="String">
    The phase of the action: `start`, `modify`, `cancel`, or `end`.
  </APIField>
  <Variable name="tenant" />
  <Variable name="user" description="The User object for the user who received the action." />
</APIBlock>
