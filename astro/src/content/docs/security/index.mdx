These pages cover protecting user accounts, user credentials, and the tokens your apps receive. To secure the servers and network that run a self-hosted instance, see [Harden](/docs/deploy/harden).

To get security announcements as a FusionAuth customer, log into [account.fusionauth.io](https://account.fusionauth.io) and make sure your account has the `Security Officer` role.
