This QuickStart explains how to add a login page and authentication to a website built with [Flask](https://flask.palletsprojects.com/). You'll begin with a simple Flask app that allows visitors to edit a file. Then, you'll add authentication to the app with a FusionAuth instance. Finally, you'll extend the app to handle multiple independent users with user data provided by FusionAuth.

This tutorial should take between 5 and 15 minutes; less if you already have prerequisites like Docker installed.

## Prerequisites

This QuickStart requires:

* [Python](https://www.python.org/downloads/) 3.10 or later
* [Docker](https://docs.docker.com/get-started/get-docker/) 23 or later
* On macOS and Windows, one of the following container management tools:
  * [Docker desktop](https://www.docker.com/products/docker-desktop/)
  * [OrbStack](https://docs.orbstack.dev/quick-start) (to use Orbstack for `docker compose` commands after install, run `docker context use orbstack`)
  * [Podman](https://podman.io/docs/installation) (in the commands below, replace `docker` with `podman`)

Be sure to open your container management tool to configure and install any dependencies needed by that tool, including Rosetta and Developer Tools on macOS.

## Install and Run FusionAuth

Before we can add authentication to our Flask app, we need a local FusionAuth instance:

<Steps>
1. Open your container management tool (listed in the prerequisites above).

1. From the `flask-quickstart` folder, clone the [GitHub repository for the FusionAuth instance you'll use with this QuickStart](https://github.com/FusionAuth/fusionauth-quickstart-app):

   ```shell-session
   git clone https://github.com/FusionAuth/fusionauth-quickstart-app.git
   ```

1. Navigate into the cloned directory:

   ```shell-session
   cd fusionauth-quickstart-app
   ```

1. To start a local instance of FusionAuth, run the following command (omit the `-d` flag to see all Docker logs):

   ```shell-session
   docker compose up -d
   ```

1. Wait until all networks, volumes, and containers show a green status of **Healthy**, **Started**, or **Created**. This may take a few minutes, depending on your network speed and cached dependencies.

1. Open [http://localhost:9011/admin](http://localhost:9011/admin) to access the FusionAuth Admin UI.

1. Log in with these credentials:

   * username: `admin@example.com`
   * password: `password`

1. Navigate to <Breadcrumb>Applications -> QuickStart App -> Edit -> OAuth</Breadcrumb>. On this page, you can find your client ID, your client secret, and specify redirect and logout URLs. In the next part of this QuickStart, we'll use these values to connect our Flask app with FusionAuth.

1. Click the logout icon in the top right to log out of the Admin UI. We'll use a different user account to access our Flask app, and because FusionAuth supports SSO, we need to log out of our admin account before we can log in as a normal user.
</Steps>

1. Take a moment to understand the calls to `oauth.register`, `authorize_redirect`, and `authorize_access_token`, since these are the heart of our FusionAuth integration:
   * `register` tells Authlib how to talk to FusionAuth, using the OpenID Connect discovery document at `/.well-known/openid-configuration` to find the authorize and token endpoints

## Add Independent Notes for Each User

To see a more realistic example of FusionAuth usage, we can improve the app even more, so every user gets a unique note to edit. To accomplish this, we'll use FusionAuth's user data:

<Steps>
1. Open the FusionAuth Admin UI at [http://localhost:9011/admin](http://localhost:9011/admin).

1. Log in with the following credentials:

   * username: `admin@example.com`
   * password: `password`

1. Navigate to <Breadcrumb>Applications -> QuickStart App -> Edit -> Registration</Breadcrumb>.

   * Under **Self-service registration**, check that **Registration mode** is set to **Create registration**. The QuickStart configuration has already turned on self-service registration.
   * In the **Registration field** list, turn on the **Enabled** and **Required** switches for the following rows:
     * **Birthdate**
     * **First name**
     * **Last name**

1. Click the **Save** button in the top right of the page to save your changes to self-service registration.

1. Navigate to <Breadcrumb>Users -> Richard Hendricks -> Manage</Breadcrumb>.

1. In the **Source** tab, look for the `firstName` and `lastName` fields. That's what we'll use to personalize the UI for each user. We'll use the user's `id` field to generate a unique name for each user's note.
1. Click the logout icon in the top right to log out of the Admin UI. We'll use a different user account to access our Flask app.

1. Replace the contents of `app.py` with the following code, which requests the `profile` and `email` scopes, reads the user's name (first and last) and Id from the ID token, and stores each user's note in a separate file:

   <ExtractedCode src="quickstart-flask/2-multi-user/app.py" lang="python"/>

   Authlib validates the ID token and decodes its claims into `token['userinfo']`, so we don't need a separate JWT library. The logout route also passes a `post_logout_redirect_uri`, which sends the user back to the login page after FusionAuth ends their session.

1. Restart the app (press **Ctrl+C**, then run `python app.py` again) and open it at [http://localhost:3000](http://localhost:3000).

1. Log in with the following credentials:

   * username: `richard@example.com`
   * password: `password`

</Steps>

Your Flask app now provides unique notes for each user. Each user can independently edit and save their note. To see all of the notes, look for `note-<id>.txt` files in the `user_data` directory. To identify which note corresponds to which user, compare the `id` in the file name with the `id` field in the user's **Source** tab.

## Next Steps

This was a quick introduction to using FusionAuth for user authentication. To learn more about integrating FusionAuth with your product, see [Get Started](/docs/get-started).

FusionAuth has many features (including [Social Login](/docs/authentication/identity-providers/#social-identity-providers), [Single Sign-On](/docs/authentication/sessions/single-sign-on), [Passkeys](/docs/authentication/passkeys/configure), [Multi-factor Authentication](/docs/authentication/multi-factor-authentication)), most of which are free. This example app is a great starting point for learning about FusionAuth features.
