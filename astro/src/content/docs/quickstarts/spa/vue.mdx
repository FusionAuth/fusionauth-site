This QuickStart adds login and a protected page to a Vue.js web app using a preconfigured, local version of FusionAuth in the following steps:

1. Create a new Vue app.
1. Customize the app with home and account pages.
1. Add login to protect the account page.
1. Add a button to the account page to fetch the user's information.

## Prerequisites

This QuickStart requires:

* [Node.js](https://nodejs.org/en/download) 22.22.2 or later, or 24.15 or later
* [Docker](https://docs.docker.com/get-started/get-docker/) 23 or later
* On macOS and Windows, one of the following container management tools:
  * [Docker desktop](https://www.docker.com/products/docker-desktop/)
  * [OrbStack](https://docs.orbstack.dev/quick-start) (to use Orbstack for `docker compose` commands after install, run `docker context use orbstack`)
  * [Podman](https://podman.io/docs/installation) (in the commands below, replace `docker` with `podman`)

Be sure to open your container management tool to configure and install any dependencies needed by that tool, including Rosetta and Developer Tools on macOS.

## Install and Run FusionAuth

To begin, clone the [GitHub repository for this QuickStart](https://github.com/FusionAuth/fusionauth-quickstart-javascript-vue-web) to your local machine:

```shell-session
git clone https://github.com/FusionAuth/fusionauth-quickstart-javascript-vue-web.git
```

The repository contains:

* `fusionauth-backend`, a preconfigured version of FusionAuth
* `vue-frontend-steps`, a runnable version of each development step of the Vue application

Navigate to `fusionauth-quickstart-javascript-vue-web/fusionauth-backend`:

```shell-session
cd fusionauth-quickstart-javascript-vue-web/fusionauth-backend
```

Open your container management tool (Docker Desktop, OrbStack, or Podman) to start the Docker daemon.

To start a local instance of FusionAuth, run the following command:

```shell-session
docker compose up -d
```

If you see an error that reads "Is the docker daemon running?", make sure your container management tool is accepting commands. Depending on your tool:
* to use Docker Desktop, Docker Desktop must be open
* to use Orbstack, enable OrbStack to run as the docker daemon with `docker context use orbstack`, then open the Orbstack app
* to use Podman, replace `docker` in the above command with `podman`

<Aside type="note">
During the Docker compose process, the included `kickstart/kickstart.json` file uses the FusionAuth API to:

* Generate an API key
* Configure [[CORS]] (<Breadcrumb>Settings -> System -> CORS</Breadcrumb>)
* Create your app ("Quick Start App") with appropriate settings and redirect URIs (<Breadcrumb>Applications -> Edit Application</Breadcrumb>)
* Create an admin user (admin@example.com) with access to the FusionAuth Admin UI (<Breadcrumb>Users</Breadcrumb>)
* Create a user (richard@example.com) and register the user with your app
* Create a custom theme ("Quick Start Theme") using `fusionauth-backend/kickstart/css/styles.css` and apply it to your [[default tenant]] (<Breadcrumb>Customizations -> Themes</Breadcrumb>)
</Aside>

Once Docker compose completes, open a browser window and navigate to the Admin UI of your FusionAuth instance at [http://localhost:9011/admin](http://localhost:9011/admin). Use the following admin account credentials to log in:

* Username: `admin@example.com`
* Password: `password`

After authenticating, you should see the FusionAuth Admin UI, which shows information about active users, logins, registrations, and more:

<Screenshot id="quickstart-admin-dashboard" url="/admin/" height={742} alt="The FusionAuth Admin UI." />

## Create the Vue App

First, create a new TypeScript Vue app with the official `create-vue` scaffolding tool:

1. If your terminal is still in the `fusionauth-backend` directory, run `cd ..` to navigate back up to `fusionauth-quickstart-javascript-vue-web`.

1. To generate a new Vue app with Vue Router in a folder called `app-quickstart-vue`, run the following command:

   ```shell-session
   npm create vue@3.24.0 app-quickstart-vue -- --ts --router --default
   ```

   Select `Yes` to install the `create-vue` package if prompted.

1. Navigate into the app folder and install the project dependencies with the following commands:

   ```shell-session
   cd app-quickstart-vue
   ```

   ```shell-session
   npm install
   ```

1. Delete the example components, assets, and about page that `create-vue` generates, as you'll replace them with your own pages:

   ```shell-session
   rm -rf src/components src/assets src/views/AboutView.vue
   ```

<Aside type="note">
This FusionAuth configuration specifies the following values:

* `redirectUri`: URI to open after a successful login.
* `postLogoutRedirectUri`: URI to open after logout.
* `shouldAutoRefresh`: Set to automatically renew the access token.
* `shouldAutoFetchUserInfo`: Return data for the user as part of a successful login.
* `scope`: OAuth 2.0 permissions for the access token.
* `clientId`: ID of the application in the FusionAuth instance.
* `serverUrl`: Base URL for the FusionAuth authorization server.
* `onRedirect`: Callback that executes when a redirect occurs. The SDK calls it before the router has loaded the first page, so it waits for `router.isReady()` before navigating.
</Aside>
