This QuickStart adds login and a protected page to an Angular web app using a preconfigured, local version of FusionAuth in the following steps:

1. Create a new Angular app.
1. Customize the app with home and account pages.
1. Add login to protect the account page.
1. Add a button to the account page to fetch the user's information.

## Prerequisites

This QuickStart requires:

* [Node.js](https://nodejs.org/en/download) 22.22.3 or later, or 24.15 or later
* [Docker](https://docs.docker.com/get-started/get-docker/) 23 or later

<Aside type="tip">
If you use macOS or Windows, you need one of the following container management tools:
  * [Docker Desktop](https://www.docker.com/products/docker-desktop/)
  * [OrbStack](https://docs.orbstack.dev/quick-start) (to use OrbStack for `docker compose` commands after installation, run `docker context use orbstack`)
  * [Podman](https://podman.io/docs/installation) (in the commands below, replace `docker` with `podman`)

Be sure to open your container management tool to configure and install any dependencies needed by that tool, including Rosetta and Developer Tools on macOS.

If you use Windows, replace `/` with `\` in all file paths.
</Aside>

## Install and Run FusionAuth

To begin, clone the [GitHub repository for this QuickStart](https://github.com/FusionAuth/fusionauth-quickstart-javascript-angular-web) to your local machine:

```shell-session
git clone https://github.com/FusionAuth/fusionauth-quickstart-javascript-angular-web
```

The repository contains:

* `backend_fusionauth`, a preconfigured version of FusionAuth
* `frontend_steps`, a runnable version of each development step of the Angular application

Navigate to `fusionauth-quickstart-javascript-angular-web/backend_fusionauth`:

```shell-session
cd fusionauth-quickstart-javascript-angular-web/backend_fusionauth
```

If you are not using Linux, then start your container runtime, such as Docker Desktop, OrbStack, or Podman before running Docker Compose.

To start a local instance of FusionAuth, run the following command:

```shell-session
docker compose up
```

<Aside type="note">
During Docker Compose startup, the included `kickstart/kickstart.json` file uses the FusionAuth API to:

* Generate an API key
* Configure [[CORS]] (<Breadcrumb>Settings -> System -> CORS</Breadcrumb>)
* Create your app ("Quick Start App") with appropriate settings and redirect URIs (<Breadcrumb>Applications -> Edit Application</Breadcrumb>)
* Create an admin user (admin@example.com) with access to the FusionAuth Admin UI (<Breadcrumb>Users</Breadcrumb>)
* Create a user (richard@example.com) and register the user with your app
* Create a custom theme ("Quick Start Theme") using `backend_fusionauth/kickstart/css/styles.css` and apply it to your [[default tenant]] (<Breadcrumb>Customizations -> Themes</Breadcrumb>)
</Aside>

Once Docker Compose initializes all containers, open a browser and navigate to the FusionAuth Admin UI at [http://localhost:9011/admin](http://localhost:9011/admin). Use the following admin account credentials to log in:

* Username: `admin@example.com`
* Password: `password`

After authenticating, you should see the FusionAuth Admin UI, which shows information about active users, logins, registrations, and more:

<Screenshot id="quickstart-admin-dashboard" url="/admin/" height={742} alt="The FusionAuth Admin UI." />

## Create the Angular App

Open a new terminal in the `fusionauth-quickstart-javascript-angular-web` directory to create the frontend app.

1. Run the command below to create a new Angular app using a minimal template:
    ```shell-session
    npx @angular/cli@22.2.6 new app --defaults --inline-template --inline-style --style=css --skip-git --skip-tests --ssr=false --ai-config=none
    ```
1. Run the app:
    ```shell-session
    cd app
    npx @angular/cli@22.2.6 serve --host=0.0.0.0 --port=3000
    ```

You can now browse to the web app at http://localhost:3000 (which matches the allowed authentication URL defined in the FusionAuth Kickstart file earlier).

As you follow this guide, the app should hot-reload when you change the source files. But if the page doesn't refresh, press <kbd>Ctrl C</kbd> to stop the Angular server, then press <kbd>Up</kbd> and <kbd>Enter</kbd> to rerun the `serve` command.

<Aside type="note">
This FusionAuth configuration specifies the following values:

* `redirectUri`: URI to open after a successful login.
* `postLogoutRedirectUri`: URI to open after logout.
* `shouldAutoRefresh`: Set to automatically renew the access token.
* `scope`: OAuth 2.0 permissions for the access token.
* `clientId`: Id of the application in the FusionAuth instance.
* `serverUrl`: Base URL for the FusionAuth authorization server.
* `onRedirect`: Callback that executes when a redirect occurs.
</Aside>

1. Click the <Breadcrumb>Login</Breadcrumb> button. Your browser should redirect to FusionAuth at `http://localhost:9011`.

   * Username: `richard@example.com`
