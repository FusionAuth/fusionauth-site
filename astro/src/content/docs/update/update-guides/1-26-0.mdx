FusionAuth `1.26.0` replaced the Two-Factor APIs from `1.25` and earlier. When you update from `1.25` or earlier, check your plan, your data, and your code.

## Plan

In FusionAuth `1.26.0` and later, email and SMS MFA require a paid plan. SMS MFA was available on the Community plan before `1.26.0`. For the plans, see [Pricing](/pricing).

Authenticator app MFA stays on every plan. In `1.26.0` and later, a user can add more than one authenticator app.

## Data

The database migration for `1.26.0` moves the following data:

* Whether each user has MFA enabled.
* The Twilio settings, which become a Twilio messenger.
* The authenticator configuration of each user.

When data doesn't migrate correctly, open a [GitHub issue](https://github.com/FusionAuth/fusionauth-issues/issues). With a plan that includes support, open a [support ticket](https://account.fusionauth.io/account/support/).

## Code

To add a method to a user, make the following changes:

* Turn on the method on the Tenant. For more information, see [Configure MFA](/docs/authentication/multi-factor-authentication/configure).
* For SMS, check the Twilio messenger.
* Replace the **`delivery`** field with the **`method`** field and the field for the method, such as **`email`**.

To remove a method, send the **`methodId`** of the method to remove, along with the **`userId`** and the **`code`**.

Before `1.26.0`, the Send API only sent Twilio SMS messages. In `1.26.0` and later, the Send API takes different parameters to add a method, to remove a method, and to send a code during a login or step-up. Check that the Tenant turns on the method and that the messenger works. Then update each call. For the parameters of each call, see the [Two-Factor APIs](/docs/apis/two-factor).
