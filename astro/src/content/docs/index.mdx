FusionAuth is a Customer Identity and Access Management (CIAM) server that provides:

* Authentication
* Authorization
* User Management

```mermaid title="FusionAuth connects users, applications, and identity providers"
graph LR
    classDef orangeBorder stroke:#ff9800,stroke-width:2px;
    User((User)) -->|authenticates| FA(FusionAuth):::orangeBorder
    App[Application] -->|delegates auth| FA
    FA <-->|brokers identity| IdP[External IdPs]
    User -->|consumes| App
```

FusionAuth provides a full implementation of [OAuth2](/docs/authentication/oauth), [OpenID Connect (OIDC)](/docs/authentication/identity-providers/overview-oidc), and [SAML v2](/docs/authentication/act-as-an-idp/host-saml-idp). In SAML v2, FusionAuth provides both [Service Provider (SP)](/docs/authentication/identity-providers/overview-samlv2) and [Identity Provider (IdP)](/docs/authentication/act-as-an-idp/host-saml-idp) functionality.

## Customize

FusionAuth is highly customizable, both in appearance and behavior. You can control every [page](/docs/theme/simple-theme-editor) and [message](/docs/messengers/template-reference). You can use lambda functions to customize [data validation](/docs/lambdas/login/login-validation), [MFA challenge logic](/docs/lambdas/login/mfa-requirement), [token transformation](/docs/lambdas/tokens/jwt-populate), and [much more](/docs/lambdas). You can use webhooks to [react to a wide variety of events](/docs/events/reference).
