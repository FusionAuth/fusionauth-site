<Item category="fix" issue="3600" since="1.71.0">
Fixed an issue where logins through some SAML v2 Identity Providers, such as Google Workspace, failed with the error `The SAML AuthnResponse object could not be parsed or verified` and mentions namespace prefixes such as `xsd`. The failure affected signed SAML responses from other IdPs that use exclusive canonicalization without `InclusiveNamespaces`. FusionAuth now properly includes `InclusiveNamespaces` in its own responses as well.
</Item>

<Item category="security">
Mitigated a Java runtime vulnerability on x86-64 systems. On x86-64, the startup scripts now pass `-XX:-UseBASE64Intrinsics` to the JVM. When you start FusionAuth without the startup scripts, add `-XX:-UseBASE64Intrinsics` to your JVM options.
</Item>

<Item category="fix">
Fixed an issue where the Windows startup scripts failed to extract the downloaded Java runtime when Windows PowerShell inherited module paths from PowerShell 7.
</Item>
