<Item category="known-issue" resolvedIn="1.69.3">
When using the [Passwordless APIs](/docs/apis/passwordless/start-passwordless-login), non-encoded query parameters cause an `HTTP 403` error on `/confirmation-required` pages.
    
This issue only affects customers who:

* modified templates in a way that removed `value?url` from the state list used to build the URL.
* use the APIs to build an `/oauth2/passwordless` link without encoding the query parameters.

This issue does not impact FusionAuth instances that use the hosted login pages for passwordless authentication.
To work around this issue, manually URL encode all query parameters before sending them to `/oauth2/passwordless`.
</Item>

<Item category="security">
Fixes a critical security issue that could result in account takeover.
