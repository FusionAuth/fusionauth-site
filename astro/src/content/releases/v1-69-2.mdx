<Item category="known-issue" resolvedIn="1.69.3">
    Customers that use the [Passwordless APIs](/docs/apis/passwordless/start-passwordless-login) directly to build an `/oauth2/passwordless` link (without encoding the query parameters) or customers that have modified their email/message templates and have removed `value?url` can see HTTP 403 errors when visiting `/confirmation-required` for passwordless logins.
</Item>

<Item category="security">
Fixes a critical security issue that could result in account takeover.
