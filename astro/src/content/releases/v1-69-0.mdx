<Item category="enhancement" issue="2807">
Added events to the [Audit Log](/docs/apis/audit-logs) that capture adding a user to a group and removing a user from a group.
</Item>

<Item category="enhancement" issue="3209">
    Added support for overriding the SAML v2 service provider (SP) EntityId using **`identityProvider.issuer`** on standard SAML v2 identity providers (IdPs).

When configured, FusionAuth uses this value as the SP EntityId and expects the same value in the SAML assertion Audience.
</Item>
