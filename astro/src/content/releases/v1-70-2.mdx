import Item from 'src/components/docs/release-notes/ReleaseNotesItem.astro';

<Item category="enhancement">
Improved refresh token reaping efficiency by cleaning expired refresh tokens more often.
</Item>

<Item category="enhancement">
Added the application to the [JWT Populate Lambda](/docs/lambdas/tokens/jwt-populate), when available. When not authenticating a User against an Application (e.g. an `/api/login` call with no `applicationId`), `context.application` will be `null`.
</Item>

<Item category="fix">
When a user has a large number of Applications, editing the IdP configuration via the Admin UI could become slow. This fix correctly disables the save button until the page finishes loading.
</Item>

<Item category="fix" since="1.70.0">
In `1.70.0`, the [OpenID Configuration](/docs/apis/oauth/openid-configuration) endpoint began adding the Tenant Id to the end of the following values, even when the request didn't specify a Tenant:

* **`authorization_endpoint`**
* **`device_authorization_endpoint`**
* **`end_session_endpoint`**
* **`token_endpoint`**

This is a Tenant-specific endpoint, so if you use it for a non-default Tenant, you should supply the correct Tenant Id.

However, `1.70.2` restores the previous behavior: if you do not pass a Tenant Id to the endpoint, these values no longer include the Tenant Id.
</Item>
