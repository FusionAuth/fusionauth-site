<Item category="enhancement">
Added a tenant rate limit for incorrect passwordless one-time codes. When enabled, FusionAuth limits how many incorrect codes a client can submit to the [Complete a Passwordless Login API](/docs/apis/passwordless/complete-a-passwordless-login) within the configured period. The rate limit is disabled by default. For more information, see [Customizable Rate Limiting](/docs/security/account-protection/advanced-threat-detection#customizable-rate-limiting).
</Item>

<Item category="fix" issue="3570">
FusionAuth now rejects an authorized redirect URL that contains a fragment, both when you create or update an Application and on requests to `/oauth2/authorize`. Previously, FusionAuth accepted such a URL and appended the authorization code after the fragment, where OAuth clients can't read the code. RFC 6749 doesn't allow fragments in redirect URLs. If an Application has an authorized redirect URL with a fragment, remove the fragment before you update.
</Item>

<Item category="fix" issue="3476">
Fixed slow responses from the [Registration API](/docs/apis/registrations) and the [User API](/docs/apis/users) when a user belongs to a Group that grants many application roles. Removing the user from such a Group now also clears the Group's roles from the user's registration.
</Item>

<Item category="fix" issue="3580">
Fixed an issue where the [Import Users API](/docs/apis/users/import) returned a `500` error when an imported user's Id already existed. The API now returns a `400` error with details when **`validateDbConstraints`** is `true`.
</Item>

<Item category="fix">
Fixed an issue where the entity search on the <Breadcrumb>Entity grants</Breadcrumb> tab of a user and of an entity in the Admin UI returned no results.
</Item>

<Item category="fix">
Fixed an issue where malformed requests to `/.well-known` logged an error with a stack trace.
</Item>

<Item category="fix">
Added a rate limit to SCIM Group create, update, and patch requests, which serialize on a database lock. The limit prevents a burst of SCIM Group requests from slowing other requests. When a client exceeds the limit, FusionAuth returns a `429` status code.
</Item>

<Item category="security">
FusionAuth now verifies the signature of the Java runtime that the startup scripts download for ZIP, RPM, and DEB installations. The Docker image already verified the Java runtime when FusionAuth built the image.
</Item>

<Item category="security">
Fixed multiple issues in passwordless login and MFA enrollment.
</Item>

<Item category="security">
Fixed multiple issues in the OAuth Device Authorization Grant.
</Item>

<Item category="security">
Fixed an issue with tenant isolation when retrieving refresh tokens with a tenant-scoped API key.
</Item>
