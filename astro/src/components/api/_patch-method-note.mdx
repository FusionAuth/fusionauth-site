For backward compatibility, a `PATCH` request with a `Content-Type` of `application/json` accepts the same body as the `PUT` request. FusionAuth merges the request values into the existing object, so every field is optional. Send only the values you want to change. To remove a value, set the value to `null`. Array behavior varies by API and field. For example, FusionAuth appends to **`user.preferredLanguages`** but replaces **`registration.roles`**.

To control how FusionAuth changes arrays, set the `Content-Type` to one of the following media types:

* `application/json-patch+json` for [JSON Patch (RFC 6902)](https://www.rfc-editor.org/rfc/rfc6902)
* `application/merge-patch+json` for [JSON Merge Patch (RFC 7396)](https://www.rfc-editor.org/rfc/rfc7396)

For more information, see [The PATCH HTTP Method](/docs/apis#the-patch-http-method).
