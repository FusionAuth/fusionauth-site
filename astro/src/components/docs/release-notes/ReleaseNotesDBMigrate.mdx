<Item category="database-migration">
This version includes a database migration. What you need to do depends on how you run FusionAuth:

* FusionAuth Cloud: no action required. FusionAuth Cloud applies the migration for you.
* Self-hosted with [silent mode](/docs/deploy/production/install/silent-mode) enabled: no action required. FusionAuth applies the migration automatically during startup.
* Self-hosted in the `production` [runtime mode](/docs/deploy/production/configuration) without silent mode: [run the migration out of band](/docs/update/database-migrations#run-migrations-out-of-band) before you start the new version.
* Self-hosted in the `development` runtime mode without silent mode: Maintenance Mode prompts you to run the migration.

{props.children}

To plan for downtime on large databases, see [Downtime and Locking](/docs/update/database-migrations#downtime-and-locking).
</Item>
