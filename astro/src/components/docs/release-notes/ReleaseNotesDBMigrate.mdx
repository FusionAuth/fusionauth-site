<Item category="database-migration">
This version makes significant changes to the database schema. Updating to this version requires a database migration. While in development mode you will be prompted to migrate the database by maintenance mode before you may login. In a production runtime mode, or with silent configuration enabled, the migration will occur automatically during startup.

<slot />

For more information about database migrations, see [Database Migrations](/docs/update/database-migrations#downtime-and-locking).
</Item>
