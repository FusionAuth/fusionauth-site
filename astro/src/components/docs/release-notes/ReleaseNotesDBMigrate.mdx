<Item category="database-migration">
This version makes significant changes to the database schema. Updating to this version requires a database migration. In the development [runtime mode](/docs/reference/configuration), Maintenance Mode prompts you to migrate the database before you can log in. With [silent mode](/docs/get-started/download-and-install/reference/silent-mode) enabled, FusionAuth applies the migration automatically during startup. In the production runtime mode without silent mode, FusionAuth never applies the migration, and you must [run it out of band](/docs/update/database-migrations#run-migrations-out-of-band).

{props.children}

For more information about database migrations, see [Database Migrations](/docs/update/database-migrations#downtime-and-locking).
</Item>
